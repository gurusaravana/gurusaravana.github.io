The idea: cancel the nonlinearity

Linearization about an operating point (Lesson 3) gives a model that is good only near that point. Feedback linearization is different: it uses feedback to cancel the nonlinearity exactly, so that the closed loop is linear everywhere the cancellation is defined. Then all of linear control (pole placement, PID, LQR) can be used on the new linear system.

The simplest case is a system in companion form, where the nonlinearity sits in the same equation as the input:

$$\dot x_1 = x_2, \quad \dot x_2 = x_3, \quad \dots, \quad \dot x_n = f(x) + g(x)u .$$

If $g(x) \ne 0$, the feedback

$$u = \frac{1}{g(x)}\big(v - f(x)\big)$$

gives $\dot x_n = v$: a chain of $n$ integrators from the new input $v$. With $v = -k_0x_1 - k_1x_2 - \dots - k_{n-1}x_n$ the closed loop is linear with characteristic polynomial $s^n + k_{n-1}s^{n-1} + \dots + k_0$, so the poles can be placed anywhere.

Example: mass, nonlinear spring and nonlinear damper. $\dot x_1 = x_2$, $\dot x_2 = -\phi(x_1) - \psi(x_2) + u$, where $\phi$ is the spring force and $\psi$ the damping force. The feedback $u = \phi(x_1) + \psi(x_2) - a_1x_1 - a_2x_2 + r$ gives $\ddot x_1 + a_2\dot x_1 + a_1x_1 = r$: a linear mass–spring–damper with any poles we like. This is Exercise 12.1 of the tutorial.

Cancelling an input nonlinearity. A related trick: if the plant is linear but the actuator is a known static nonlinearity $f$ (a valve with a square-law characteristic, a dead zone), feed the controller output through the inverse $f^{-1}$ before the actuator. Then $f(f^{-1}(\cdot))$ is the identity and the loop is linear. For $f(v) = v^2$, $v \ge 0$, the inverse is $\sqrt{\cdot}$; for a dead zone of width $d$ the inverse adds $d\,\mathrm{sign}(\cdot)$.

A change of variables first

The nonlinearity is not always in the same equation as the input. Consider

$$\dot x_1 = a\sin x_2, \qquad \dot x_2 = -x_1^2 + u .$$

No choice of $u$ cancels $a\sin x_2$ directly. But take new coordinates $z_1 = x_1$, $z_2 = a\sin x_2 = \dot x_1$. Then

$$\dot z_1 = z_2, \qquad \dot z_2 = a\cos x_2\,\dot x_2 = a\cos x_2\,(-x_1^2 + u),$$

and the feedback

$$u = x_1^2 + \frac{1}{a\cos x_2}\,v, \qquad -\frac\pi2 < x_2 < \frac\pi2,$$

gives the linear system $\dot z_1 = z_2$, $\dot z_2 = v$. The transformation and the control are defined only where $\cos x_2 \ne 0$: feedback linearization is often only valid in a region. This is input–state linearization: a change of state coordinates $z = T(x)$ plus feedback makes the whole state equation linear.

Input–output linearization and internal dynamics

Now give the same system an output and ask it to track a reference:

$$\dot x_1 = a\sin x_2, \qquad \dot x_2 = -x_1^2 + u, \qquad y = x_2 .$$

The input–state linearization above makes the state equation linear, but the output becomes $y = \sin^{-1}(z_2/a)$, which is still nonlinear. Linearizing the state equation does not necessarily linearize the output map.

Instead, aim at the output directly. With $u = x_1^2 + v$ we get $\dot y = v$: a linear map from $v$ to $y$, and $v = -k(y - y_d)$ makes $y$ follow $y_d$. There is a catch. This feedback has made $x_1$ unobservable from $y$, and $x_1$ still evolves by $\dot x_1 = a\sin x_2 = a\sin y$. If we hold $y = y_d$ constant, $x_1(t) = x_1(0) + t\,a\sin y_d$, which grows without bound.

Relative degree

Take a single-input single-output system affine in the input:

$$\dot x = f(x) + g(x)u, \qquad y = h(x), \qquad x \in \mathbb R^n .$$

Differentiate the output until the input appears. The Lie derivative of $h$ along $f$ is $L_fh = \frac{\partial h}{\partial x}f$, the rate of change of $h$ along the vector field $f$; repeated, $L_f^kh = L_f(L_f^{k-1}h)$. Then

$$\dot y = L_fh + (L_gh)\,u .$$

If $L_gh = 0$ the input does not appear and we differentiate again: $\ddot y = L_f^2h + (L_gL_fh)\,u$, and so on.

The system has relative degree $\rho$ (in a region) if $$L_gL_f^{k}h(x) = 0 \;\text{ for } k = 0, \dots, \rho - 2, \qquad L_gL_f^{\rho - 1}h(x) \ne 0 .$$ Then $y^{(\rho)} = L_f^\rho h(x) + L_gL_f^{\rho - 1}h(x)\,u$, and the feedback $$u = \frac{1}{L_gL_f^{\rho - 1}h(x)}\big(v - L_f^\rho h(x)\big)$$ gives $y^{(\rho)} = v$: a chain of $\rho$ integrators from $v$ to $y$.

In practice we rarely write Lie derivatives out; we just differentiate $y$ and substitute the state equations. For a linear system $G(s) = \frac{b(s)}{a(s)}$, the relative degree is the pole excess $\deg a - \deg b$, which is why it carries that name. It satisfies $1 \le \rho \le n$. When $\rho = n$, nothing is hidden: the output and its derivatives are a full set of coordinates and input–output linearization is also input–state linearization.

Example (two tanks, Exercise 12.3). With levels $x_1, x_2$ and pump flow $1 + u$:

$$\dot x_1 = 1 + u - \sqrt{1 + x_1}, \qquad \dot x_2 = \sqrt{1 + x_1} - \sqrt{1 + x_2}, \qquad y = x_2 .$$

$\dot y$ does not contain $u$. Differentiating once more, the input enters through $\dot x_1$:

$$\ddot y = \frac{\dot x_1}{2\sqrt{1 + x_1}} - \frac{\dot x_2}{2\sqrt{1 + x_2}} = \frac12\Big(\frac{1}{\sqrt{1 + x_1}} - \frac{\sqrt{1 + x_1}}{\sqrt{1 + x_2}}\Big) + \frac{u}{2\sqrt{1 + x_1}} .$$

The coefficient of $u$ is never zero, so $\rho = 2 = n$. In the coordinates $z_1 = y$, $z_2 = \dot y$ (so $x_2 = z_1$ and $\sqrt{1 + x_1} = z_2 + \sqrt{1 + z_1}$) the system is $\dot z_1 = z_2$, $\dot z_2 = \alpha(z) + \beta(z)u$, and $u = (v - \alpha(z))/\beta(z)$ linearizes it exactly.

The normal form

If $\rho < n$, take $\xi = (y, \dot y, \dots, y^{(\rho - 1)}) = (h, L_fh, \dots, L_f^{\rho - 1}h)$ as the first $\rho$ coordinates and complete them with $n - \rho$ further coordinates $\eta$ (chosen, where possible, so that $u$ does not enter their equations). The system becomes

$$\dot\eta = f_0(\eta, \xi), \qquad \dot\xi_1 = \xi_2, \;\dots,\; \dot\xi_{\rho - 1} = \xi_\rho, \qquad \dot\xi_\rho = L_f^\rho h + L_gL_f^{\rho - 1}h\,u, \qquad y = \xi_1 .$$

The zero dynamics are the internal dynamics when the output is held at zero: $y \equiv 0$ forces $\xi \equiv 0$, leaving $\dot\eta = f_0(\eta, 0)$. The system is minimum phase if the zero dynamics have an asymptotically stable equilibrium at the origin.

This generalizes linear systems: the zero dynamics of $G(s) = b(s)/a(s)$ have the zeros of $G$ as eigenvalues, and a linear system is minimum phase when all its zeros are in the left half-plane. Input–output linearization cancels the zeros with the controller, so it is only safe when they are stable.

Example 1. $\dot x_1 = x_2$, $\dot x_2 = -x_1 + \epsilon(1 - x_1^2)x_2 + u$, $y = x_2$. Here $\dot y$ contains $u$, so $\rho = 1$, and the system is already in normal form with $\xi = y$, $\eta = x_1$. With $y \equiv 0$: $\dot\eta = x_2 = 0$. The zero dynamics $\dot\eta = 0$ have no asymptotically stable equilibrium (every $\eta$ is an equilibrium), so the system is not minimum phase. With the output $y = x_1$ instead, $\rho = 2 = n$ and there are no zero dynamics at all.

Example 2.

$$\dot x_1 = -x_1 + \frac{2 + x_3}{1 + x_3^2}\,u, \qquad \dot x_2 = x_3, \qquad \dot x_3 = x_2x_3 + u, \qquad y = x_2 .$$

$\dot y = x_3$ and $\ddot y = \dot x_3 = x_2x_3 + u$, so $\rho = 2$. Holding $y \equiv 0$ gives $\dot y = \ddot y = 0$, i.e. $x_2 = x_3 = 0$ and $u = -x_2x_3 = 0$, and what remains is $\dot x_1 = -x_1$: the system is minimum phase. (A proper internal coordinate is $\eta = x_1 - 2\arctan x_3 - \frac12\ln(1 + x_3^2)$, chosen so that $u$ cancels from $\dot\eta$; on $\xi = 0$ it equals $x_1$ and gives the same $\dot\eta = -\eta$.)

One version of the tutorial slide writes $\ddot y = \dot x_3 = x_1x_3 + u$ and then $u = -x_1x_3$. From the state equation $\dot x_3 = x_2x_3 + u$, so it should read $\ddot y = x_2x_3 + u$ and $u = -x_2x_3$. Since $x_2 = x_3 = 0$ either way, the conclusion ($u = 0$, $\dot x_1 = -x_1$, minimum phase) is unchanged.

Tracking

To make $y$ follow a smooth reference $y_d(t)$, with $e = y - y_d$, choose

$$v = y_d^{(\rho)} - k_{\rho - 1}e^{(\rho - 1)} - \dots - k_1\dot e - k_0e .$$

Since $y^{(\rho)} = v$, the error obeys $e^{(\rho)} + k_{\rho - 1}e^{(\rho - 1)} + \dots + k_0e = 0$, which converges to zero if $s^\rho + k_{\rho - 1}s^{\rho - 1} + \dots + k_0$ is Hurwitz. The derivatives of $e$ are computed from the state ($y^{(k)} = L_f^kh(x)$ for $k < \rho$), not by differentiating a measured signal. The internal states stay bounded if the system is minimum phase (more precisely, if $\dot\eta = f_0(\eta, \xi)$ is input-to-state stable with $\xi$ as input, Lesson 6) and the reference and its derivatives are bounded.

Limits of exact linearization

  • Model errors. The cancellation is exact only if the model is. Designing $u = -x^2 - x$ for $\dot x = x^2 + u$ gives $\dot x = -x$; if the true plant is $\dot x = (1 + \varepsilon)x^2 + u$, the loop is $\dot x = \varepsilon x^2 - x$, which has a second equilibrium at $x = 1/\varepsilon$ and finite escape beyond it, whatever the sign of $\varepsilon \ne 0$.
  • Singular input gain. Where $g(x)$ or $L_gL_f^{\rho - 1}h$ is zero the control is undefined, and near it the control is huge (the $\cos x_2$ example).
  • Saturation. The cancelling term may demand more input than the actuator can give.
  • Useful nonlinearities are cancelled too. A damping term like $-x^3$ helps stability; cancelling it wastes control effort. Lyapunov-based designs (backstepping, for instance) keep such terms.
  • The full state is needed, measured or estimated by an observer.

Exercises

  1. (Tutorial Exercise 12.1) For $\dot x_1 = x_2$, $\dot x_2 = -\phi(x_1) - \psi(x_2) + u$, find a feedback that makes the closed loop linear with poles at $-2 \pm j$.
    Show solution
    Cancel both forces and add linear ones: $u = \phi(x_1) + \psi(x_2) - a_1x_1 - a_2x_2 + r$ gives $\ddot x_1 + a_2\dot x_1 + a_1x_1 = r$. Poles $-2 \pm j$ need $s^2 + 4s + 5$: $a_1 = 5$, $a_2 = 4$.
  2. (Tutorial Exercise 12.2) Linearize $\dot x_1 = x_1^2 + x_2$, $\dot x_2 = u$, $y = x_1$ exactly.
    Show solution
    Differentiate the output: $\dot y = x_1^2 + x_2$, $\ddot y = 2x_1(x_1^2 + x_2) + u$, so $\rho = 2 = n$. With $z_1 = y$, $z_2 = \dot y$: $\dot z_1 = z_2$, $\dot z_2 = 2z_1z_2 + u$. Hence $u = -2z_1z_2 + v = -2x_1(x_1^2 + x_2) + v$ gives $\ddot y = v$.
  3. (Tutorial Exercise 12.3) For the two tanks in the notes, write $\alpha(z)$ and $\beta(z)$ and the linearizing control.
    Show solution
    With $r = z_2 + \sqrt{1 + z_1}$ (which equals $\sqrt{1 + x_1}$): $\alpha(z) = \frac12\big(\frac1r - \frac{r}{\sqrt{1 + z_1}}\big)$, $\beta(z) = \frac{1}{2r}$, and $u = 2r\big(v - \alpha(z)\big)$. $\beta$ is never zero because $r > 0$.
  4. What is the relative degree of $G(s) = \dfrac{s + 3}{s^3 + 2s^2 + 4s + 1}$? Is it minimum phase?
    Show solution
    Pole excess $3 - 1 = 2$, so $\rho = 2$. The zero dynamics are one-dimensional with eigenvalue at the zero $s = -3$: stable, so minimum phase.
  5. The pendulum with torque input: $\dot x_1 = x_2$, $\dot x_2 = -\frac gl\sin x_1 - \frac{b}{ml^2}x_2 + \frac{1}{ml^2}u$. Find a feedback that gives $\ddot x_1 + 2\dot x_1 + x_1 = 0$. Is it defined everywhere?
    Show solution
    $u = ml^2\big(\frac gl\sin x_1 + \frac{b}{ml^2}x_2 - x_1 - 2x_2\big) = mgl\sin x_1 + bx_2 - ml^2(x_1 + 2x_2)$. The input gain $1/(ml^2)$ is never zero, so it is defined for every state (unlike the inverted pendulum on a cart, where the gain contains $\cos x_1$).
  6. For $\dot x_1 = x_1 + x_2$, $\dot x_2 = u$, $y = x_2$: find $\rho$ and the zero dynamics. Can you track $y_d = 1$ with input–output linearization?
    Show solution
    $\dot y = u$: $\rho = 1$. Internal state $\eta = x_1$ with $\dot\eta = \eta + y$. Zero dynamics $\dot\eta = \eta$: unstable, not minimum phase. Holding $y = 1$ gives $\dot x_1 = x_1 + 1$, so $x_1$ grows exponentially. Input–output linearization fails here; the output $y = x_1$ (with $\rho = 2$) would work.

Practice problems from the exercise compendium

From Exercises in Nonlinear Control Systems by M. Johansson, B. Bernhardsson and K. H. Johansson (Department of Automatic Control, Lund University), Chapter 7 (Nonlinear Controller Design). “Ex 7.2” means Chapter 7, Exercise 2. Work from the compendium statement. The hints and short answers here are written for this course; full solutions are not reproduced.

  1. Ex 7.1 Inverting an actuator nonlinearity: a square-law valve, a piecewise linear characteristic (and the dead zone as a special case), and backlash.
    Hint and answer
    Hint. Solve $u = f(v)$ for $v$ on each piece. For the dead zone set the inner slope to zero.
    Answer. (a) $v = \sqrt u$, $u \ge 0$. (b) $v = u/k_1$ for $|u| \le k_1d$, and $v = \big(u - \mathrm{sign}(u)(k_1 - k_2)d\big)/k_2$ beyond. With $k_1 = 0$, $k_2 = 1$ (dead zone): $v = u + d\,\mathrm{sign}(u)$. (c) Backlash has no static inverse; the usual compensation adds half the gap in the direction of motion, $v = u + b\,\mathrm{sign}(\dot u)$.
  2. Ex 7.2 Linearizing feedback for $\dot x_1 = x_2, \dots, \dot x_n = f(x) + g(x)u$; the inverted pendulum; sensitivity to model error.
    Hint and answer
    Hint. (a) Make $\dot x_n = v$. (b) Use $v = -x_1 - 2x_2$ for a double pole at $-1$. (c) Compare the designed and the true $\dot x$ and look for a new equilibrium.
    Answer. (a) $u = (v - f(x))/g(x)$, well posed where $g(x) \ne 0$. (b) $u = (-a\sin x_1 - x_1 - 2x_2)/(b\cos(\cdot))$: undefined where the cosine in the input gain is zero (the input then has no effect on the angular acceleration). (c) $u = -x^2 - x$ gives $\dot x = \varepsilon x^2 - x$: starts beyond $x = 1/\varepsilon$ (on the side of its sign) escape, for any $\varepsilon \ne 0$.
  3. Ex 7.16 $\ddot x - 2\dot x^2 + x = u - 1$: state form, equilibria for $u = 0$, and a globally stabilizing feedback.
    Hint and answer
    Hint. Use $x_1 = x$, $x_2 = \dot x$. For (c), cancel the nonlinear and constant terms and add linear damping.
    Answer. (a) $\dot x_1 = x_2$, $\dot x_2 = -x_1 + 2x_2^2 + u - 1$. (b) One equilibrium, $(-1, 0)$; its linearization has eigenvalues $\pm j$, so linearization is inconclusive. (c) $u = 1 - 2x_2^2 - 2x_2$ gives $\ddot x + 2\dot x + x = 0$: globally asymptotically stable (double pole at $-1$).
