Notes

Why study nonlinear systems?

A system is linear when it obeys the superposition principle: it is additive (the response to $u_1 + u_2$ is the sum of the separate responses) and homogeneous (the response to $a u$ is $a$ times the response to $u$). Superposition is what makes the linear toolbox so powerful: transfer functions, Bode and Nyquist plots, root locus and the closed-form solution $x(t) = e^{At}x(0)$ all depend on it.

Every practical system is nonlinear to some degree. Often we can describe it by a linear model around an operating point, and that linearized model predicts the behaviour well near that point. But linearization is only a local approximation: it says nothing about what happens far from the operating point, and some behaviour cannot appear in any linear model at all.

  • For linear systems we can usually write the solution in closed form. For nonlinear systems we generally cannot, so we use qualitative analysis: we predict how the system behaves (stable or not, oscillating or not, where it settles) without solving the equations.
  • Unlike the linear case, no single tool works for every nonlinear system. Nonlinear analysis uses several methods, each suited to a class of problems, and needs more mathematics.

Linearization tells you what happens near one operating point. Nonlinear analysis tells you what happens everywhere else, including behaviour that a linear model can never show.

Why nonlinear control?

  1. Improving existing control systems. A linear controller is designed for a small range around one operating point. Over a wide range the unmodelled nonlinearities degrade it. Example: a pendulum $\ddot\theta + \frac{g}{l}\sin\theta = 0$ behaves like $\ddot\theta + \frac{g}{l}\theta = 0$ only for small angles; a nonlinear controller can handle large swings.
  2. Analysis of hard nonlinearities. Linear control assumes the system can be linearized. Hard (discontinuous) nonlinearities such as Coulomb friction $F_f = \mu F_N\,\mathrm{sign}(v)$, saturation, dead zone, backlash and hysteresis cannot be linearized at the discontinuity and can cause limit cycles or loss of stability.
  3. Dealing with model uncertainty. Linear designs need well-known parameters. Robust and adaptive controllers deliberately use nonlinear terms, for example $u = f(x) + \delta$, to cope with parameter variations and uncertainty.
  4. Design simplicity. A design built on the physics of the process can be simpler and more intuitive than a linear design, and it often works over a larger range.

Other reasons: linear models fail over large operating ranges; linearizing at some points gives an inadequate model (for example, linearizing $\dot x = u^3$ at $x = 0$, $u = 0$ gives $\dot x = 0$: the linear model says the input has no effect, although the real system can be driven anywhere); nonlinear controllers can be more robust to large parameter changes.

Features of nonlinear systems

  1. The response to one test signal is no guide to the response to other inputs, because superposition does not hold.
  2. The response can be very sensitive to the input amplitude and the initial conditions. Stability has to be studied together with the type and size of the expected inputs and initial states, not only from the model.
  3. Nonlinear systems can show limit cycles: self-sustained oscillations of fixed amplitude and frequency.
  4. They can show jump resonance in the frequency response.
  5. A sinusoidal input produces harmonics and sub-harmonics at the output.
  6. They show frequency entrainment and asynchronous quenching.

Classification of nonlinearities

By origin:

  • Inherent nonlinearities come from the physics or structure of the system itself: the $\sin\theta$ of a pendulum, the magnetic saturation of a motor, the $\sqrt{h}$ outflow of a tank, nonlinear electronic components, biological systems.
  • Incidental (parasitic) nonlinearities come from imperfections and physical limits rather than from the intended dynamics: friction, backlash in gears, actuator saturation, sensor dead band and noise.
  • Intentional nonlinearities are inserted on purpose to modify the system: relays (on–off control), adaptive control laws, bang–bang optimal control.

By mathematical form:

  1. Memoryless (static): the output depends only on the present input. Relay, saturation, dead zone, quantizer, piecewise-linear gains.
  2. With memory (dynamic): the output depends on past inputs as well. Hysteresis and backlash: the output for a given input depends on whether the input is rising or falling.
  3. Time-varying: the characteristic itself changes with time or with another variable.
  4. Local or global: the nonlinearity matters only in some region of the state space, or everywhere.

A hard nonlinearity has a discontinuity or a corner (relay, saturation, dead zone, backlash); a soft nonlinearity is smooth ($x^3$, $\sin x$) and can be linearized.

Common physical nonlinearities

  • Saturation. The output is proportional to the input over a limited range and then stays nearly constant. Every device saturates when driven hard enough: amplifier outputs, motor speed and torque limits, valve travel, sensor ranges.
  • Dead zone. No output for inputs smaller than a threshold $\delta$; linear beyond it. Examples: a DC motor that does not turn until its torque overcomes static friction, valve-controlled pneumatic and hydraulic actuators, sensors with a dead band.
  • Relay (on–off). The output switches between $+M$ and $-M$ with the sign of the input. Used deliberately in thermostats and simple position controllers. A real relay often has a dead zone and hysteresis: it switches on at $+h$ but back off only at $-h$.
  • Backlash. In a gear train there is a small gap between the teeth of mating gears. When the driving gear reverses, the driven gear does not move until the gap is closed, then follows linearly. With periodic motion the input–output plot is a parallelogram-shaped loop.
  • Friction. Viscous friction is linear (force proportional to velocity). Coulomb friction is a constant force opposing motion. Stiction (static friction) is larger than Coulomb friction: more force is needed to start motion than to keep it going, because surface irregularities interlock. In practice stiction falls off to Coulomb friction at small velocities.

Nonlinear phenomena

The following behaviours can occur only in nonlinear systems.

Finite escape time

The state of an unstable linear system grows to infinity only as $t \to \infty$. A nonlinear system's state can reach infinity in finite time.

Linear: $\dot x = ax$ has the solution $x(t) = x(0)e^{at}$. For $a > 0$ it grows without bound, but $x(t)$ is finite at every finite time. Nonlinear: $\dot x = x^2$ with $x(0) = x_0 > 0$. Separating variables, $\int dx/x^2 = \int dt$ gives

$$x(t) = \frac{x_0}{1 - x_0 t},$$

which reaches infinity at the escape time $t_e = 1/x_0$.

The slides used the logistic equation $\dot x = rx(1 - x/K)$ as the example of finite escape time. That equation does not have one: from any $x(0) > 0$ its solution $x(t) = \dfrac{K}{1 + \left(\frac{K}{x(0)} - 1\right)e^{-rt}}$ stays finite and tends to the carrying capacity $K$, and a population above $K$ decays smoothly to $K$ rather than crashing. The logistic equation is a good example of two equilibria ($x = 0$ unstable, $x = K$ stable); $\dot x = x^2$ above is the standard escape-time example.

Multiple isolated equilibria

A linear system $\dot x = Ax$ with $\det A \neq 0$ has exactly one equilibrium, the origin, and if it is stable it attracts every initial state. A nonlinear system can have several isolated equilibria, and which one the state reaches depends on where it starts.

Example. $\dot x = x - x^3 = x(1 - x)(1 + x)$ has three equilibria, $x = -1, 0, 1$. Where $\dot x > 0$ the state moves right, where $\dot x < 0$ it moves left, so $x = \pm 1$ are stable and $x = 0$ is unstable. From $x(0) = 0.5$ the solution goes to $1$; from $x(0) = -0.5$ it goes to $-1$. Compare $\dot x = -x$: one equilibrium, reached from every start.

Duffing oscillator. $\ddot x + \delta\dot x + \alpha x + \beta x^3 = 0$. With $\alpha < 0$ and $\beta > 0$ (a "double-well" spring) it has three equilibria: $x = 0$ (a saddle) and $x = \pm\sqrt{-\alpha/\beta}$ (stable). The figure uses $\delta = 0.3$, $\alpha = -1$, $\beta = 1$.

Limit cycles

For a linear time-invariant system to oscillate it must have a pair of eigenvalues exactly on the imaginary axis. That condition is not robust: any small perturbation of the parameters destroys it. Even then, the amplitude of the oscillation depends on the initial state.

A nonlinear system can have a limit cycle: an isolated closed trajectory, an oscillation of fixed amplitude and frequency that does not depend on the initial state and survives parameter changes. The Van der Pol oscillator

$$\ddot x - \mu(1 - x^2)\dot x + x = 0, \qquad \mu > 0$$

has damping $-\mu(1 - x^2)$ that is negative for $|x| < 1$ (energy is pumped in) and positive for $|x| > 1$ (energy is removed). Small oscillations grow, large ones shrink, and every trajectory except the origin settles on the same closed curve. Because no input is needed, this is a self-excited or zero-input limit cycle.

Chaos

A nonlinear system can have steady-state behaviour that is neither an equilibrium nor a periodic oscillation nor a quasi-periodic one. In a chaotic system the motion looks random although the equations are fully deterministic, and it depends extremely sensitively on the initial state. The Lorenz equations, a simple model of atmospheric convection,

$$\dot x = \sigma(y - x), \qquad \dot y = x(\rho - z) - y, \qquad \dot z = xy - \beta z,$$

are chaotic for $\sigma = 10$, $\rho = 28$, $\beta = 8/3$: the trajectory never repeats and stays on a "strange attractor". Two starts that differ by $10^{-5}$ soon follow completely different paths (the "butterfly effect").

Multiple modes of behaviour

A nonlinear system can show very different behaviour for different values of a parameter, or jump from one behaviour to another. In a linear system the behaviour is fixed by the eigenvalues of $A$. The logistic map $x_{n+1} = r x_n(1 - x_n)$, a population model, has a stable fixed point for $1 < r < 3$, oscillates with period 2, then 4, 8, … as $r$ grows (period doubling), and becomes chaotic beyond about $r \approx 3.57$. Each change of behaviour at a critical parameter value is a bifurcation.

Frequency–amplitude dependence

In a linear system the frequency of free oscillation does not depend on the amplitude. In a nonlinear system it usually does. Consider a mass on a nonlinear spring,

$$M\ddot x + B\dot x + Kx + K'x^3 = 0,$$

the Duffing equation. $M$, $B$, $K$ are positive. If $K' > 0$ the spring stiffens as it stretches (hard spring); if $K' < 0$ it softens (soft spring). With small damping, the free response is a decaying oscillation whose frequency changes as the amplitude decays:

  • Hard spring ($K' > 0$): larger amplitude means a stiffer spring and a higher frequency, so the frequency decreases as the oscillation dies away, towards $\omega_n = \sqrt{K/M}$.
  • Soft spring ($K' < 0$): larger amplitude means a softer spring and a lower frequency, so the frequency increases as the amplitude decays.
  • Linear spring ($K' = 0$): the frequency stays at $\omega_n$.

The chapter notes state the opposite ("for a hard spring the frequency increases with decreasing amplitude"). The figure and the physical argument above show the correct direction: a hard spring oscillates faster at large amplitude, so its frequency falls as the amplitude decays.

Jump resonance

Now drive the same system with $A\cos\omega t$:

$$M\ddot x + B\dot x + Kx + K'x^3 = A\cos\omega t.$$

Keep $A$ constant, vary $\omega$ slowly and record the output amplitude $X$. For a hard spring the resonance curve bends to the right and, for small damping and large enough forcing, has three possible amplitudes over a band of frequencies. The middle one is unstable.

As $\omega$ increases, $X$ follows the upper branch $1 \to 2$; any further increase makes the amplitude jump down to point 3, and it then follows $3 \to 4$. Coming back from high frequency, $X$ follows the lower branch $4 \to 5$ and then jumps up to point 6 before following $6 \to 1$. This hysteresis in the frequency response is jump resonance. It needs small damping and a forcing large enough to drive the system well into its nonlinear range.

Sub-harmonics, entrainment and quenching

  • Sub-harmonic oscillations. A sinusoidal input of frequency $\omega$ can produce a steady oscillation at $\omega/n$ (an integer sub-multiple of the forcing frequency). Whether it appears depends on the parameters, the initial state, and the amplitude and frequency of the forcing.
  • Frequency entrainment. Take a system with a limit cycle of frequency $\omega_l$ and force it at a nearby frequency $\omega$. In a linear system you would see beats at $|\omega - \omega_l|$, and the beat frequency shrinks steadily as $\omega \to \omega_l$. In a nonlinear system, inside a band of frequencies around $\omega_l$ (the zone of entrainment) the limit cycle locks to the forcing: only one frequency, $\omega$, remains.
  • Asynchronous quenching. Forcing a system that has a limit cycle at a frequency $\omega_q$ unrelated to $\omega_l$ can suppress the limit cycle altogether. This is also called signal stabilization, and it is the idea behind adding a high-frequency "dither" signal to reduce the effect of friction or relay chattering.

Nonlinear state-space models

A nonlinear system with $n$ states and $p$ inputs is written as $n$ first-order equations

$$\dot x_i = f_i(t, x_1, \dots, x_n, u_1, \dots, u_p), \qquad i = 1, \dots, n,$$

or, collecting them into vectors $x \in \mathbb{R}^n$, $u \in \mathbb{R}^p$,

$$\dot x = f(t, x, u), \qquad y = h(t, x, u).$$

  • If $f$ and $h$ do not depend on $t$ explicitly, the system is time-invariant: $\dot x = f(x, u)$, $y = h(x, u)$.
  • If, in addition, there is no input (or the input is fixed by a feedback law $u = \gamma(x)$), the system is autonomous: $\dot x = f(x)$.

Equilibrium (singular) point. For $\dot x = f(x)$, a point $\bar x$ is an equilibrium if $f(\bar x) = 0$. If the state starts there it stays there for all time. Equilibria are where we study stability and long-term behaviour.

To find the equilibria, set every derivative to zero and solve the algebraic equations $f(x) = 0$. A nonlinear system may have none, one, several or infinitely many.

Examples of nonlinear system models

Simple pendulum. A mass $m$ on a light rod of length $l$, with friction coefficient $k$. Newton's law for rotation gives

$$ml\ddot\theta = -mg\sin\theta - kl\dot\theta.$$

With $x_1 = \theta$ and $x_2 = \dot\theta$:

$$\dot x_1 = x_2, \qquad \dot x_2 = -\frac{g}{l}\sin x_1 - \frac{k}{m}x_2.$$

Setting $x_2 = 0$ and $\sin x_1 = 0$ gives the equilibria $(n\pi, 0)$, $n = 0, \pm 1, \dots$: the pendulum hanging down ($n$ even) or balanced upright ($n$ odd). Physically there are only two, since angles differing by $2\pi$ are the same position.

Mass–spring system. A mass $m$ on a linear spring $k$: $m\ddot y = -ky$, so with $x_1 = y$, $x_2 = \dot y$: $\dot x_1 = x_2$, $\dot x_2 = -\frac{k}{m}x_1$. This one is linear, $\dot x = Ax$ with $A = \begin{bmatrix} 0 & 1 \\ -k/m & 0\end{bmatrix}$. Replacing the spring by a hard spring $k y + k' y^3$ makes it the nonlinear Duffing equation above.

Continuous stirred tank reactor. A tank of volume $V$ with feed flow $q$, feed concentration $C_{Af}$ and feed temperature $T_f$, in which reactant A reacts with rate constant $r(T) = k_0e^{-E/(RT)}$, and a cooling jacket at temperature $T_c$:

$$\dot C_A = \frac{q}{V}(C_{Af} - C_A) - k_0e^{-E/(RT)}C_A, \qquad \dot T = \frac{q}{V}(T_f - T) + K_r\,k_0e^{-E/(RT)}C_A - K_c(T - T_c).$$

The states are the concentration $C_A$ and the temperature $T$. The product of $C_A$ with the exponential (Arrhenius) term makes the model strongly nonlinear; such reactors can have several steady states at the same feed conditions.

On the slide the Arrhenius term was written $K\exp(E/RT)$ and the cooling term $+K_c(T - T_c)$. The reaction rate is $k_0e^{-E/(RT)}$ (it increases with temperature), and heat removed by the jacket enters with a minus sign, $-K_c(T - T_c)$ with $K_c > 0$.

Analysing nonlinear systems

A sensible workflow:

  1. Theoretical analysis first: equilibria, local stability, possible oscillations.
  2. Simulation guided by the theory. Blind simulation can mislead: you only see the initial states and parameter values you happened to try.
  3. Control design, then improve it using the insight from the analysis if the performance is not good enough.

The main analysis methods in this course:

  • Phase plane analysis (Lesson 2): a graphical method for second-order systems.
  • Linearization (Lesson 3): local behaviour near an equilibrium.
  • Describing function method (Lesson 4): predicts limit cycles in feedback loops with one nonlinearity.
  • Lyapunov's methods (Lesson 5): stability without solving the equations.
  • Absolute stability: circle and Popov criteria (Lesson 6).

Exercises

  1. Show that $y = x^2$ is not linear by testing additivity and homogeneity.
    Show solution
    Additivity: the response to $x_1 + x_2$ is $(x_1 + x_2)^2 = x_1^2 + 2x_1x_2 + x_2^2$, which differs from $x_1^2 + x_2^2$ by $2x_1x_2$. Homogeneity: the response to $ax$ is $a^2x^2 \neq a x^2$ unless $a = 0$ or $1$. Both fail, so the system is nonlinear.
  2. Find the escape time of $\dot x = x^2$ from $x(0) = 2$, and describe the solution from $x(0) = -2$.
    Show solution
    $x(t) = \dfrac{x_0}{1 - x_0t}$. For $x_0 = 2$: $x(t) = \dfrac{2}{1 - 2t}$, which escapes at $t_e = 1/2$. For $x_0 = -2$: $x(t) = \dfrac{-2}{1 + 2t}$, which stays finite and tends to $0$ as $t \to \infty$. Finite escape depends on the initial state.
  3. Find and classify the equilibria of the logistic equation $\dot x = rx(1 - x/K)$ with $r, K > 0$.
    Show solution
    $\dot x = 0$ at $x = 0$ and $x = K$. Near $x = 0$, $\dot x \approx rx$, so small populations grow: unstable. Near $x = K$, put $x = K + \xi$: $\dot\xi \approx -r\xi$, stable. Every positive start converges to $K$ without escaping.
  4. Write the state equations of $\ddot y + 2\dot y + y + y^3 = u$ and find its equilibria for a constant input $u = 2$.
    Show solution
    With $x_1 = y$, $x_2 = \dot y$: $\dot x_1 = x_2$, $\dot x_2 = -x_1 - x_1^3 - 2x_2 + u$. At equilibrium $x_2 = 0$ and $x_1 + x_1^3 = 2$, whose only real root is $x_1 = 1$. Equilibrium: $(1, 0)$.
  5. For the pendulum $\dot x_1 = x_2$, $\dot x_2 = -\sin x_1 - 0.5x_2$, list all equilibria and say which are physically the same.
    Show solution
    $x_2 = 0$ and $\sin x_1 = 0$, so $(n\pi, 0)$ for every integer $n$. Even $n$ ($0, \pm 2\pi, \dots$) are the hanging position; odd $n$ ($\pm\pi, \pm 3\pi, \dots$) are the inverted position. There are two physically distinct equilibria.
  6. The Van der Pol damping term is $-\mu(1 - x^2)\dot x$. Using the energy $E = \tfrac12(x^2 + \dot x^2)$, show why small oscillations grow and large ones shrink.
    Show solution
    $\dot E = x\dot x + \dot x\ddot x = x\dot x + \dot x\left(\mu(1 - x^2)\dot x - x\right) = \mu(1 - x^2)\dot x^2$. If $|x| < 1$ throughout a cycle, $\dot E \ge 0$: energy grows. If $|x| > 1$ for most of the cycle, $\dot E$ is mostly negative: energy shrinks. The amplitude settles where the energy gained and lost over one cycle balance, which is the limit cycle.
  7. Classify each as memoryless or with memory, and hard or soft: (a) $y = \tanh x$, (b) backlash, (c) a relay with hysteresis, (d) a quantizer.
    Show solution
    (a) memoryless, soft (smooth). (b) with memory, hard. (c) with memory, hard. (d) memoryless, hard (discontinuous steps).

Practice problems from the exercise compendium

From Exercises in Nonlinear Control Systems by M. Johansson, B. Bernhardsson and K. H. Johansson (Department of Automatic Control, Lund University), Chapter 1 (Nonlinear Models and Simulation). “Ex 1.3” means Chapter 1, Exercise 3. Work from the compendium statement and figure. The hints and short answers here are written for this course; full solutions are not reproduced.

  1. Ex 1.1 Pendulum $ml\ddot\theta = -mg\sin\theta - kl\dot\theta$: choose states, find all equilibria and decide their local stability by linearization.
    Hint and answer
    Hint. Use $x_1 = \theta$, $x_2 = \dot\theta$. The Jacobian of $-\frac{g}{l}\sin x_1$ is $-\frac{g}{l}\cos x_1$.
    Answer. $\dot x_1 = x_2$, $\dot x_2 = -\frac{g}{l}\sin x_1 - \frac{k}{m}x_2$. Equilibria $(n\pi, 0)$. At even $n$: $A = \begin{bmatrix}0&1\\-g/l&-k/m\end{bmatrix}$, asymptotically stable for $k > 0$. At odd $n$: $A = \begin{bmatrix}0&1\\g/l&-k/m\end{bmatrix}$, $\det A < 0$, a saddle (unstable).
  2. Ex 1.2 Flexible single-link manipulator: choose states and write the state equations.
    Hint and answer
    Hint. Two second-order equations need four states: both angles and both angular velocities.
    Answer. $x = (q_1, \dot q_1, q_2, \dot q_2)$: $\dot x_1 = x_2$, $\dot x_2 = -\frac{M}{I}\sin x_1 - \frac{k}{I}(x_1 - x_3)$, $\dot x_3 = x_4$, $\dot x_4 = \frac{k}{J}(x_1 - x_3) + \frac{1}{J}u$.
  3. Ex 1.3 Synchronous generator on an infinite bus: (a) state equation with $E_{FD}$ as input, (b) reduce it when $E_q$ is constant, (c) find the equilibria of the reduced model.
    Hint and answer
    Hint. (b) With $E_q$ constant the first equation alone is a forced pendulum. (c) Set $\dot\delta = 0$ and solve $\sin\delta = P/(\eta_1E_q)$.
    Answer. (a) $\dot x_1 = x_2$, $\dot x_2 = \frac{1}{M}\left(P - Dx_2 - \eta_1x_3\sin x_1\right)$, $\dot x_3 = \frac{1}{\tau}\left(-\eta_2x_3 + \eta_3\cos x_1 + E_{FD}\right)$. (b) $M\ddot\delta + D\dot\delta + \eta_1E_q\sin\delta = P$: a pendulum with constant input torque $P$. (c) $\delta = \arcsin\frac{P}{\eta_1E_q} + 2n\pi$ or $\pi - \arcsin\frac{P}{\eta_1E_q} + 2n\pi$, $\dot\delta = 0$; they exist only if $|P| \le \eta_1E_q$.
  4. Ex 1.5 Phase-locked loop with $\sin(\cdot)$ and $G(s) = C(sI - A)^{-1}B$: (b) find the equilibria, (c) when does it match the pendulum model for $G(s) = 1/(\tau s + 1)$?
    Hint and answer
    Hint. (b) At equilibrium $z = -A^{-1}B\sin e$ and $Cz = 0$; recall $G(0) = -CA^{-1}B$. (c) Eliminate $z$ to get one second-order equation in $e$.
    Answer. (b) $G(0)\sin e = 0$ with $G(0) \neq 0$, so $e = n\pi$, $z = 0$. (c) $\tau\ddot e + \dot e + \sin e = 0$. It matches $\ddot\theta + \frac{k}{m}\dot\theta + \frac{g}{l}\sin\theta = 0$ when $\frac{k}{m} = \frac{g}{l} = \frac{1}{\tau}$.
  5. Ex 1.8 Motor ($1/s$), valve $f(x) = x^2$ and process $1/(s + 1)^2$ in a unit feedback loop: (a) state equations, (b) for which constant $r > 0$ is there a locally stable equilibrium?
    Hint and answer
    Hint. Let $x_1$ be the motor output, and $x_2$, $x_3$ the two first-order process states. Linearize at $x_1 = \sqrt r$ and use the Routh test on the third-order characteristic polynomial.
    Answer. (a) $\dot x_1 = r - x_3$, $\dot x_2 = -x_2 + x_1^2$, $\dot x_3 = -x_3 + x_2$, $y = x_3$. (b) Equilibrium $x_1 = \sqrt r$, $x_2 = x_3 = r$; characteristic polynomial $s^3 + 2s^2 + s + 2\sqrt r$, stable if $0 < 2\sqrt r < 2$, so $0 < r < 1$. (c) A real valve passes no negative flow: $f(x) = 0$ for $x < 0$.
  6. Ex 1.15 Two tanks in series with $\dot h = (u - q)/A$, $q = a\sqrt{2gh}$: find the inflow that gives $h_1 = h_2 = 0.1$ m, and linearize there ($A = 3\times10^{-3}$, $a = 7\times10^{-6}$).
    Hint and answer
    Hint. At steady state $u = q = a\sqrt{2gh}$. The derivative of $a\sqrt{2gh}$ with respect to $h$ is $a\sqrt{2g}/(2\sqrt h)$.
    Answer. $u_0 = 9.8\times10^{-6}$ m³/s. With $k = \frac{a\sqrt{2g}}{2A\sqrt{h_0}} \approx 0.0163$ s⁻¹: $\Delta\dot h_1 = -k\Delta h_1 + \frac{1}{A}\Delta u$, $\Delta\dot h_2 = k\Delta h_1 - k\Delta h_2$ (time constant about 61 s per tank). The process is not linear: filling and emptying responses are not mirror images because outflow grows like $\sqrt h$.
  7. Ex 1.17 Lorenz equations: (a) all equilibria, (b) when is the origin locally asymptotically stable?
    Hint and answer
    Hint. From $\dot x_1 = 0$, $x_1 = x_2$. Then either $x_1 = 0$ or $x_3 = r - 1$. The linearization at the origin splits into a $2\times2$ block and $-b$.
    Answer. (a) The origin, and for $r > 1$ also $\left(\pm\sqrt{b(r - 1)}, \pm\sqrt{b(r - 1)}, r - 1\right)$. (b) Eigenvalues $-b$ and the roots of $s^2 + (\sigma + 1)s + \sigma(1 - r)$: locally asymptotically stable if $r < 1$.
