Notes

Translational elements

ElementForceLaplace form
Mass $M$$M\,\ddot x$$Ms^2X(s)$
Damper $B$$B\,\dot x$$BsX(s)$
Spring $K$$Kx$$KX(s)$

For a damper or spring between two masses, use the relative motion: $B(\dot x_1 - \dot x_2)$ and $K(x_1 - x_2)$ on mass 1, and the opposite sign on mass 2.

Method (D'Alembert's principle)

  1. Draw a free-body diagram for each mass (node), with the inertial force $M\ddot x$ opposing positive motion.
  2. Write the force balance: sum of opposing forces = applied force.
  3. Take Laplace transforms with zero initial conditions.
  4. Solve the simultaneous equations for the output you want.

A quick check: in the $s$-domain each equation reads (sum of impedances on this mass) × $X_k$ − (impedances shared with the other mass) × $X_j$ = applied force, just like mesh analysis.

Worked example 1: single mass–spring–damper

$$M\ddot x + B\dot x + Kx = f(t) \quad\Rightarrow\quad \frac{X(s)}{F(s)} = \frac{1}{Ms^2 + Bs + K}$$

In the mass–spring–damper animation, set damping to zero for undamped oscillation, then raise it until the mass returns without overshoot: critical damping is $B = 2\sqrt{MK}$.

Worked example 2: two masses coupled by a spring and a damper

$M_1$ is tied to the wall by $K_1$ and $B_1$, coupled to $M_2$ by $K$ and $B$; $M_2$ has friction $B_2$ and is pushed by $f(t)$. Find $X(s)/F(s)$ for the displacement $x$ of $M_2$.

Node 1: $M_1\ddot x_1 + B_1\dot x_1 + B(\dot x_1 - \dot x) + K_1x_1 + K(x_1 - x) = 0$

Node 2: $M_2\ddot x + B_2\dot x + B(\dot x - \dot x_1) + K(x - x_1) = f(t)$

$$\begin{aligned}\left[M_1s^2 + (B + B_1)s + (K_1 + K)\right]X_1 - (Bs + K)X &= 0\\ -(Bs + K)X_1 + \left[M_2s^2 + (B + B_2)s + K\right]X &= F\end{aligned}$$

From the first equation $X_1 = \dfrac{Bs + K}{M_1s^2 + (B + B_1)s + (K_1 + K)}X$. Substituting and clearing the denominator:

$$\frac{X(s)}{F(s)} = \frac{M_1s^2 + (B + B_1)s + (K_1 + K)}{\left[M_1s^2 + (B + B_1)s + (K_1 + K)\right]\left[M_2s^2 + (B + B_2)s + K\right] - (Bs + K)^2}$$

This is the system in the two-mass simulation. Press Play: $M_2$ moves first and drags $M_1$ through the coupling. Make $K$ very stiff and the two masses move almost as one.

Worked example 3: vertical two-mass system

$M_1$ hangs from $K_1$ with damper $B$ and carries force $f(t)$; $M_2$ hangs from $M_1$ by spring $K_2$. Find $Y_2(s)/F(s)$.

Node 1: $M_1\ddot y_1 + B\dot y_1 + K_1y_1 + K_2(y_1 - y_2) = f(t)$. Node 2: $M_2\ddot y_2 + K_2(y_2 - y_1) = 0$.

From node 2, $Y_1 = \dfrac{M_2s^2 + K_2}{K_2}Y_2$. Substituting into node 1:

$$\frac{Y_2(s)}{F(s)} = \frac{K_2}{\left[M_1s^2 + Bs + (K_1 + K_2)\right](M_2s^2 + K_2) - K_2^2}$$

Worked example 4: masses coupled only by a damper

$M_1$ (with $B_1$, $K_1$ to ground) carries $f(t)$; $M_2$ (with $B_2$, $K_2$ to ground) is linked to $M_1$ by damper $B_{12}$. Find $X_1/F$ and $X_2/F$.

$$\begin{aligned}\left[M_1s^2 + (B_1 + B_{12})s + K_1\right]X_1 - B_{12}sX_2 &= F\\ -B_{12}sX_1 + \left[M_2s^2 + (B_2 + B_{12})s + K_2\right]X_2 &= 0\end{aligned}$$

With the determinant

$$\Delta = \left[M_1s^2 + (B_1 + B_{12})s + K_1\right]\left[M_2s^2 + (B_2 + B_{12})s + K_2\right] - (B_{12}s)^2$$

$$\frac{X_1(s)}{F(s)} = \frac{M_2s^2 + (B_2 + B_{12})s + K_2}{\Delta}, \qquad \frac{X_2(s)}{F(s)} = \frac{B_{12}s}{\Delta}$$

Note the $s$ in the numerator of $X_2/F$: a damper passes on only changes, so in steady state $M_2$ returns to rest.

Rotational systems and analogies

Inertia $J\ddot\theta$, rotational damping $B\dot\theta$ and torsional spring $K\theta$ play the same roles, with torque in place of force.

So the single mass–spring–damper behaves exactly like the series RLC circuit of Lesson 3.

Real-world examples

Car suspension

Each wheel of a car is a mass–spring–damper: the coil spring is $K$, the shock absorber is $B$ and a quarter of the car body is $M$. Engineers model the body and the wheel as two masses (a quarter-car model, much like worked example 2) to trade comfort against road grip.

Door closer

A hydraulic door closer is a spring with a damper. It is set close to critical damping, $B \approx 2\sqrt{MK}$, so the door shuts quickly without slamming or bouncing.

Washing machine and machine mounts

The drum of a washing machine hangs on springs with friction dampers. Motors, pumps and generators sit on rubber mounts for the same reason: to stop vibration reaching the floor.

Tall buildings and bridges

Some skyscrapers carry a very large tuned mass damper near the top: a heavy mass on springs and dampers that swings against the building and reduces sway in wind and earthquakes. It is a two-mass system like worked example 2.

Measuring instruments

The pointer of a moving-coil meter and the sensing mass of an accelerometer are mass–spring–damper systems. They are designed with a damping ratio near 0.6 to 0.7 so the reading settles fast with little overshoot.

Exercises

  1. In worked example 2, find the steady-state displacements for a constant force $F_0$.
    Show solution
    Set $s = 0$: $X/F = (K_1 + K)/((K_1 + K)K - K^2) = (K_1 + K)/(K_1K)$, so $x = F_0/K_1 + F_0/K$, and $x_1 = F_0/K_1$. The two-mass simulation shows these values in its readout.
  2. For $M = 1$ kg and $K = 10$ N/m, what damping gives critical damping?
    Show solution
    $B = 2\sqrt{MK} = 2\sqrt{10} = 6.32$ N·s/m.
  3. In worked example 4, what is the final value of $x_2(t)$ for a step force?
    Show solution
    $\lim_{s\to0} s\cdot\frac{B_{12}s}{\Delta}\cdot\frac{F_0}{s} = 0$: $M_2$ returns to its starting position, since a damper carries no force at rest.
  4. Write the force–voltage analogous circuit of $M\ddot x + B\dot x + Kx = f$.
    Show solution
    A series RLC circuit with $L = M$, $R = B$, $C = 1/K$, driven by voltage $v = f$; the loop charge $q$ plays the role of $x$.

Practice problems from the textbook

From the end-of-chapter Problems in N. S. Nise, Control Systems Engineering, 7th ed. (Hoboken, NJ: John Wiley & Sons, 2015), Chapter 2 (Modeling in the Frequency Domain). “Nise 4.24” means Chapter 4, Problem 24; § is the textbook section the problem practises. Work from the textbook statement and figure. The hints and short answers here are written for this course; full solutions are not reproduced.

  1. Nise 2.24 §2.5 Find $X_1(s)/F(s)$ for the translational system in Figure P2.9.
    Hint
    Hint. Draw the free-body diagram of each mass. One equation per independent motion.
  2. Nise 2.25 §2.5 Find $X_2(s)/F(s)$ for the two-mass system in Figure P2.10.
    Hint
    Hint. Write the equations in the "sum of impedances connected to the mass × its displacement − shared impedances × other displacement = applied force" pattern, then use Cramer's rule.
  3. Nise 2.27 §2.5 Find $X_1(s)/F(s)$ for the system in Figure P2.12.
    Hint
    Hint. Count the independent displacements first. Each one gives one equation of motion.
  4. Nise 2.33 §2.6 Find $\theta_2(s)/T(s)$ for the rotational system in Figure P2.18.
    Hint
    Hint. Same pattern as translation, with inertia $Js^2$, damping $Ds$ and stiffness $K$.
  5. Nise 2.39 §2.7 Find $\theta_L(s)/T(s)$ for a rotational system with gears (Figure P2.24).
    Hint
    Hint. Reflect impedances through the gears: multiply by $(N_\text{dest}/N_\text{source})^2$, and reflect the torque by $N_\text{dest}/N_\text{source}$.
  6. Nise 2.47 §2.8 Find $\theta_L(s)/E_a(s)$ for a dc motor described by its torque–speed numbers and driving a load through gears.
    Hint and answer
    Hint. The torque–speed line goes through (0, 100 N·m) and (600 rad/s, 55 N·m). Use the stall torque for $K_t/R_a$ and the no-load speed for $K_b$, then reflect the load inertia and damping to the motor shaft.
    Answer. Part answer: no-load speed = 100/(45/600) ≈ 1333 rad/s, so $K_t/R_a = 100/12 = 8.33$ N·m/V and $K_b = 12/1333 = 0.009$ V·s/rad.
  7. Nise 2.50 §2.9 Find the series and parallel electrical analogs of the translational system of Figure 2.20 in the text.
    Hint
    Hint. Series analog: mass → inductor, damper → resistor, spring → capacitor (1/K), force → voltage. Parallel analog: mass → capacitor, damper → conductance, spring → inductor, force → current.
