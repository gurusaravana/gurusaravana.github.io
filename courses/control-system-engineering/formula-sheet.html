Laplace theorems L2

  • Time shift: $f(t-T)u(t-T) \to e^{-sT}F(s)$; scaling: $f(at) \to \frac1aF\!\left(\frac sa\right)$
  • $\dfrac{df}{dt} \to sF(s) - f(0^-)$; $\;\dfrac{d^2f}{dt^2} \to s^2F(s) - sf(0^-) - f'(0^-)$
  • $\int_{0^-}^t f(\tau)\,d\tau \to F(s)/s$
  • Initial value: $f(0^+) = \lim_{s\to\infty} sF(s)$
  • Final value: $f(\infty) = \lim_{s\to0} sF(s)$ (stable systems only)

Partial fractions L2

Distinct roots: $K_i = \lim_{s\to-p_i}(s+p_i)F(s)$

Root $-p_1$ repeated $r$ times:

$$K_i = \frac{1}{(i-1)!}\lim_{s\to-p_1}\frac{d^{\,i-1}}{ds^{\,i-1}}\left[(s+p_1)^rF(s)\right]$$

Complex pair: $\dfrac{K_2s + K_3}{s^2+as+b}$, inverts to $Ce^{-\alpha t}\cos(\beta t - \phi)$. If $\deg N \ge \deg D$, divide first.

Block diagrams L5

$$T(s) = \frac{C(s)}{R(s)} = \frac{G(s)}{1 \pm G(s)H(s)}$$

$+$ for negative feedback, $-$ for positive feedback.

  • Series: $G_1G_2$; parallel: $G_1 \pm G_2$
  • Take-off point moved after $G$: put $1/G$ in the branch; moved before $G$: put $G$
  • Summing point moved after $G$: put $G$ in the added input; moved before $G$: put $1/G$
  • Two inputs: $C(s) = C_R(s) + C_D(s)$ (one input at a time, the other set to 0)

Mason's gain formula L6

$$T = \frac{C(s)}{R(s)} = \frac{1}{\Delta}\sum_k P_k\Delta_k$$

$$\Delta = 1 - \sum L_i + \sum L_iL_j - \sum L_iL_jL_k + \dots$$

$P_k$: gain of forward path $k$. $L_iL_j$: pairs of non-touching loops. $\Delta_k$: $\Delta$ with the loops touching path $k$ removed ($\Delta_k = 1$ if every loop touches it).

First-order system L7

$\dfrac{C(s)}{R(s)} = \dfrac{a}{s + a}$, unit step: $c(t) = 1 - e^{-at}$

  • Time constant $\tau = 1/a$ (63.2 % of final value)
  • Rise time (10–90 %) $T_r = 2.2/a = 2.2\tau$
  • Settling time $T_s = 4/a = 4\tau$ (2 %), $3\tau$ (5 %)
  • Unit ramp: $c(t) = t - \tau + \tau e^{-t/\tau}$, error $= \tau$

3 Stability analysis

Routh–Hurwitz L11

For $a_0s^n + a_1s^{n-1} + \dots + a_n = 0$, rows 1–2 from alternate coefficients, then

$$b_1 = \frac{a_1a_2 - a_0a_3}{a_1},\qquad b_2 = \frac{a_1a_4 - a_0a_5}{a_1}$$

  • Sign changes in column 1 = number of RHP poles
  • Missing or mixed-sign coefficient: not stable
  • Zero in column 1 only: replace with $\varepsilon \to 0^+$
  • Row of zeros: auxiliary $A(s)$ from the row above, use $dA/ds$; roots of $A(s)$ are system roots
  • Range of $K$: all column-1 entries $> 0$; $A(s) = 0$ at $K_{cr}$ gives $\omega$

Root locus: conditions L12

$1 + KG(s)H(s) = 0 \;\Leftrightarrow\; D(s) + KN(s) = 0$

  • Angle: $\angle G(s)H(s) = \pm180°(2q + 1)$
  • Magnitude: $K = 1/|G(s)H(s)|$, or $K = -D(s)/N(s)$
  • $n$ poles, $m$ zeros, $q = n - m$ branches to infinity
  • $j\omega$ crossing: Routh, or put $s = j\omega$ and set real and imaginary parts to 0
  • Other parameter $\alpha$: write $1 + \alpha G_{eq}(s) = 0$

Root locus: sketching rules ($K \ge 0$) L12

  • $n$ branches, symmetric about the real axis, from poles ($K = 0$) to zeros ($K \to \infty$)
  • Real axis: on the locus if an odd number of real poles + zeros lie to the right
  • Centroid $\sigma_A = \dfrac{\sum p_i - \sum z_i}{q}$, angles $\theta = \dfrac{r\cdot180°}{q}$, $r = 1, 3, 5,\dots$
  • Break-away / break-in: $N(s)D'(s) - N'(s)D(s) = 0$ ($dK/ds = 0$)
  • Departure: $\theta_{dep} = 180° + \sum\angle(p_j - z_i) - \sum_{i\ne j}\angle(p_j - p_i)$
  • Arrival: $\theta_{arr} = 180° - \sum_{i\ne j}\angle(z_j - z_i) + \sum\angle(z_j - p_i)$
  • $K \le 0$: even count on real axis, $r = 0, 2, 4,\dots$, drop the 180°
  • Constant-$\zeta$ line at $\theta = \cos^{-1}\zeta$ from the negative real axis

Frequency response and margins L13

Put $s = j\omega$. $\;|G|_{\text{dB}} = 20\log_{10}|G|$. Closed loop $M(j\omega) = \dfrac{G(j\omega)}{1 + G(j\omega)H(j\omega)}$.

  • Gain margin $K_g = \dfrac{1}{|GH(j\omega_{pc})|}$, in dB $-20\log_{10}|GH(j\omega_{pc})|$, where $\angle GH(j\omega_{pc}) = -180°$
  • Phase margin $\gamma = 180° + \angle GH(j\omega_{gc})$, where $|GH(j\omega_{gc})| = 1$ (0 dB)
  • Minimum phase: both margins positive → stable. Typical: $\gamma$ 30°–60°, GM > 6 dB
  • Rule of thumb: $\zeta \approx \gamma/100$ (for $\gamma$ below about 70°)
  • Bandwidth $\omega_b$: $|M|$ falls to 0.707 (−3 dB)

Second-order frequency specs L13

Loop $G = \dfrac{\omega_n^2}{s(s + 2\zeta\omega_n)}$, unity feedback, $u = \omega/\omega_n$:

$$M_r = \frac{1}{2\zeta\sqrt{1 - \zeta^2}},\qquad \omega_r = \omega_n\sqrt{1 - 2\zeta^2}\quad(\zeta \le 0.707)$$

$$\omega_b = \omega_n\left[1 - 2\zeta^2 + \sqrt{2 - 4\zeta^2 + 4\zeta^4}\right]^{1/2}$$

$$\gamma = 90° - \tan^{-1}\frac{u_{gc}}{2\zeta},\qquad u_{gc} = \left[\sqrt{4\zeta^4 + 1} - 2\zeta^2\right]^{1/2}$$

For $\zeta > 0.707$: no peak, $M_r = 1$.

Nyquist criterion L14

$$Z = N + P$$

  • $P$: open-loop RHP poles; $N$: clockwise encirclements of $-1 + j0$; $Z$: closed-loop RHP poles
  • Stable if and only if $Z = 0$; for $P = 0$, no encirclement of $-1$
  • Crossing the negative real axis at $-a$: GM $= 1/a$
  • PM: angle from the negative real axis to the unit-circle crossing

Lead and lag compensation L15

$G_c(s) = K_c\dfrac{s + z}{s + p}$: lead if $z < p$ (like PD), lag if $z > p$ (like PI)

Lead, $\alpha = z/p < 1$: $\;\phi_m = \sin^{-1}\dfrac{1 - \alpha}{1 + \alpha}$ at $\omega_m = \sqrt{zp}$

Required lead $\phi_m$ = desired PM − existing PM + 5° to 12°. Place $\omega_m$ where the uncompensated gain is $-10\log(1/\alpha)$ dB.

4 State space analysis

State model L16

$$\dot{\mathbf x} = A\mathbf x + B\mathbf u, \qquad \mathbf y = C\mathbf x + D\mathbf u$$

Phase variables for $\overset{...}{y} + a_2\ddot y + a_1\dot y + a_0y = u$:

$$A = \begin{bmatrix}0&1&0\\0&0&1\\-a_0&-a_1&-a_2\end{bmatrix},\ B = \begin{bmatrix}0\\0\\1\end{bmatrix},\ C = \begin{bmatrix}1&0&0\end{bmatrix}$$

$G(s) = C(sI - A)^{-1}B + D$; poles = eigenvalues of $A$, roots of $|sI - A| = 0$. Circuits: capacitor voltages and inductor currents as states.

Solution of the state equation L17

$$\phi(t) = e^{At} = \mathcal L^{-1}\left[(sI - A)^{-1}\right]$$

$$\mathbf x(t) = \phi(t)\mathbf x(0) + \int_0^t \phi(t - \tau)B\mathbf u(\tau)\,d\tau$$

Zero-input + zero-state response. $\phi(0) = I$, $\;\phi^{-1}(t) = \phi(-t)$, $\;\phi(t_1 + t_2) = \phi(t_1)\phi(t_2)$.

Controllability and observability L18

$Q_c = \begin{bmatrix}B & AB & \cdots & A^{n-1}B\end{bmatrix}$, controllable if $\text{rank}(Q_c) = n$

$Q_o = \begin{bmatrix}C \\ CA \\ \vdots \\ CA^{n-1}\end{bmatrix}$, observable if $\text{rank}(Q_o) = n$

Single input or output: $\det \ne 0$. A pole–zero cancellation hides an uncontrollable or unobservable mode.

Watch out in the exam

  • Check stability before using the final value theorem.
  • $t_r$, $t_p$ and $M_p$ formulas need $0 < \zeta < 1$.
  • $K_p$ means the proportional gain in Lesson 10 but the position error constant in Lesson 9.
  • Bode sketches use asymptotes; say if you corrected by 3 dB at a corner.
  • Use $\theta = \cos^{-1}\zeta$ in radians inside $t_r$.
  • Nonlinear systems (L19): superposition fails; linear methods hold only near an operating point.
