By the end of this lesson you can

  • Define state, state variables and the state model
  • Write state models from differential equations and circuits
  • Convert between state space and transfer function

Notes

The state is the smallest set of variables that, with the input, fully determines the future behaviour. A linear time-invariant state model is

$$\dot{\mathbf x} = A\mathbf x + B\mathbf u, \qquad \mathbf y = C\mathbf x + D\mathbf u$$

From a differential equation (phase variables)

For $\dddot y + a_2\ddot y + a_1\dot y + a_0y = u$, choose $x_1 = y$, $x_2 = \dot y$, $x_3 = \ddot y$:

$$A = \begin{bmatrix}0&1&0\\0&0&1\\-a_0&-a_1&-a_2\end{bmatrix},\ B = \begin{bmatrix}0\\0\\1\end{bmatrix},\ C = \begin{bmatrix}1&0&0\end{bmatrix}$$

From a circuit

Choose capacitor voltages and inductor currents as state variables, since they describe the stored energy.

State space to transfer function

$$G(s) = C(sI - A)^{-1}B + D$$

The eigenvalues of $A$ (roots of $|sI - A| = 0$) are the poles of the system.

Exercises

  1. Write a state model for $\ddot y + 3\dot y + 2y = u$.
    Show solution
    $x_1 = y$, $x_2 = \dot y$: $A = \begin{bmatrix}0&1\\-2&-3\end{bmatrix}$, $B = \begin{bmatrix}0\\1\end{bmatrix}$, $C = [1\ 0]$.
  2. Find $G(s)$ for that model.
    Show solution
    $G(s) = 1/(s^2 + 3s + 2)$.
  3. What are the eigenvalues of $A$ in Exercise 1?
    Show solution
    $s^2 + 3s + 2 = 0$: $-1$ and $-2$, the system poles.
