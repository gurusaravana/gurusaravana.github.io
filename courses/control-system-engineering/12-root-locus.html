Notes

Consider a loop with an adjustable gain $K$ in the forward path, plant $G(s)$ and feedback $H(s)$. The closed-loop transfer function is $T(s) = \dfrac{KG(s)}{1 + KG(s)H(s)}$, so the characteristic equation is

$$1 + KG(s)H(s) = 1 + K\frac{N(s)}{D(s)} = 0 \qquad\Longleftrightarrow\qquad D(s) + K\,N(s) = 0$$

As $K$ changes, the closed-loop poles move. The root locus is the path they trace as $K$ goes from 0 to $\infty$. A point $s$ is on the locus when the angle condition $\angle G(s)H(s) = \pm180°(2q + 1)$ holds; the gain there follows from the magnitude condition $K = 1/|G(s)H(s)|$.

Rules for sketching the root locus ($K \ge 0$)

RuleWhat to do
DefinitionsThe loop gain is $KN(s)/D(s)$. $N(s)$ has order $m$ with zeros $z_i$; $D(s)$ has order $n$ with poles $p_i$. Let $q = n - m \ge 0$.
SymmetryThe locus is symmetric about the real axis (complex poles come in conjugate pairs).
Number of branchesThere are $n$ branches, one for each closed-loop pole.
Start and end pointsBranches start ($K = 0$) at the open-loop poles and end ($K \to \infty$) at the open-loop zeros. The remaining $q$ branches go to infinity.
Locus on the real axisA real-axis point is on the locus if the total number of real poles and zeros to its right is odd.
AsymptotesThe $q$ branches that go to infinity follow straight lines from the centroid $\sigma_A = \dfrac{\sum p_i - \sum z_i}{q}$ at angles $\theta = \dfrac{r \cdot 180°}{q}$, $r = 1, 3, 5, \dots$
Break-away and break-in pointsOn the real axis, where $N(s)D'(s) - N'(s)D(s) = 0$ (the same as $dK/ds = 0$).
Angle of departure from a complex pole $p_j$$\theta_{dep} = 180° + \sum_i \angle(p_j - z_i) - \sum_{i \ne j}\angle(p_j - p_i)$
Angle of arrival at a complex zero $z_j$$\theta_{arr} = 180° - \sum_{i \ne j}\angle(z_j - z_i) + \sum_i \angle(z_j - p_i)$
Crossing the imaginary axisUse the Routh array (Lesson 11) to find the marginal $K$ and the crossing frequency.
Poles for a given $K$Put the value of $K$ into $D(s) + KN(s) = 0$ and find the roots (a computer may be needed).
$K$ for a given poleWrite $K = -D(s)/N(s)$ and substitute the pole location. If the point is not exactly on the locus, $K$ comes out slightly complex: use its real part.

Complementary root locus ($K \le 0$)

For negative $K$ (positive feedback), most rules are unchanged. These change:

  • Real axis: the locus is to the left of an even number of real poles and zeros (that is, to the right of an odd number).
  • Asymptote angles: $\theta = \dfrac{r \cdot 180°}{q}$ with $r = 0, 2, 4, \dots$ (same centroid).
  • Angle of departure: $\theta_{dep} = \sum_i \angle(p_j - z_i) - \sum_{i \ne j}\angle(p_j - p_i)$; angle of arrival: $\theta_{arr} = \sum_i \angle(z_j - p_i) - \sum_{i \ne j}\angle(z_j - z_i)$ (the 180° is dropped).

Worked example 1: three real poles

$KG(s)H(s) = \dfrac{K}{s(s + 1)(s + 5)}$ (the same plant as the Ziegler–Nichols example in Lesson 10).

  1. Poles at $0, -1, -5$; no zeros. $n = 3$, $m = 0$, $q = 3$ branches go to infinity.
  2. Real axis: the locus lies on $[-1, 0]$ and $(-\infty, -5]$.
  3. Asymptotes: $\sigma_A = \dfrac{0 - 1 - 5}{3} = -2$, angles $60°$, $180°$, $300°$.
  4. Break-away: $K = -(s^3 + 6s^2 + 5s)$, $dK/ds = -(3s^2 + 12s + 5) = 0 \Rightarrow s = -0.47$ (the other root, $-3.53$, is not on the locus). There $K = 1.13$.
  5. Imaginary-axis crossing: $s^3 + 6s^2 + 5s + K = 0$ gives $K = 30$ and $\omega = \sqrt5 = 2.24$ rad/s. For $K > 30$ the system is unstable.

Worked example 2: complex poles and a zero

$KG(s)H(s) = \dfrac{K(s + 2)}{s^2 + 2s + 2}$: poles at $-1 \pm j$, zero at $-2$.

  1. Two branches. One ends at the zero $-2$; $q = 1$, so the other goes to $-\infty$ along the negative real axis.
  2. Real axis: the locus lies on $(-\infty, -2]$.
  3. Departure from $p_1 = -1 + j$: the angle from the zero is $\angle(p_1 + 2) = \angle(1 + j) = 45°$; the angle from the other pole is $\angle(p_1 - p_2) = \angle(2j) = 90°$. So $\theta_{dep} = 180° + 45° - 90° = 135°$.
  4. Break-in: $N'D - ND' = (s^2 + 2s + 2) - (s + 2)(2s + 2) = -(s^2 + 4s + 2) = 0 \Rightarrow s = -2 - \sqrt2 = -3.41$.
  5. The complex part of the locus is a circle of radius $\sqrt2$ centred on the zero.

Why the root locus? Choosing K for $G = K/[s(s + 3)]$

Choosing a gain is a real design problem: a surgical robot arm must not overshoot, a rocket's guidance loop must settle quickly, and a factory drive must not oscillate. In each case we turn one knob, $K$, and want the closed-loop poles in a good place. The characteristic equation of $G(s) = \dfrac{K}{s(s + 3)}$ with unity feedback is $s^2 + 3s + K = 0$.

Trial and error: pick values of $K$ and solve each time.

This works for a second-order loop but tells us little about the pattern, and for higher orders each trial means solving a cubic or worse.

Algebra: for $\zeta = 0.707$ we need $3/(2\sqrt K) = 0.707$, so $K = 4.5$ and the poles are $-1.5 \pm j1.5$. Exact, but only because the equation is quadratic.

Root locus: draw every pole position for all $K$ at once. Here the two poles start at 0 and −3, meet at −1.5 when $K = 2.25$, and then move straight up and down along $\operatorname{Re}(s) = -1.5$. Draw the $\zeta = 0.707$ line (45° from the negative real axis); where it cuts the locus is the design point, and the magnitude condition gives $K = |s|\,|s + 3| = 2.12 \times 2.12 = 4.5$.

In MATLAB, rlocfind on this locus with a click near the 45° line returned $K \approx 4.55$: a click is never exact, so check with the magnitude condition.

Imaginary-axis crossing without the Routh array

Besides the Routh array, there is a direct method: put $s = j\omega$ in the characteristic equation and set the real and imaginary parts to zero separately. The two equations give the crossing frequency $\omega$ and the gain $K$ there.

Worked example 3: three poles at 0, −1, −2

$KG(s)H(s) = \dfrac{K}{s(s + 1)(s + 2)}$, characteristic equation $s^3 + 3s^2 + 2s + K = 0$.

  1. Poles $0, -1, -2$; no zeros; three branches, all going to infinity.
  2. Real axis: the locus lies on $[-1, 0]$ and $(-\infty, -2]$.
  3. Asymptotes: $\sigma_A = \dfrac{0 - 1 - 2}{3} = -1$, angles $60°$, $180°$, $300°$.
  4. Break-away: $K = -(s^3 + 3s^2 + 2s)$, $dK/ds = -(3s^2 + 6s + 2) = 0 \Rightarrow s = -0.423$ or $-1.577$. Only $-0.423$ lies on the locus (between 0 and −1); there $K = 0.385$.
  5. Imaginary-axis crossing (the $s = j\omega$ method): $-j\omega^3 - 3\omega^2 + j2\omega + K = 0$. Real part: $K - 3\omega^2 = 0$. Imaginary part: $\omega(2 - \omega^2) = 0$. So $\omega = \sqrt2 = 1.414$ rad/s and $K = 6$. The closed loop is stable for $0 < K < 6$.

Worked example 4: two real poles and a zero

$KG(s)H(s) = \dfrac{K(s + 3)}{(s + 1)(s + 2)}$, characteristic equation $s^2 + (3 + K)s + 2 + 3K = 0$.

  1. Poles $-1, -2$; zero $-3$. Two branches: one ends at the zero, the other goes to $-\infty$ (one asymptote, at 180°).
  2. Real axis: the locus lies on $[-2, -1]$ and $(-\infty, -3]$.
  3. Break-away and break-in: $N'D - ND' = (s^2 + 3s + 2) - (s + 3)(2s + 3) = -(s^2 + 6s + 7) = 0 \Rightarrow s = -3 \pm \sqrt2$. Break-away at $-1.586$ ($K = 0.17$), break-in at $-4.414$ ($K = 5.83$).
  4. Between them the locus is a circle of radius $\sqrt2$ centred on the zero at −3. It never reaches the right half-plane, so the closed loop is stable for every $K > 0$.

Designing K for a required overshoot

  1. Turn the overshoot limit into a damping ratio: $\zeta = \dfrac{-\ln M_p}{\sqrt{\pi^2 + \ln^2 M_p}}$.
  2. Draw the constant-$\zeta$ line from the origin at the angle $\theta = \cos^{-1}\zeta$ measured from the negative real axis.
  3. Find where the line cuts the locus (use the angle condition to check the point).
  4. Find $K$ there with the magnitude condition $K = 1/|G(s)H(s)|$.

Example. For $G = K/[s(s + 3)]$ with overshoot at most 10%: $\zeta = 0.59$; round up to $\zeta = 0.6$, so $\theta = \cos^{-1}0.6 = 53.1°$. The line meets $\operatorname{Re}(s) = -1.5$ at height $1.5\tan 53.1° = 2$, so $s = -1.5 \pm j2$. Angle check: $\angle s + \angle(s + 3) = 126.9° + 53.1° = 180°$. Then $K = |s|\,|s + 3| = 2.5 \times 2.5 = 6.25$, giving about 9.5% overshoot.

Root locus for a parameter other than K

Any parameter $\alpha$ that enters the characteristic equation linearly can be varied the same way. Rearrange the equation into the form

$$1 + \alpha\,G_{eq}(s) = 0$$

and apply all the rules to $G_{eq}$. Example: $G = \dfrac{10}{s(s + a)}$ with unity feedback gives $s^2 + as + 10 = 0$, that is $1 + a\dfrac{s}{s^2 + 10} = 0$. So $G_{eq} = s/(s^2 + 10)$, with poles at $\pm j\sqrt{10}$ and a zero at 0. The locus is a circle of radius $\sqrt{10}$ about the origin, meeting the real axis at $s = -\sqrt{10} = -3.16$ when $a = 2\sqrt{10} = 6.32$ (critical damping).

Root locus in MATLAB

num = [1];  den = [1 3 2 0];      % K/(s(s+1)(s+2))
sys = tf(num, den);
rlocus(sys)                        % draw the locus
[K, poles] = rlocfind(sys)         % click a point: returns K and all the poles

Exercises

  1. $G H = K/(s(s + 2)(s + 4))$. Find the centroid and asymptote angles.
    Show solution
    $n - m = 3$. $\sigma = (0 - 2 - 4)/3 = -2$. Angles 60°, 180°, 300°.
  2. For the same system, find the break-away point.
    Show solution
    $K = -s(s+2)(s+4) = -(s^3 + 6s^2 + 8s)$. $dK/ds = 0 \Rightarrow 3s^2 + 12s + 8 = 0 \Rightarrow s = -0.845$ (the root between 0 and −2).
  3. Find where it crosses the $j\omega$ axis.
    Show solution
    $s^3 + 6s^2 + 8s + K = 0$: marginal at $K = 48$, $\omega = \sqrt8 = 2.83$ rad/s.
  4. For $KG(s)H(s) = \dfrac{K}{s(s + 1)(s + 5)}$, find the gain at the break-away point $s = -0.47$.
    Show solution
    $K = |s(s + 1)(s + 5)| = 0.4725 \times 0.5275 \times 4.5275 = 1.13$. For $0 < K < 1.13$ the two dominant poles are real; above it they become a complex pair.
  5. For $KG(s)H(s) = \dfrac{K(s + 2)}{s^2 + 2s + 2}$, find the angle of departure from the pole at $-1 - j$.
    Show solution
    By symmetry it is $-135°$: $180° + \angle(1 - j) - \angle(-2j) = 180° - 45° + 90° = 225° \equiv -135°$.
  6. For the complementary root locus ($K < 0$) of $\dfrac{K}{s(s + 2)(s + 4)}$, what are the asymptote angles and which parts of the real axis are on the locus?
    Show solution
    Angles $0°$, $120°$, $240°$ (from $r = 0, 2, 4$), same centroid $-2$. Real axis: $[-4, -2]$ and $[0, \infty)$, where an even number of poles lie to the right.
  7. For $G = K/[s(s + 3)]$, find $K$ for $\zeta = 0.5$ and the closed-loop poles.
    Show solution
    $s^2 + 3s + K = 0$: $\zeta = 3/(2\sqrt K) = 0.5 \Rightarrow \sqrt K = 3$, $K = 9$. Poles $-1.5 \pm j2.60$.
  8. Use the $s = j\omega$ method to find where the root locus of $K/(s + 1)^3$ crosses the imaginary axis.
    Show solution
    $s^3 + 3s^2 + 3s + 1 + K = 0$. With $s = j\omega$: real part $1 + K - 3\omega^2 = 0$, imaginary part $\omega(3 - \omega^2) = 0$. So $\omega = \sqrt3 = 1.73$ rad/s and $K = 8$.
  9. For $K(s + 3)/[(s + 1)(s + 2)]$, find $K$ when the closed-loop poles are at the top and bottom of the circle, $-3 \pm j\sqrt2$.
    Show solution
    $K = \dfrac{|s + 1|\,|s + 2|}{|s + 3|} = \dfrac{\sqrt6 \times \sqrt3}{\sqrt2} = 3$. Check: $s^2 + 6s + 11 = 0$ gives $-3 \pm j\sqrt2$.
