By the end of this lesson you can

  • Explain the root locus as the path of closed-loop poles as K varies
  • Apply the construction rules
  • Read gain, damping and stability limits from a root locus

Notes

For $1 + KG(s)H(s) = 0$, the root locus plots the closed-loop poles as $K$ goes from 0 to $\infty$. A point is on the locus if $\angle G(s)H(s) = \pm180°(2q + 1)$; the gain there is $K = 1/|G(s)H(s)|$.

Construction rules

  1. The locus starts ($K = 0$) at open-loop poles and ends ($K\to\infty$) at open-loop zeros or at infinity.
  2. Number of branches = number of open-loop poles; the locus is symmetric about the real axis.
  3. A real-axis point is on the locus if the number of poles plus zeros to its right is odd.
  4. Asymptotes: $n - m$ of them, at angles $\dfrac{(2q + 1)180°}{n - m}$, meeting at the centroid $\sigma = \dfrac{\sum p - \sum z}{n - m}$.
  5. Break-away and break-in points: solve $dK/ds = 0$.
  6. Imaginary-axis crossings: from the Routh array (Lesson 11).
  7. Angles of departure from complex poles and arrival at complex zeros: from the angle condition.

Peer learning (Jigsaw): each group masters two rules, then teaches them to a mixed group that sketches a full locus together.

Exercises

  1. $G H = K/(s(s + 2)(s + 4))$. Find the centroid and asymptote angles.
    Show solution
    $n - m = 3$. $\sigma = (0 - 2 - 4)/3 = -2$. Angles 60°, 180°, 300°.
  2. For the same system, find the break-away point.
    Show solution
    $K = -s(s+2)(s+4) = -(s^3 + 6s^2 + 8s)$. $dK/ds = 0 \Rightarrow 3s^2 + 12s + 8 = 0 \Rightarrow s = -0.845$ (the root between 0 and −2).
  3. Find where it crosses the $j\omega$ axis.
    Show solution
    $s^3 + 6s^2 + 8s + K = 0$: marginal at $K = 48$, $\omega = \sqrt8 = 2.83$ rad/s.
