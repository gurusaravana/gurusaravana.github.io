By the end of this lesson you can

  • State the principle of the argument
  • Draw a Nyquist plot for simple systems
  • Apply the criterion Z = N + P

Notes

The Nyquist plot is the polar plot of $G(j\omega)H(j\omega)$ for $\omega$ from $-\infty$ to $\infty$ (the Nyquist contour enclosing the right half plane).

Criterion

$$Z = N + P$$

  • $P$: open-loop poles in the right half plane.
  • $N$: clockwise encirclements of the point $-1 + j0$ by the plot.
  • $Z$: closed-loop poles in the right half plane. Stable if and only if $Z = 0$.

For an open-loop stable system ($P = 0$), the closed loop is stable if the plot does not encircle $-1$.

Relative stability

If the plot crosses the negative real axis at $-a$, the gain margin is $1/a$. The phase margin is the angle between the negative real axis and the point where the plot crosses the unit circle.

Poles on the imaginary axis (such as $1/s$) are avoided with a small semicircle, which maps into a large arc in the Nyquist plot.

Exercises

  1. $GH$ is open-loop stable and its Nyquist plot encircles $-1$ twice clockwise. Is the closed loop stable?
    Show solution
    No. $Z = N + P = 2 + 0 = 2$ right-half-plane closed-loop poles.
  2. The plot crosses the negative real axis at $-0.25$. Find the gain margin.
    Show solution
    $GM = 1/0.25 = 4$, i.e. 12 dB.
  3. For $GH = K/(s + 1)^3$, the plot crosses the real axis where $\angle = -180°$. Find $K$ for marginal stability.
    Show solution
    At $\omega = \sqrt3$, $|GH| = K/8$. Marginal when $K/8 = 1$: $K = 8$ (matches the Routh result).
