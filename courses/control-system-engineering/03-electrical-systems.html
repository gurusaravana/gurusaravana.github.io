Notes

Kirchhoff's laws and the element laws give the equations. Two routes lead to the same transfer function: the classical route writes differential equations first, and the impedance route works directly in the $s$-domain.

ElementVoltage–current lawImpedance $Z(s)$
Resistor$v = Ri$$R$
Inductor$v = L\,di/dt$$Ls$
Capacitor$v = \frac{1}{C}\int i\,dt$$1/(Cs)$

Worked example 1: series RLC circuit (classical method)

Find $V_C(s)/V(s)$ for a series RLC circuit driven by $v(t)$.

  1. KVL: $L\dfrac{di}{dt} + Ri + \dfrac1C\displaystyle\int_0^t i\,d\tau = v(t)$.
  2. Use charge, $i = dq/dt$: $L\ddot q + R\dot q + \dfrac1C q = v(t)$.
  3. Use $q = Cv_C$: $LC\ddot v_C + RC\dot v_C + v_C = v(t)$.
  4. Laplace transform with zero initial conditions: $(LCs^2 + RCs + 1)V_C(s) = V(s)$.

$$G(s) = \frac{V_C(s)}{V(s)} = \frac{1}{LCs^2 + RCs + 1} = \frac{1/LC}{s^2 + \frac RL s + \frac1{LC}}$$

The same circuit by the impedance method

  1. Impedances: $Z_R = R$, $Z_L = Ls$, $Z_C = 1/(Cs)$.
  2. Mesh equation by inspection: $\left(Ls + R + \frac1{Cs}\right)I(s) = V(s)$.
  3. Output: $V_C = I\cdot\frac1{Cs}$, so $I(s) = CsV_C(s)$.
  4. Substitute: $(LCs^2 + RCs + 1)V_C(s) = V(s)$, the same result with no calculus.

Open the RLC circuit simulation. Set $R = 4\,\Omega$, $L = 1$ H, $C = 0.25$ F: then $\omega_n = 2$ rad/s and $\zeta = 1$. Lower $R$ and watch the response start to ring. Switch the output to $V_R$ or $V_L$ for Exercise Problems 2 and 3.

Mesh analysis by inspection

For each mesh, write

$$\left[\begin{smallmatrix}\text{sum of impedances}\\\text{around this mesh}\end{smallmatrix}\right]I_k - \sum\left[\begin{smallmatrix}\text{impedances common}\\\text{to mesh } k \text{ and } j\end{smallmatrix}\right]I_j = \left[\begin{smallmatrix}\text{sum of applied voltages}\\\text{around this mesh}\end{smallmatrix}\right]$$

then solve the simultaneous equations with Cramer's rule.

Worked example 2: two-loop RL–RC circuit

Loop 1 has $R_1$ and $L$; loop 2 has $R_2$ and $C$; the inductor is shared. Find $G(s) = I_2(s)/V(s)$.

$$(R_1 + Ls)I_1 - LsI_2 = V, \qquad -LsI_1 + \left(Ls + R_2 + \tfrac1{Cs}\right)I_2 = 0$$

By Cramer's rule, $I_2 = \dfrac{LsV}{\Delta}$ with $\Delta = (R_1 + Ls)\left(Ls + R_2 + \frac1{Cs}\right) - L^2s^2 = (R_1 + R_2)Ls + R_1R_2 + \dfrac{R_1}{Cs} + \dfrac LC$. Multiplying top and bottom by $Cs$:

$$G(s) = \frac{I_2(s)}{V(s)} = \frac{LCs^2}{(R_1 + R_2)LCs^2 + (R_1R_2C + L)s + R_1}$$

Worked example 3: two-loop RC network

Two RC sections in cascade: $R_1$ then $C_1$ to ground, then $R_2$ then $C_2$ to ground, with $E_o$ across $C_2$.

$$\left(R_1 + \tfrac1{C_1s}\right)I_1 - \tfrac1{C_1s}I_2 = E_i, \qquad -\tfrac1{C_1s}I_1 + \left(R_2 + \tfrac1{C_1s} + \tfrac1{C_2s}\right)I_2 = 0, \qquad E_o = \tfrac{I_2}{C_2s}$$

Solving with Cramer's rule and clearing fractions:

$$\frac{E_o(s)}{E_i(s)} = \frac{1}{(R_1C_1s + 1)(R_2C_2s + 1) + R_1C_2s}$$

The extra $R_1C_2s$ term is the loading effect: the second stage draws current from the first, so the network is not just two first-order lags multiplied together.

See it in the two-loop RC network simulation: the gap between the two curves is the loading effect.

Worked example 4: three-loop network by inspection

For the three-loop network in the notes, with clockwise loop currents, inspection gives

$$\begin{aligned}(2s + 2)I_1 - (2s + 1)I_2 - I_3 &= V\\ -(2s + 1)I_1 + (9s + 1)I_2 - 4sI_3 &= 0\\ -I_1 - 4sI_2 + \left(4s + 1 + \tfrac1s\right)I_3 &= 0\end{aligned}$$

Completing the solution with Cramer's rule is Exercise 3 below.

Real-world examples

Output filter of a power converter

A buck (step-down) DC-DC converter, as in a laptop charger or a solar charge controller, ends in an inductor and a capacitor feeding the load resistance. That is an RLC circuit, so its output can overshoot and ring after a load step, and the converter's controller is designed around this second-order model.

Inverter LC filter

Solar and UPS inverters switch at high frequency and use an LC filter to give a smooth 50 Hz sine wave. Designers place the filter's natural frequency $1/\sqrt{LC}$ well below the switching frequency and add damping so it does not resonate.

Radio tuning circuit

An RLC circuit passes signals near $\omega_n = 1/\sqrt{LC}$ and blocks others. Turning the tuning knob changes $C$, which moves $\omega_n$ to the station you want. Here a low damping ratio (sharp resonance) is the goal.

DC motor drive

The armature of a DC motor is an R–L circuit coupled to a mechanical load. The model at the end of these notes is used to tune speed controllers for electric vehicles, conveyors and robot joints.

Exercises

  1. Find $V_R(s)/V(s)$ and $V_L(s)/V(s)$ for the series RLC circuit.
    Show solution
    $\dfrac{V_R}{V} = \dfrac{RCs}{LCs^2 + RCs + 1}$ and $\dfrac{V_L}{V} = \dfrac{LCs^2}{LCs^2 + RCs + 1}$. Check both shapes in the RLC simulation: $V_R$ rises then falls to zero, $V_L$ jumps to 1 V then decays.
  2. For $R = 10\,\Omega$, $L = 1$ H, $C = 0.01$ F (output across $C$), find $\omega_n$ and $\zeta$.
    Show solution
    $\omega_n = 1/\sqrt{0.01} = 10$ rad/s. $\zeta = (10/2)\sqrt{0.01/1} = 0.5$.
  3. Complete worked example 4: write $I_3(s)/V(s)$ as a ratio of determinants.
    Show solution
    $I_3 = \Delta_3/\Delta$, where $\Delta$ is the determinant of the 3×3 coefficient matrix and $\Delta_3$ is the same matrix with its third column replaced by $[V\ 0\ 0]^T$, so $\Delta_3 = V\left[(2s+1)(4s) + (9s+1)\right]$ expanded along that column. Expand $\Delta$ the same way and simplify.
  4. In worked example 3, take $R_1 = R_2 = 1$ kΩ and $C_1 = C_2 = 1$ mF. Write $E_o/E_i$, and compare with the unloaded product.
    Show solution
    $R_1C_1 = R_2C_2 = R_1C_2 = 1$ s, so $E_o/E_i = 1/(s^2 + 3s + 1)$; the unloaded product would be $1/(s^2 + 2s + 1)$. The loaded network is slower, as the simulation shows.
  5. Neglecting $L_a$, write the DC motor transfer function as a first-order system.
    Show solution
    $\Omega/V_a = K/(\tau s + 1)$ with $K = K_t/(R_aB + K_tK_b)$ and $\tau = R_aJ/(R_aB + K_tK_b)$.
