By the end of this lesson you can

  • Draw a state diagram
  • Find the state transition matrix
  • Solve the state equation for given inputs

Notes

A state diagram is a block diagram or signal flow graph built from integrators: each state variable is the output of an integrator whose input is its derivative.

State transition matrix

$$\phi(t) = e^{At} = \mathcal L^{-1}\left[(sI - A)^{-1}\right]$$

Properties: $\phi(0) = I$, $\phi^{-1}(t) = \phi(-t)$, $\phi(t_1 + t_2) = \phi(t_1)\phi(t_2)$.

Solution

$$\mathbf x(t) = \phi(t)\mathbf x(0) + \int_0^t \phi(t - \tau)B\mathbf u(\tau)\,d\tau$$

The first term is the zero-input (free) response; the second is the zero-state (forced) response.

Exercises

  1. Find $\phi(t)$ for $A = \begin{bmatrix}0&1\\-2&-3\end{bmatrix}$.
    Show solution
    $(sI - A)^{-1} = \dfrac{1}{(s+1)(s+2)}\begin{bmatrix}s+3&1\\-2&s\end{bmatrix}$, so $\phi(t) = \begin{bmatrix}2e^{-t} - e^{-2t} & e^{-t} - e^{-2t}\\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t}\end{bmatrix}$.
  2. With $u = 0$ and $\mathbf x(0) = [1\ 0]^T$, find $x_1(t)$.
    Show solution
    $x_1(t) = 2e^{-t} - e^{-2t}$.
  3. Check $\phi(0)$ for your answer to Exercise 1.
    Show solution
    At $t = 0$ the matrix is $\begin{bmatrix}1&0\\0&1\end{bmatrix} = I$, as required.
