By the end of this lesson you can

  • Write differential equations for RLC circuits
  • Derive transfer functions with Laplace transforms
  • Use impedances to find transfer functions directly

Notes

Kirchhoff's laws and the element laws give the differential equations. With zero initial conditions, each element has an impedance:

ElementVoltage–current lawImpedance $Z(s)$
Resistor$v = Ri$$R$
Inductor$v = L\,di/dt$$Ls$
Capacitor$v = \frac{1}{C}\int i\,dt$$1/(Cs)$

Series RLC circuit

Input $v_i(t)$, output the capacitor voltage $v_o(t)$. KVL gives $L\,\dfrac{di}{dt} + Ri + \dfrac{1}{C}\int i\,dt = v_i$. Using the voltage divider with impedances:

$$\frac{V_o(s)}{V_i(s)} = \frac{1/(Cs)}{Ls + R + 1/(Cs)} = \frac{1}{LCs^2 + RCs + 1}$$

This is a second-order system with $\omega_n = 1/\sqrt{LC}$ and $\zeta = \dfrac{R}{2}\sqrt{C/L}$.

RC low-pass circuit

$$\frac{V_o(s)}{V_i(s)} = \frac{1}{RCs + 1}$$

a first-order system with time constant $\tau = RC$.

Armature-controlled DC motor

With armature resistance $R_a$, inductance $L_a$, back-emf constant $K_b$, torque constant $K_t$, inertia $J$ and friction $B$:

$$\frac{\Omega(s)}{V_a(s)} = \frac{K_t}{(L_as + R_a)(Js + B) + K_tK_b}$$

Model the RLC circuit in MATLAB with tf(1,[L*C R*C 1]) and step(), and compare it with the second-order simulation in Lesson 7.

Exercises

  1. Find $V_o/V_i$ for a series RLC circuit when the output is taken across the resistor.
    Show solution
    $\dfrac{V_o}{V_i} = \dfrac{R}{Ls + R + 1/(Cs)} = \dfrac{RCs}{LCs^2 + RCs + 1}$.
  2. For $R = 10\,\Omega$, $L = 1$ H, $C = 0.01$ F (output across $C$), find $\omega_n$ and $\zeta$.
    Show solution
    $\omega_n = 1/\sqrt{0.01} = 10$ rad/s. $\zeta = (10/2)\sqrt{0.01/1} = 0.5$.
  3. Neglecting $L_a$, write the DC motor transfer function as a first-order system.
    Show solution
    $\Omega/V_a = K_t/(R_a(Js + B) + K_tK_b) = K/(\tau s + 1)$ with $K = K_t/(R_aB + K_tK_b)$ and $\tau = R_aJ/(R_aB + K_tK_b)$.
