By the end of this lesson you can

  • Draw block diagrams of control systems
  • Apply block diagram reduction rules
  • Find the overall transfer function of multi-loop systems

Notes

A block diagram shows each part of a system as a block with its transfer function, joined by signals, summing points and take-off points.

Reduction rules

RuleResult
Blocks in series$G_1G_2$
Blocks in parallel$G_1 \pm G_2$
Negative feedback loop$\dfrac{G}{1 + GH}$
Positive feedback loop$\dfrac{G}{1 - GH}$
Move a summing point ahead of a block $G$Put $1/G$ in the added input
Move a summing point behind a block $G$Put $G$ in the added input
Move a take-off point ahead of a block $G$Put $G$ in the branch
Move a take-off point behind a block $G$Put $1/G$ in the branch

Method

  1. Combine all series and parallel blocks.
  2. Reduce inner feedback loops.
  3. Move summing or take-off points to untangle overlapping loops.
  4. Repeat until one block remains.

With several inputs (reference and disturbance), find each response separately with the other input set to zero, and add them (superposition).

Exercises

  1. $G_1$ and $G_2$ in series with unity negative feedback around both. Find $C/R$.
    Show solution
    $C/R = G_1G_2/(1 + G_1G_2)$.
  2. An inner loop $G_2$ with feedback $H_2$ is in series with $G_1$, and the whole has feedback $H_1$. Find $C/R$.
    Show solution
    Inner loop: $G_2/(1 + G_2H_2)$. Overall: $\dfrac{G_1G_2}{1 + G_2H_2 + G_1G_2H_1}$.
  3. Unity feedback system with $G = 10/(s(s+2))$. Find the closed-loop transfer function.
    Show solution
    $T = 10/(s^2 + 2s + 10)$.
