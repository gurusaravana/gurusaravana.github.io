By the end of this lesson you can

  • Convert a block diagram into a signal flow graph
  • Identify forward paths, loops and non-touching loops
  • Apply Mason's gain formula

Notes

A signal flow graph uses nodes for signals and branches with gains for the relations between them. It gives the transfer function in one step, without repeated reduction.

Terms

  • Forward path: a path from input node to output node that touches no node twice.
  • Loop: a closed path that returns to its starting node.
  • Non-touching loops: loops that share no node.

Mason's gain formula

$$T = \frac{1}{\Delta}\sum_k P_k\Delta_k$$

where $P_k$ is the gain of the $k$-th forward path and

$$\Delta = 1 - \sum L_i + \sum L_iL_j - \sum L_iL_jL_k + \dots$$

($\sum L_i$: all loop gains; $\sum L_iL_j$: products of all pairs of non-touching loops; and so on). $\Delta_k$ is $\Delta$ computed with the loops that touch the $k$-th forward path removed.

Example

For $G_1$ in series with an inner loop $G_2, H_2$, and outer feedback $H_1$: one forward path $P_1 = G_1G_2$; loops $L_1 = -G_2H_2$, $L_2 = -G_1G_2H_1$, which touch. So $\Delta = 1 + G_2H_2 + G_1G_2H_1$ and $\Delta_1 = 1$, matching Lesson 4.

Exercises

  1. A graph has forward paths $P_1 = G_1G_2G_3$ and $P_2 = G_4$, and one loop $L_1 = -G_2H$ touching $P_1$ only. Find $T$.
    Show solution
    $\Delta = 1 + G_2H$, $\Delta_1 = 1$, $\Delta_2 = 1 + G_2H$. $T = \dfrac{G_1G_2G_3 + G_4(1 + G_2H)}{1 + G_2H}$.
  2. Two non-touching loops have gains $L_1 = -0.5$ and $L_2 = -0.2$. Find $\Delta$.
    Show solution
    $\Delta = 1 - (L_1 + L_2) + L_1L_2 = 1 + 0.7 + 0.1 = 1.8$.
  3. Why is Mason's formula often faster than block diagram reduction?
    Show solution
    It finds the transfer function directly from paths and loops, without redrawing the diagram after each step or moving summing and take-off points.
