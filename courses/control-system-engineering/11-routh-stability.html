  • Define BIBO stability in terms of pole locations
  • Build the Routh array and handle special cases
  • Find the range of gain for stability

Notes

A linear system is stable if every bounded input gives a bounded output, which holds when all closed-loop poles have negative real parts. Poles on the $j\omega$ axis (non-repeated) give marginal stability.

Routh array

For $a_0s^n + a_1s^{n-1} + \dots + a_n$, write the first two rows from alternate coefficients, then

$$b_1 = \frac{a_1a_2 - a_0a_3}{a_1},\qquad b_2 = \frac{a_1a_4 - a_0a_5}{a_1},\ \dots$$

The number of sign changes in the first column equals the number of right-half-plane roots.

Special cases

  • Zero in the first column: replace it with a small $\varepsilon > 0$ and continue.
  • Whole row of zeros: form the auxiliary polynomial from the row above, differentiate it and use its coefficients. Its roots are symmetric about the origin (often on the $j\omega$ axis).

Range of $K$

Keep $K$ as a symbol, require every first-column entry to be positive, and solve. The boundary value is the marginal gain; the auxiliary equation then gives the frequency of oscillation.

Exercises

  1. Is $s^3 + 2s^2 + 3s + 10 = 0$ stable?
    Show solution
    First column: 1, 2, $(6 - 10)/2 = -2$, 10. Two sign changes: unstable with two right-half-plane roots.
  2. Find $K$ for stability: $s^3 + 3s^2 + 2s + K = 0$.
    Show solution
    $s^1$ row: $(6 - K)/3$. Need $0 < K < 6$. At $K = 6$: $3s^2 + 6 = 0$, so it oscillates at $\omega = \sqrt2$ rad/s.
  3. What does a row of zeros tell you?
    Show solution
    There are roots placed symmetrically about the origin, such as a pair on the imaginary axis, found from the auxiliary polynomial.
