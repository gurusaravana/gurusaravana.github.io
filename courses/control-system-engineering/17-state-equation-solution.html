By the end of this lesson you can

  • Draw a state diagram
  • Find the state transition matrix
  • Solve the state equation for given inputs

Notes

A state diagram is a block diagram or signal flow graph built from integrators: each state variable is the output of an integrator whose input is its derivative.

State transition matrix

$$\phi(t) = e^{At} = \mathcal L^{-1}\left[(sI - A)^{-1}\right]$$

Properties: $\phi(0) = I$, $\phi^{-1}(t) = \phi(-t)$, $\phi(t_1 + t_2) = \phi(t_1)\phi(t_2)$.

Solution

$$\mathbf x(t) = \phi(t)\mathbf x(0) + \int_0^t \phi(t - \tau)B\mathbf u(\tau)\,d\tau$$

The first term is the zero-input (free) response; the second is the zero-state (forced) response.

Exercises

  1. Find $\phi(t)$ for $A = \begin{bmatrix}0&1\\-2&-3\end{bmatrix}$.
    Show solution
    $(sI - A)^{-1} = \dfrac{1}{(s+1)(s+2)}\begin{bmatrix}s+3&1\\-2&s\end{bmatrix}$, so $\phi(t) = \begin{bmatrix}2e^{-t} - e^{-2t} & e^{-t} - e^{-2t}\\ -2e^{-t} + 2e^{-2t} & -e^{-t} + 2e^{-2t}\end{bmatrix}$.
  2. With $u = 0$ and $\mathbf x(0) = [1\ 0]^T$, find $x_1(t)$.
    Show solution
    $x_1(t) = 2e^{-t} - e^{-2t}$.
  3. Check $\phi(0)$ for your answer to Exercise 1.
    Show solution
    At $t = 0$ the matrix is $\begin{bmatrix}1&0\\0&1\end{bmatrix} = I$, as required.

Practice problems from the textbook

From the end-of-chapter Problems in N. S. Nise, Control Systems Engineering, 7th ed. (Hoboken, NJ: John Wiley & Sons, 2015), Chapter 4 (Time Response), Chapter 5 (Reduction of Multiple Subsystems). “Nise 4.24” means Chapter 4, Problem 24; § is the textbook section the problem practises. Work from the textbook statement and figure. The hints and short answers here are written for this course; full solutions are not reproduced.

  1. Nise 4.10 §4.10 Find the transfer function and poles of a system given in state space.
    Hint
    Hint. Poles are the eigenvalues of $A$: solve $\det(sI - A) = 0$.
  2. Nise 4.38 §4.10 Find the poles of a system without solving the state equation.
    Hint
    Hint. Only $\det(sI - A)$ is needed.
  3. Nise 4.40 §4.10 Find $Y(s)$ for a system given in state space.
    Hint
    Hint. $X(s) = (sI - A)^{-1}[x(0) + BU(s)]$, then $Y(s) = CX(s) + DU(s)$.
  4. Nise 4.42 §4.10 Solve a state equation for $y(t)$ with a unit step input, using the Laplace transform.
    Hint
    Hint. Find $(sI-A)^{-1}$ with the adjoint method, multiply out, and invert each entry with partial fractions.
  5. Nise 4.47 §4.11 Using classical methods, find the state-transition matrix, the state vector and the output.
    Hint
    Hint. $\Phi(t) = e^{At}$; with distinct eigenvalues each entry is a sum of $e^{\lambda_i t}$ terms. Use $\Phi(0) = I$ and $\dot\Phi(0) = A$ to find the constants.
  6. Nise 5.30 §5.7 Represent systems in Jordan (diagonal) canonical form and draw their signal flow graphs.
    Hint
    Hint. Expand the transfer function in partial fractions; each residue becomes a gain in $C$ and each pole a diagonal entry of $A$.
  7. Nise 5.31 §5.7 Represent systems in phase-variable form and draw their signal flow graphs.
    Hint
    Hint. A chain of integrators with feedback from every state to the first node.
