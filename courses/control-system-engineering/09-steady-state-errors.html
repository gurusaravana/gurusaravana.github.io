Notes

Steady-state error is the measure of a system's accuracy. Ideally the output matches the reference input exactly as time goes to infinity; the error should be as small as possible. It depends on only two things: the type of reference input and the type of the system.

The final value theorem

We do not need a full inverse Laplace transform to find where the error settles. Multiply the s-domain error by $s$ and let $s \to 0$:

$$e_{ss} = \lim_{t\to\infty}e(t) = \lim_{s\to0}sE(s), \qquad E(s) = \frac{R(s)}{1 + G(s)}\ \text{(unity feedback)}$$

The final value theorem only holds when the closed loop is stable. Always check stability (Lesson 11) before quoting a steady-state error; an unstable loop has no steady state.

The magic of integrators and system type

A plain gain $K$ in the loop leaves a permanent step error $e_{ss} = r_{ss}/(1 + K)$. Adding a single integrator ($K/s$, a pole at the origin) acts as an accumulator in the forward path: it keeps pushing until the step error is exactly zero. The number of integrators in the open-loop forward path is the system type:

Type 0 (no integrator)Type 1 (one integrator)Type 2 (two integrators)

Static error constants

$$K_p = \lim_{s\to0}G(s),\qquad K_v = \lim_{s\to0}sG(s),\qquad K_a = \lim_{s\to0}s^2G(s)$$

InputErrorMeaning
Unit step $1/s$ (position)$e_{ss} = \dfrac{1}{1 + K_p}$Zero error needs $K_p = \infty$: type 1 or higher.
Unit ramp $1/s^2$ (velocity)$e_{ss} = \dfrac{1}{K_v}$Type 0 cannot follow at all; type 1 follows with a finite gap; type 2 tracks perfectly.
Unit parabola $1/s^3$ (acceleration)$e_{ss} = \dfrac{1}{K_a}$Types 0 and 1 fail; type 2 has a finite gap; perfect tracking needs type 3.

Notice the diagonal staircase: the order of the input polynomial dictates the system type needed for a finite error. For inputs of size $A$, multiply the errors by $A$.

Breaking the unity rule

The shortcut "count the integrators" works for unity feedback. If sensors, filters or other dynamics put an $H(s)$ in the feedback path, use the closed-loop transfer function $T(s)$ instead:

$$E(s) = R(s)\,[1 - T(s)], \qquad T(s) = \frac{G_1(s)G_2(s)}{1 + G_1(s)G_2(s)H(s)}, \qquad e_{ss} = \lim_{s\to0}sR(s)[1 - T(s)]$$

The engineer's toolkit and dilemma

  • The engine: the final value theorem, $e_{ss} = \lim_{s\to0}sE(s)$.
  • The rule of thumb: match the system type to the target (type 0 for position, type 1 for velocity, type 2 for acceleration); add an integrator to remove a constant error.
  • The failsafe: when in doubt (non-unity feedback, disturbances), use $E(s) = R(s)[1 - T(s)]$.

Speed (rise and settling time), relative stability (overshoot) and accuracy (steady-state error) pull against each other. Raising the gain or the type improves accuracy but reduces stability and increases overshoot. Good control design is about finding the right balance for the application.

Exercises

  1. $G = 10/((s + 1)(s + 2))$, unity feedback. Find $e_{ss}$ for a unit step.
    Show solution
    Type 0, $K_p = 10/2 = 5$, $e_{ss} = 1/6 = 0.167$.
  2. $G = 20(s + 2)/(s(s + 4)(s + 5))$. Find $e_{ss}$ for $r(t) = 3t$.
    Show solution
    Type 1, $K_v = 20(2)/(4\cdot5) = 2$, $e_{ss} = 3/2 = 1.5$.
  3. What is the minimum type needed for zero error to a ramp input?
    Show solution
    Type 2.
  4. For servomechanisms with the open-loop transfer functions below, say which input gives a constant steady-state error and find its value: (a) $\dfrac{20(s + 2)}{s(s + 1)(s + 3)}$, (b) $\dfrac{10}{(s + 2)(s + 3)}$, (c) $\dfrac{10}{s^2(s + 1)(s + 2)}$.
    Show solution
    (a) Type 1: a unit ramp gives a constant error. $K_v = \dfrac{20 \times 2}{1 \times 3} = 13.3$, $e_{ss} = 1/K_v = 0.075$. The closed loop $s^3 + 4s^2 + 23s + 40$ is stable, so this is valid.
    (b) Type 0: a unit step. $K_p = 10/6 = 1.67$, $e_{ss} = 1/(1 + 1.67) = 0.375$. Stable.
    (c) Type 2: a unit parabola. $K_a = 10/2 = 5$, $e_{ss} = 1/K_a = 0.2$ on paper. But the characteristic equation $s^4 + 3s^3 + 2s^2 + 10 = 0$ has a missing $s$ term, so the closed loop is unstable (two poles at $0.64 \pm j1.15$). There is no real steady state; the system needs compensation first.
  5. For a unity feedback system with $G(s) = \dfrac{10(s + 2)}{s^2(s + 1)}$, find (a) the position, velocity and acceleration error constants and (b) the steady-state error for $R(s) = \dfrac{5}{s} - \dfrac{2}{s^2} + \dfrac{1}{6s^3}$.
    Show solution
    (a) Type 2: $K_p = \infty$, $K_v = \infty$, $K_a = \lim s^2G = 10 \times 2/1 = 20$.
    (b) The step and ramp parts give zero error. The parabolic part $\tfrac16\cdot\tfrac1{s^3}$ gives $e_{ss} = \dfrac{1/6}{K_a} = \dfrac{1}{120} = 0.0083$.
    Check stability first: the characteristic equation is $s^3 + s^2 + 10s + 20 = 0$. Routh: first column $1, 1, -10, 20$, two sign changes, so the closed loop is unstable and the textbook value $1/120$ is never reached in practice.
  6. A servo system has $G(s) = \dfrac{25}{s(0.1s + 1)}$ with unity feedback. Find the static error constants and the steady-state error for $r(t) = a_0 + a_1t + \dfrac{a_2}{2}t^2$.
    Show solution
    Type 1: $K_p = \infty$, $K_v = 25$, $K_a = 0$. $e_{ss} = \dfrac{a_0}{1 + \infty} + \dfrac{a_1}{25} + \dfrac{a_2}{0}$. So $e_{ss} = \infty$ whenever $a_2 \ne 0$; if $a_2 = 0$ it is $a_1/25$. (The loop $0.1s^2 + s + 25$ is stable.)
  7. A unity feedback system has $G(s) = \dfrac{K_1(2s + 1)}{s(5s + 1)(1 + s)^2}$. For $r(t) = 1 + 6t$, find the minimum $K_1$ that makes the steady-state error less than 0.1.
    Show solution
    Type 1, $K_v = K_1$. Step part: 0. Ramp part: $6/K_1$. So $6/K_1 < 0.1 \Rightarrow K_1 > 60$ (the textbook answer).
    But check stability: the characteristic equation is $5s^4 + 11s^3 + 7s^2 + (1 + 2K_1)s + K_1 = 0$. The Routh array needs $72 - 10K_1 > 0$ and $72 + 13K_1 - 20K_1^2 > 0$, which gives $0 < K_1 < 2.25$. At $K_1 = 60$ the loop is unstable, so this specification cannot be met by gain alone; a compensator is needed (Lesson 15).
