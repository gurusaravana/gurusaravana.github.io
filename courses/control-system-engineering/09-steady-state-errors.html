By the end of this lesson you can

  • Find steady-state error with the final value theorem
  • Define system type and the static error constants
  • Choose the type needed to follow a given input

Notes

For a unity feedback system with open-loop $G(s)$, the error is $E(s) = R(s)/(1 + G(s))$, and

$$e_{ss} = \lim_{s\to0}\frac{sR(s)}{1 + G(s)}$$

The type of the system is the number of open-loop poles at the origin ($1/s^N$ factors in $G$).

Static error constants

$$K_p = \lim_{s\to0}G(s),\qquad K_v = \lim_{s\to0}sG(s),\qquad K_a = \lim_{s\to0}s^2G(s)$$

Raising the type removes error for that input, but each integrator adds 90° of phase lag and makes the loop harder to stabilise.

Exercises

  1. $G = 10/((s + 1)(s + 2))$, unity feedback. Find $e_{ss}$ for a unit step.
    Show solution
    Type 0, $K_p = 10/2 = 5$, $e_{ss} = 1/6 = 0.167$.
  2. $G = 20(s + 2)/(s(s + 4)(s + 5))$. Find $e_{ss}$ for $r(t) = 3t$.
    Show solution
    Type 1, $K_v = 20(2)/(4\cdot5) = 2$, $e_{ss} = 3/2 = 1.5$.
