By the end of this lesson you can

  • Define controllability and observability
  • Apply Kalman's rank tests
  • Explain why they matter for design

Notes

A system is controllable if some input can move the state from any initial value to any final value in finite time. It is observable if the initial state can be found from the output measured over a finite time.

Kalman's tests (for an $n$-th order system)

$$Q_c = \begin{bmatrix}B & AB & A^2B & \cdots & A^{n-1}B\end{bmatrix},\qquad \text{rank}(Q_c) = n$$

$$Q_o = \begin{bmatrix}C \\ CA \\ \vdots \\ CA^{n-1}\end{bmatrix},\qquad \text{rank}(Q_o) = n$$

For a single-input or single-output system, check that the determinant of the square test matrix is not zero.

Why they matter

  • State feedback can place every pole only if the system is controllable.
  • An observer (state estimator) can rebuild every state only if the system is observable.
  • A pole–zero cancellation in the transfer function hides an uncontrollable or unobservable mode.

Exercises

  1. Is $A = \begin{bmatrix}0&1\\-2&-3\end{bmatrix}$, $B = \begin{bmatrix}0\\1\end{bmatrix}$ controllable?
    Show solution
    $Q_c = \begin{bmatrix}0&1\\1&-3\end{bmatrix}$, determinant $-1 \ne 0$: controllable.
  2. Same $A$, $C = [1\ 1]$. Is it observable?
    Show solution
    $CA = [-2\ -2]$. $Q_o = \begin{bmatrix}1&1\\-2&-2\end{bmatrix}$, determinant 0: not observable. (The zero at $s = -1$ cancels the pole at $-1$.)
  3. Why can't you place all poles by state feedback if a system is uncontrollable?
    Show solution
    The uncontrollable mode is not affected by the input at all, so no feedback through the input can move its pole.

Practice problems from the textbook

From the end-of-chapter Problems in N. S. Nise, Control Systems Engineering, 7th ed. (Hoboken, NJ: John Wiley & Sons, 2015), Chapter 12 (Design via State Space). “Nise 4.24” means Chapter 4, Problem 24; § is the textbook section the problem practises. Work from the textbook statement and figure. The hints and short answers here are written for this course; full solutions are not reproduced.

  1. Nise 12.11 §12.3 Decide the controllability of each plant in Figure P12.2.
    Hint
    Hint. Use $C_M = [B\ AB\ A^2B\ \dots]$ and check its rank. Diagonal systems can often be decided by inspection.
  2. Nise 12.24 §12.6 Decide whether each system in Figure P12.2 is observable.
    Hint
    Hint. Use $O_M = [C;\ CA;\ CA^2;\ \dots]$ and check its rank.
  3. Nise 12.4 §12.2 Design state feedback for a given open-loop plant.
    Hint
    Hint. Write the plant in phase-variable form; then the gains are the differences between the desired and the open-loop characteristic coefficients.
  4. Nise 12.13 §12.4 Design state feedback for a system that is not in phase-variable form.
    Hint
    Hint. Either transform to phase-variable form, or match $\det(sI - A + BK)$ with the desired polynomial directly.
  5. Nise 12.21 §12.4 Design an observer for a given plant.
    Hint
    Hint. Make the observer poles about ten times faster than the controller poles.
  6. Nise 12.23 §12.7 Design an observer for the phase variables of a plant whose phase variables are not available.
    Hint
    Hint. Dual of controller design: work with $A^T$ and $C^T$.
