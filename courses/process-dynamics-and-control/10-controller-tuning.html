By the end of this lesson you can

  • Tune PI and PID controllers from an FOPDT model
  • Compare IMC, Ziegler–Nichols and Cohen–Coon settings
  • Judge a closed-loop response by IAE, overshoot and robustness

Notes

Tuning means choosing $K_c$, $\tau_I$ and $\tau_D$. Model-based rules start from the FOPDT parameters $K$, $\tau$, $\theta$ of Lesson 7.

IMC (lambda) tuning for PI control

Choose a closed-loop time constant $\tau_c$. Larger $\tau_c$ gives slower, more robust control. A common choice is $\tau_c \ge \theta$ (or $\tau_c = \tau$ for very smooth control).

$$K_c = \frac{1}{K}\,\frac{\tau}{\tau_c + \theta}, \qquad \tau_I = \min\{\tau,\ 4(\tau_c + \theta)\}$$

Ziegler–Nichols (ultimate gain) method

With P-only control, raise $K_c$ until the loop oscillates steadily. Record the ultimate gain $K_{cu}$ and period $P_u$.

Controller$K_c$$\tau_I$$\tau_D$
P$0.5K_{cu}$––
PI$0.45K_{cu}$$P_u/1.2$–
PID$0.6K_{cu}$$P_u/2$$P_u/8$

Ziegler–Nichols settings are aggressive (quarter-decay response). In practice many engineers start there and then reduce $K_c$.

Judging the result

  • IAE $= \int|e|\,dt$: smaller is better.
  • Overshoot and settling time for set-point changes.
  • Robustness: does it stay stable if the process gain or dead time changes by 20–50 %?

Exercises

  1. FOPDT: $K = 2$, $\tau = 10$ min, $\theta = 2$ min. Find IMC PI settings with $\tau_c = \theta$.
    Show solution
    $K_c = \dfrac{1}{2}\cdot\dfrac{10}{2 + 2} = 1.25$. $\tau_I = \min\{10, 16\} = 10$ min.
  2. A loop oscillates steadily at $K_{cu} = 6$ with $P_u = 8$ min. Give Ziegler–Nichols PI settings.
    Show solution
    $K_c = 0.45(6) = 2.7$, $\tau_I = 8/1.2 = 6.7$ min.
  3. Use the simulation with $L = 1$ s. Find gains with less than 10 % overshoot and the smallest IAE you can.
    Show solution
    Open-ended. For example $K_p = 3$, $K_i = 0.5$, $K_d = 1$ gives almost no overshoot with IAE about 2.1. Compare answers with classmates.
