By the end of this lesson you can

  • Use the Laplace transform to turn ODEs into algebra
  • Derive a transfer function and find its gain, poles and zeros
  • Use the initial and final value theorems

Notes

The Laplace transform $F(s) = \int_0^\infty f(t)e^{-st}dt$ turns linear differential equations into algebraic equations in $s$.

$f(t)$$F(s)$
Unit step $S(t)$$1/s$
Ramp $t$$1/s^2$
$e^{-at}$$1/(s+a)$
$\sin\omega t$$\omega/(s^2+\omega^2)$
$df/dt$$sF(s) - f(0)$
$f(t-\theta)S(t-\theta)$$e^{-\theta s}F(s)$

Transfer function

With zero initial conditions (deviation variables), the transfer function is the ratio of output to input transforms:

$$G(s) = \frac{Y(s)}{U(s)}$$

From $\tau\,dy/dt + y = Ku$ we get $(\tau s + 1)Y(s) = KU(s)$, so $G(s) = K/(\tau s + 1)$.

  • Steady-state gain: $K = G(0)$, the final change in output per unit change in input.
  • Poles: roots of the denominator. They decide speed and stability: all poles must have negative real parts for a stable process.
  • Zeros: roots of the numerator. They shape the response, for example inverse response for a right-half-plane zero.

Final value theorem

$$\lim_{t\to\infty} y(t) = \lim_{s\to 0} sY(s)$$

valid only if the system is stable.

Exercises

  1. Find the transfer function of $2\,y'' + 3\,y' + y = 4u$.
    Show solution
    $G(s) = 4/(2s^2 + 3s + 1) = 4/((2s+1)(s+1))$. Gain 4, poles at $-0.5$ and $-1$.
  2. A process $G(s) = 5/(10s + 1)$ gets a step of size 2. What is the final change in output?
    Show solution
    $\lim_{s\to0} s\cdot\dfrac{5}{10s+1}\cdot\dfrac{2}{s} = 10$.
  3. Is $G(s) = 1/(s^2 - s + 2)$ stable?
    Show solution
    No. The poles $s = 0.5 \pm j1.32$ have positive real parts, so the response grows.
