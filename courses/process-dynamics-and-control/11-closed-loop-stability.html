By the end of this lesson you can

  • Derive the closed-loop characteristic equation
  • Apply the Routh–Hurwitz criterion
  • Find the ultimate gain by direct substitution

Notes

For controller $G_c$, valve $G_v$, process $G_p$ and sensor $G_m$, the set-point response is

$$\frac{Y}{Y_{sp}} = \frac{G_cG_vG_p}{1 + G_{OL}}, \qquad G_{OL} = G_cG_vG_pG_m$$

The loop is stable if and only if every root of the characteristic equation $1 + G_{OL}(s) = 0$ lies in the left half of the $s$-plane.

Routh–Hurwitz criterion

Write the characteristic polynomial $a_ns^n + \dots + a_0$ and build the Routh array. The number of sign changes in the first column equals the number of unstable roots. It tells us the range of $K_c$ for stability without solving for the roots.

Direct substitution

At the edge of stability a pair of roots sits on the imaginary axis. Put $s = j\omega$ into the characteristic equation and solve the real and imaginary parts for $K_{cu}$ and $\omega_u$. Then $P_u = 2\pi/\omega_u$.

Key lessons

  • First- and second-order processes under P control can never go unstable. Third order and higher, or any dead time, can.
  • Too much gain or too much integral action destabilises a loop.

In the simulation set $K_i = 0$, $K_d = 0$, $L = 2$ s and increase $K_p$ until the response stops decaying. That is the ultimate gain.

Exercises

  1. $G_{OL} = K_c/(s+1)^3$. Find the ultimate gain.
    Show solution
    Characteristic equation $s^3 + 3s^2 + 3s + 1 + K_c = 0$. With $s = j\omega$: imaginary part $-\omega^3 + 3\omega = 0 \Rightarrow \omega_u = \sqrt3$. Real part $-3\omega^2 + 1 + K_c = 0 \Rightarrow K_{cu} = 8$.
  2. Using that result, what is $P_u$, and what are Z–N PI settings?
    Show solution
    $P_u = 2\pi/\sqrt3 = 3.63$. $K_c = 3.6$, $\tau_I = 3.02$.
  3. Can a P controller make $G_p = 2/(5s + 1)$ unstable? Explain.
    Show solution
    No. The closed-loop pole is at $s = -(1 + 2K_c)/5$, which is negative for every positive $K_c$.
