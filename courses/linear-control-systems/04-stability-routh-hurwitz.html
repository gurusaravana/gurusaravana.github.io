Notes

For a linear time-invariant system, stability is defined through the natural response (the part that does not depend on the input):

  • Stable: the natural response approaches zero as $t \to \infty$.
  • Unstable: it grows without bound.
  • Marginally stable: it neither decays nor grows, but stays constant or oscillates.

An equivalent view is BIBO stability: every bounded input produces a bounded output.

A system is stable when all closed-loop poles are in the left half-plane (negative real parts). Any pole in the right half-plane makes it unstable. Simple poles on the $j\omega$ axis (and none in the right half-plane) make it marginally stable; repeated poles on the $j\omega$ axis give responses like $t\sin\omega t$ and are unstable.

The Routh–Hurwitz criterion

Finding the roots of a high-order polynomial by hand is hard. The Routh–Hurwitz criterion tells us how many roots lie in the left half-plane, the right half-plane and on the $j\omega$ axis (how many, not where) using only arithmetic:

The number of roots of the characteristic equation with positive real parts equals the number of sign changes in the first column of the Routh array.

For $a_ns^n + a_{n-1}s^{n-1} + \dots + a_1s + a_0 = 0$:

  1. Label the rows $s^n, s^{n-1}, \dots, s^0$.
  2. Row 1: $a_n, a_{n-2}, a_{n-4}, \dots$ Row 2: $a_{n-1}, a_{n-3}, \dots$
  3. Each new entry is a negative 2×2 determinant divided by the first entry of the row above: $b_1 = \dfrac{a_{n-1}a_{n-2} - a_na_{n-3}}{a_{n-1}}$, $b_2 = \dfrac{a_{n-1}a_{n-4} - a_na_{n-5}}{a_{n-1}}$, $c_1 = \dfrac{b_1a_{n-3} - a_{n-1}b_2}{b_1}$, and so on.
  4. Any row may be multiplied or divided by a positive constant to simplify the numbers.

A necessary (not sufficient) condition is that all coefficients are present and have the same sign. Two useful special cases:

  • Second order $a_2s^2 + a_1s + a_0$: stable if and only if all coefficients have the same sign.
  • Third order $a_3s^3 + a_2s^2 + a_1s + a_0$: stable if and only if all coefficients are positive and $a_2a_1 > a_0a_3$. Equality gives a pair of roots on the $j\omega$ axis.

Case II: a zero only in the first column

If the first entry of a row is zero but others in that row are not, the next row would need a division by zero. Two remedies:

Epsilon method. Replace the zero by a small number $\varepsilon$, finish the table, then let $\varepsilon \to 0$ and count sign changes.

Example 6. $s^5 + 2s^4 + 2s^3 + 4s^2 + 11s + 10 = 0$:

$s^{5}$1211
$s^{4}$2410
$s^{3}$$\varepsilon$6
$s^{2}$$\dfrac{4\varepsilon - 12}{\varepsilon} \to -\dfrac{12}{\varepsilon}$10
$s^{1}$$\dfrac{6c_1 - 10\varepsilon}{c_1} \to 6$0
$s^{0}$10

As $\varepsilon \to 0^+$ the column reads $+, +, +, -, +, +$: two sign changes, so two roots in the right half-plane.

Example 7. $s^4 + s^3 + s^2 + s + K = 0$:

$s^{4}$11$K$
$s^{3}$110
$s^{2}$$\varepsilon$$K$
$s^{1}$$\dfrac{\varepsilon - K}{\varepsilon} \to -\dfrac{K}{\varepsilon}$0
$s^{0}$$K$

For $K > 0$ the $s^1$ entry is large and negative: two sign changes. For $K < 0$ the last entry is negative. The system is unstable for every value of K.

Example 8. $T(s) = \dfrac{10}{s^5 + 2s^4 + 3s^3 + 6s^2 + 5s + 3}$. The $s^3$ row starts with zero; with $\varepsilon$ the first column is $1, 2, \varepsilon, \dfrac{6\varepsilon - 7}{\varepsilon}, \dfrac{42\varepsilon - 49 - 6\varepsilon^2}{12\varepsilon - 14}, 3$. Whether $\varepsilon$ is taken positive ($+,+,+,-,+,+$) or negative ($+,+,-,+,+,+$), there are two sign changes: two right-half-plane poles.

Reverse-coefficient method. The polynomial with the coefficients written in reverse order has the reciprocal roots $1/s_i$, which lie in the same half-plane. Its Routh table often has no zero.

Example 9 (example 8 again). $D(s) = 3s^5 + 5s^4 + 6s^3 + 3s^2 + 2s + 1$:

$s^{5}$362
$s^{4}$531
$s^{3}$4.21.4
$s^{2}$1.331
$s^{1}$$-1.75$0
$s^{0}$1

Two sign changes, the same answer as the epsilon method, with no limits to take.

Case III: an entire row of zeros

A row of zeros means the polynomial has an even factor (roots placed symmetrically about the origin: a pair on the real axis, a pair on the $j\omega$ axis, or a quadruple). Form the auxiliary polynomial $U(s)$ from the row above the zeros, replace the zero row by the coefficients of $dU/ds$, and continue. The roots of $U(s)$ are also roots of the original polynomial.

Example 10. $q(s) = s^3 + 2s^2 + 4s + K$:

$s^{3}$14
$s^{2}$2$K$
$s^{1}$$\dfrac{8 - K}{2}$0
$s^{0}$$K$

Stable for $0 < K < 8$. At $K = 8$ the $s^1$ row is all zeros; $U(s) = 2s^2 + 8 = 2(s^2 + 4)$, so two roots sit at $\pm j2$ and the system is marginally stable. Dividing, $q(s) = (s + 2)(s + j2)(s - j2)$.

Example 11. $q(s) = s^5 + s^4 + 4s^3 + 24s^2 + 3s + 63$:

$s^{5}$143
$s^{4}$12463
$s^{3}$$-20$$-60$
$s^{2}$2163
$s^{1}$00
row of zeros: use $U(s) = 21s^2 + 63$, $dU/ds = 42s$
$s^{1}$420
$s^{0}$63

$U(s) = 21s^2 + 63 = 21(s^2 + 3)$ gives two roots at $\pm j\sqrt{3}$. The column $1, 1, -20, 21, 42, 63$ has two sign changes, so two roots are in the right half-plane. Check by division: $q(s)/(s^2 + 3) = s^3 + s^2 + s + 21$, whose roots are $-3$ and $1 \pm j\sqrt{6}$. The system is unstable.

Case IV: repeated roots on the jω axis

If the $j\omega$ roots are repeated, the response contains $t\sin(\omega t + \phi)$, which grows. The Routh table alone does not reveal this: it looks marginally stable. Check whether the auxiliary polynomial itself has repeated roots, for example $U(s) = (s^2 + 1)^2$.

Using Routh for design

Problem. (a) Find $k_1$ and $k_2$ so that the system oscillates at $\omega_c = 9$ rad/s (critical stability). (b) Find $k_1$ and $k_2$ so that two poles are at $-2 \pm j2$.

Mason's rule: one forward path $T_1 = \dfrac{8k_1}{s(s + 4)(s + 5)}$; two touching loops, $-\dfrac{8k_2s}{s(s + 4)(s + 5)}$ and $-\dfrac{8k_1}{s(s + 4)(s + 5)}$. So

$$G(s) = \frac{8k_1}{s(s + 4)(s + 5) + 8k_2s + 8k_1}, \qquad s^3 + 9s^2 + (20 + 8k_2)s + 8k_1 = 0$$

$s^{3}$1$20 + 8k_2$
$s^{2}$9$8k_1$
$s^{1}$$\dfrac{180 + 72k_2 - 8k_1}{9}$0
$s^{0}$$8k_1$

(a) Oscillation needs the $s^1$ row to vanish, and the $s^2$ row then gives the frequency: $9s^2 + 8k_1 = 0$, so $\omega_c^2 = 8k_1/9 = 81$ and $k_1 = 91.125$. Then $180 + 72k_2 - 8(91.125) = 0$ gives $k_2 = 7.625$.

(b) With poles at $-2 \pm j2$, the factor is $(s + 2)^2 + 4 = s^2 + 4s + 8$. Dividing $s^3 + 9s^2 + (20 + 8k_2)s + 8k_1$ by it leaves the quotient $s + 5$ and the remainder $(8k_2 - 8)s + (8k_1 - 40)$, which must vanish: $k_2 = 1$, $k_1 = 5$. The third pole is at $-5$, so all poles are in the left half-plane and the system is stable.

Exercises

  1. Class exercise (figure above): find the values of the amplifier gain $k$ for which the system is stable.
    Show solution
    The three loops have gains $-\dfrac{k}{8(s + 4)}$, $-\dfrac{3k}{8(s + 4)(s + 1)}$ and $-\dfrac{k}{s(s + 1)(s + 4)}$, all touching. Multiplying $1 - \sum L$ by $8s(s + 1)(s + 4)$ gives $8s^3 + (40 + k)s^2 + (32 + 4k)s + 8k = 0$. Third-order test: $(40 + k)(32 + 4k) > 64k$, i.e. $4k^2 + 128k + 1280 > 0$, which holds for every $k > 0$. So the system is stable for all $k > 0$ (and unstable for $k < 0$, where the last coefficient is negative).
  2. Find the range of $K$ for stability of $s^4 + 4s^3 + 6s^2 + 4s + K = 0$.
    Show solution
    Column: $1, 4, 5, (20 - 4K)/5, K$. Stable for $0 < K < 5$. At $K = 5$, $U(s) = 5s^2 + 5$ gives oscillation at 1 rad/s.
  3. Use the reverse-coefficient method on $s^4 + s^3 + 2s^2 + 2s + 3 = 0$.
    Show solution
    Reverse: $3s^4 + 2s^3 + 2s^2 + s + 1$. Column: $3, 2, 0.5, -3, 1$: two sign changes, so two right-half-plane roots. (The original table has a zero in the $s^2$ row.)
  4. How many roots of $s^4 + 2s^3 + 3s^2 + 2s + 2 = 0$ lie in each region?
    Show solution
    Column: $1, 2, 2, 0$ (row of zeros). $U(s) = 2s^2 + 2$, $dU/ds = 4s$; continuing gives $4, 2$: no sign changes. So two roots at $\pm j$ (from $U$) and two in the left half-plane ($s^2 + 2s + 2$: $-1 \pm j$). Marginally stable.
  5. For unity feedback with $G(s) = \dfrac{K}{s(s + 2)(s + 4)}$, find the critical gain and the frequency of oscillation.
    Show solution
    $s^3 + 6s^2 + 8s + K = 0$; $s^1$ row $(48 - K)/6$. $K_{cr} = 48$; $U = 6s^2 + 48$ gives $\omega = \sqrt{8} = 2.83$ rad/s.
