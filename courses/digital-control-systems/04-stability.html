Notes

Stability is the first requirement of any control system, analog or digital. A digital controller updates only once per sampling period, so a loop that would be stable in continuous time can become unstable when it is sampled (Lesson 3, Example 1). This lesson defines stability for discrete-time LTI systems and gives three tests: pole locations, the Routh–Hurwitz criterion after a bilinear change of variable, and the Jury test, which works on the z-polynomial directly.

Asymptotic stability

The most common definitions look at the size of the response in the steady state. If it grows without bound, the system is unstable.

  • Asymptotically stable: the response to any initial conditions decays to zero, $\lim_{k\to\infty} y(k) = 0$.
  • Marginally stable: the response to initial conditions stays bounded but does not decay to zero.

Take the LTI difference equation $y(k+n) + a_{n-1}y(k+n-1) + \dots + a_0y(k) = b_mu(k+m) + \dots + b_0u(k)$ with initial conditions $y(0), \dots, y(n-1)$ and zero input. Z-transforming with the time-advance property gives

$$Y(z) = \frac{N(z)}{z^n + a_{n-1}z^{n-1} + \dots + a_1z + a_0}$$

where $N(z)$ depends on the initial conditions. The zeros of the transfer function come from the input terms, so they play no part here. The denominator is the same as that of the transfer function (unless poles and zeros cancel), so the response to initial conditions is a sum of terms $p_i^k$, one for each pole $p_i$.

In the absence of pole-zero cancellation, an LTI digital system is asymptotically stable if all its poles are in the open unit disc $\{z : |z| < 1\}$, and marginally stable if they are in the closed unit disc $\{z : |z| \le 1\}$ with no repeated poles on the unit circle.

Example 1. Determine the asymptotic stability of each system.

  1. $H(z) = \dfrac{4(z - 2)}{(z - 2)(z - 0.1)}$: the transfer function reduces to $4/(z - 0.1)$, but the cancelled pole at $z = 2$ is still a mode of the system. Any initial condition that excites it grows like $2^k$. Not asymptotically stable. An unstable pole can never be removed by cancellation.
  2. $H(z) = \dfrac{4(z - 0.2)}{(z - 0.2)(z - 0.1)}$: both poles, 0.2 and 0.1, are inside the unit circle. Asymptotically stable.
  3. $H(z) = \dfrac{5(z - 0.3)}{(z - 0.2)(z - 0.1)}$: poles 0.2 and 0.1. Asymptotically stable.
  4. $H(z) = \dfrac{8(z - 0.2)}{(z - 0.1)(z - 1)}$: a simple pole on the unit circle at $z = 1$. The initial-condition response tends to a constant. Marginally stable.

BIBO stability

The second definition concerns the forced response to a bounded input. An input is bounded if $|u(k)| < b_u$ for all $k$, with $0 < b_u < \infty$.

A system is bounded-input bounded-output (BIBO) stable if every bounded input produces a bounded output: $|y(k)| < b_y < \infty$. The response to any input is the convolution sum with the impulse response $h(k)$:

$$y(k) = \sum_{i=0}^{k} h(k - i)\,u(i), \qquad k = 0, 1, 2, \dots$$

so $|y(k)| \le b_u\sum_i |h(i)|$. The system is BIBO stable if and only if the impulse response is absolutely summable, $\sum_{k=0}^{\infty}|h(k)| < \infty$, which for a rational $H(z)$ means all poles inside the unit circle.

For LTI systems with no pole-zero cancellation, BIBO stability and asymptotic stability are equivalent and are checked with the same tests. That is why the literature simply says "stable", assuming no unstable cancellation. Note that a marginally stable system is not BIBO stable: a bounded input at the right frequency (a step into a pole at $z = 1$) produces an output that grows without bound.

Internal stability

A stable closed-loop transfer function from reference to output is not enough. Some internal signal, such as the control effort, may still grow without bound. In a feedback system every signal in the loop must stay bounded when the external inputs are bounded.

$$\begin{bmatrix} Y(z) \\ U(z) \end{bmatrix} = \frac{1}{1 + C(z)G_{ZAS}(z)}\begin{bmatrix} C(z)G_{ZAS}(z) & G_{ZAS}(z) \\ C(z) & -C(z)G_{ZAS}(z) \end{bmatrix}\begin{bmatrix} R(z) \\ D(z) \end{bmatrix}$$

The system is internally stable if all four transfer functions are BIBO stable. The test matters when the controller cancels a plant pole or zero outside the unit circle: the cancelled factor disappears from $Y/R$ but stays in $Y/D$ or $U/R$.

The slides write $G_{ZAS}(s)$ in these transfer functions; they are z-domain functions, $G_{ZAS}(z)$. The entry from $D$ to $U$ also carries a minus sign: the disturbance reaches $U$ through the negative feedback.

The Routh–Hurwitz criterion with a bilinear transform

The Routh–Hurwitz criterion tests for roots in the left half-plane, so it cannot be applied to a z-polynomial directly. A bilinear transformation maps the inside of the unit circle onto the left half-plane:

$$z = \frac{1 + w}{1 - w} \quad\Longleftrightarrow\quad w = \frac{z - 1}{z + 1}$$

Substitute into $F(z) = a_nz^n + \dots + a_0$, multiply through by $(1 - w)^n$, and apply the usual Routh array to the $w$-polynomial. Each sign change in the first column is one root outside the unit circle. The algebra grows quickly with the order, so this is practical for low-order polynomials, where it gives stability conditions on a gain very neatly.

Example 2. $z^2 - 0.25 = 0$. Substituting and multiplying by $(1 - w)^2$: $(1 + w)^2 - 0.25(1 - w)^2 = 0.75w^2 + 2.5w + 0.75 = 0$.

No sign changes: the system is stable. (Indeed the roots are $z = \pm 0.5$.)

The Jury stability test

E. I. Jury's test checks a z-polynomial directly, with no change of variable. For

$$F(z) = a_nz^n + a_{n-1}z^{n-1} + \dots + a_1z + a_0, \qquad a_n > 0$$

all roots are inside the unit circle if and only if all $n + 1$ conditions hold:

  1. $F(1) > 0$
  2. $(-1)^nF(-1) > 0$
  3. $|a_0| < a_n$
  4. $|b_0| > |b_{n-1}|$
  5. $|c_0| > |c_{n-2}|$
  6. … and so on, until the last row: $|r_0| > |r_2|$.

The first two need no table and often settle the question at once: if either fails, the polynomial is unstable. The rest come from the Jury table, which has $2n - 3$ rows:

Row$z^0$$z^1$$z^2$…$z^{n-1}$$z^n$
1$a_0$$a_1$$a_2$…$a_{n-1}$$a_n$
2$a_n$$a_{n-1}$$a_{n-2}$…$a_1$$a_0$
3$b_0$$b_1$$b_2$…$b_{n-1}$
4$b_{n-1}$$b_{n-2}$$b_{n-3}$…$b_0$
5$c_0$$c_1$…$c_{n-2}$
6$c_{n-2}$$c_{n-3}$…$c_0$
⋮
$2n-3$$r_0$$r_1$$r_2$

Each even row is the row above written backwards. Each new row comes from 2×2 determinants of the two rows above it:

$$b_k = \begin{vmatrix} a_0 & a_{n-k} \\ a_n & a_k \end{vmatrix} = a_0a_k - a_na_{n-k}, \qquad c_k = \begin{vmatrix} b_0 & b_{n-1-k} \\ b_{n-1} & b_k \end{vmatrix}$$

and so on, always using the first column and the column $k$ positions from the end.

Example 4. Test $F(z) = z^5 + 2.6z^4 - 0.56z^3 - 2.05z^2 + 0.0775z + 0.35$.

$F(1) = 1 + 2.6 - 0.56 - 2.05 + 0.0775 + 0.35 = 1.4175 > 0$: condition 1 holds. $F(-1) = -1 + 2.6 + 0.56 - 2.05 - 0.0775 + 0.35 = 0.3825$, so $(-1)^5F(-1) = -0.3825 < 0$: condition 2 fails, and the polynomial is already known to be unstable. Completing the table for practice:

(Its roots are $-2.5$, $0.7$, $0.5$, $-0.8$ and $-0.5$; the one at $-2.5$ is outside the unit circle.)

Example 5. $F(z) = z^2 - 0.25$. $F(1) = 0.75 > 0$, $(-1)^2F(-1) = 0.75 > 0$, and $|a_0| = 0.25 < a_2 = 1$. For $n = 2$ these three conditions are all there is, so the system is stable, in agreement with Example 2.

Example 6. $F(z) = z^3 - 1.2z^2 - 1.375z - 0.25$. $F(1) = 1 - 1.2 - 1.375 - 0.25 = -1.825 < 0$: condition 1 fails, so the system is unstable, as Example 3 found with Routh. (For completeness: $(-1)^3F(-1) = 1.075 > 0$ and $|a_0| = 0.25 < 1$ hold, and row 3 is $b = [-0.9375,\ 1.5438,\ 1.675]$, where $|b_0| < |b_2|$ fails too.)

For a second-order polynomial $z^2 + a_1z + a_0$ the Jury conditions reduce to the "stability triangle": $|a_0| < 1$, $1 + a_1 + a_0 > 0$ and $1 - a_1 + a_0 > 0$. These three inequalities are the quickest test you will ever use for a second-order loop.

Exercises

  1. A loop has characteristic equation $z^2 - 1.6z + 0.6 + 0.1K = 0$. Find the range of $K$ for stability.
    Show solution
    Use the second-order conditions with $a_1 = -1.6$, $a_0 = 0.6 + 0.1K$. $|a_0| < 1$ gives $-16 < K < 4$. $1 + a_1 + a_0 = 0.1K > 0$ gives $K > 0$. $1 - a_1 + a_0 = 3.2 + 0.1K > 0$ holds for $K > -32$. So $0 < K < 4$. At $K = 4$ the poles are on the unit circle.
  2. Use the Jury test on $F(z) = z^3 - 0.5z^2 - 0.25z + 0.125$.
    Show solution
    $F(1) = 0.375 > 0$. $(-1)^3F(-1) = -(-1.125) = 1.125 > 0$. $|a_0| = 0.125 < 1$. Row 3: $b_0 = a_0^2 - a_3^2 = -0.9844$, $b_2 = a_0a_2 - a_3a_1 = 0.1875$; $|b_0| > |b_2|$. All four conditions hold: stable. (It factors as $(z - 0.5)^2(z + 0.5)$.)
  3. Use the bilinear transform and Routh to test $z^2 - z + 0.5 = 0$.
    Show solution
    With $z = (1 + w)/(1 - w)$: $(1 + w)^2 - (1 + w)(1 - w) + 0.5(1 - w)^2 = 2.5w^2 + w + 0.5$. All coefficients are positive, and for a second-order polynomial that means no sign changes: stable. Check: the roots are $0.5 \pm j0.5$, with $|z| = 0.707$.
  4. $H(z) = \dfrac{z}{z - 1}$ is marginally stable. Show that it is not BIBO stable.
    Show solution
    Its impulse response is $h(k) = 1$ for all $k$, and $\sum|h(k)|$ diverges. Concretely, the bounded input $u(k) = 1$ gives $Y(z) = z^2/(z - 1)^2$, so $y(k) = k + 1$, which grows without bound.
  5. Plant $G_{ZAS}(z) = \dfrac{1}{z - 2}$, controller $C(z) = \dfrac{0.5(z - 2)}{z - 0.5}$. Is the loop stable from $R$ to $Y$? Is it internally stable?
    Show solution
    $CG = \dfrac{0.5}{z - 0.5}$ and $1 + CG = \dfrac{z}{z - 0.5}$, so $Y/R = 0.5/z$: stable. But $Y/D = \dfrac{G}{1 + CG} = \dfrac{z - 0.5}{z(z - 2)}$ has a pole at $z = 2$. Any disturbance at the plant input makes the output grow, so the loop is not internally stable. The controller tried to cancel an unstable pole.
  6. For the ZOH loop of Lesson 3, Example 1, the characteristic equation is $z - e^{-T} + K(1 - e^{-T}) = 0$. Confirm the gain limit with the Jury conditions for $T = 0.2$ s.
    Show solution
    For a first-order polynomial $z + a_0$ the only condition is $|a_0| < 1$. Here $a_0 = -e^{-0.2} + K(1 - e^{-0.2}) = -0.8187 + 0.1813K$. Then $-1 < a_0 < 1$ gives $-1 < K < 10.03$. With positive gains: $0 < K < 10.03$. Faster sampling allows more gain.
