Notes

Lesson 2 found the z-transfer function of one cascade: DAC, plant, ADC. Real loops put samplers in different places, and a digital controller is usually designed first in continuous time and then turned into a difference equation. This lesson covers both: pulse transfer functions of open and closed sampled loops, and the four common discretization methods.

The pulse transfer function

The pulse transfer function relates the z-transform of the sampled output to that of the sampled input, with zero initial conditions: $G(z) = Y(z)/X(z) = \mathcal{Z}\{G(s)\}$, where $\mathcal{Z}\{G(s)\}$ is shorthand for "find $g(t) = \mathcal{L}^{-1}\{G(s)\}$, sample it, and z-transform the samples".

Open-loop systems

The hold $G_0(s)$ and the plant $G_p(s)$ have no sampler between them, so they must be transformed together:

$$Y(z) = \mathcal{Z}\{G_0(s)G_p(s)\}\,G_c(z)\,X(z) = G(z)\,G_c(z)\,X(z)$$

Blocks separated by a sampler multiply as z-transforms: $G_1(z)G_2(z)$. Blocks joined directly are multiplied first and transformed once: $\mathcal{Z}\{G_1(s)G_2(s)\}$, written $G_1G_2(z)$. In general $G_1G_2(z) \ne G_1(z)G_2(z)$.

For (a), with a sampler between the blocks:

$$G_a(z) = \mathcal{Z}\left\{\frac{1}{s + a}\right\}\mathcal{Z}\left\{\frac{1}{s + b}\right\} = \frac{z^2}{(z - e^{-aT})(z - e^{-bT})}$$

For (b), with the blocks joined directly, expand $\dfrac{1}{(s + a)(s + b)} = \dfrac{1}{b - a}\left[\dfrac{1}{s + a} - \dfrac{1}{s + b}\right]$ first:

$$G_b(z) = \frac{1}{b - a}\left[\frac{z}{z - e^{-aT}} - \frac{z}{z - e^{-bT}}\right] = \frac{(e^{-aT} - e^{-bT})\,z}{(b - a)(z - e^{-aT})(z - e^{-bT})}$$

The poles are the same but the numerators differ, so the two systems respond differently.

The slide draws the second cascade with $1/(s+b)$ in both blocks. The comparison only makes sense with the same two blocks in each row, so this page uses $1/(s+a)$ and $1/(s+b)$ in both.

Closed-loop systems

Write the sampled error: $E(z) = X(z) - \mathcal{Z}\{H(s)G_0(s)G_p(s)\}\,G_c(z)E(z)$, and the output $Y(z) = G(z)G_c(z)E(z)$. Eliminating $E(z)$:

$$Y(z) = \frac{G_c(z)\,G(z)}{1 + G_c(z)\,\mathcal{Z}\{H(s)G_0(s)G_p(s)\}}\,X(z)$$

The slide's formula leaves out the factor $X(z)$ on the right-hand side. Dividing by $X(z)$ gives the closed-loop pulse transfer function.

The method for any sampled loop. (1) Name the output of every sampler; these are the only sampled signals. (2) Write each sampler's input in terms of $R(s)$ and the sampled signals, multiplying continuous blocks together. (3) Take the starred transform of each equation: a product with a starred signal becomes $GH(z)E(z)$. (4) Solve the algebraic equations. If the input $R(s)$ reaches a continuous block before any sampler, it stays inside a transform such as $RG(z)$, and no transfer function $C(z)/R(z)$ exists; only the output $C(z)$ can be found.

Common sampled-loop configurations

The table below is worth knowing well. Each figure is one row; $GH(z)$ means $\mathcal{Z}\{G(s)H(s)\}$ and $RG(z)$ means $\mathcal{Z}\{R(s)G(s)\}$.

Derivation of row 4, as a check of the method. Let $v$ be the output of $G_1$, which is sampled. Then $V(s) = G_1(s)R(s) - G_1(s)H(s)G_2(s)V^*(s)$. Starring: $V(z) = RG_1(z) - G_1G_2H(z)V(z)$, so $V(z) = RG_1(z)/(1 + G_1G_2H(z))$, and $C(z) = G_2(z)V(z)$.

The slide gives row 4 the same answer as row 5, $R(z)G_1(z)G_2(z)/(1 + G_1(z)G_2H(z))$. Without a sampler at the error, $R$ and $G_1$ are transformed together, as derived above.

Example 1

Find the closed-loop pulse transfer function. This is row 1 with $G = G_1G_2$ and $H = 1$. The open-loop part is the ZOH-plant cascade of Lesson 2:

$$G(z) = (1 - z^{-1})\,\mathcal{Z}\left\{\frac{K}{s(s + 1)}\right\} = \frac{z - 1}{z}\,K\left[\frac{z}{z - 1} - \frac{z}{z - e^{-T}}\right] = \frac{K(1 - e^{-T})}{z - e^{-T}}$$

$$\frac{C(z)}{R(z)} = \frac{G(z)}{1 + G(z)} = \frac{K(1 - e^{-T})}{z - e^{-T} + K(1 - e^{-T})}$$

The closed-loop pole is $z = e^{-T} - K(1 - e^{-T})$. It stays inside the unit circle only while $K < (1 + e^{-T})/(1 - e^{-T})$; for $T = 1$ s that is $K < 2.16$.

Principles of discretization

Most industrial processes are continuous and are modelled by differential equations or transfer functions in $s$, and a wide range of design methods exists for continuous systems. To implement a design on a computer we need a discrete-time version. Discretization means: given $G(s)$, find a $G(z)$ with similar characteristics. No method preserves every characteristic exactly, so we need to know what each method keeps and what errors it introduces.

MethodWhat it matchesNotes
Impulse invarianceThe impulse response at the sampling instantsGood time-domain match; aliasing at high frequencies.
Step invariance (ZOH)The step response at the sampling instantsExact for a plant driven by a DAC. Used for plant models.
Finite differencesDerivatives replaced by forward, backward or central differencesSimple and cheap; approximation error grows with $T$.
Bilinear (Tustin)Integration by the trapezoidal rulePreserves stability; good frequency response. Used for controllers.

Impulse invariance

Choose $G(z)$ so that its impulse response equals the samples of the continuous impulse response: $g(k) = g_a(t)\big|_{t=kT} = g_a(kT)$. The procedure:

  1. Find the impulse response $g_a(t) = \mathcal{L}^{-1}\{G_a(s)\}$.
  2. Choose $T$ and sample: $g(k) = g_a(kT)$.
  3. Z-transform: $G(z) = \mathcal{Z}\{g(k)\}$, written briefly as $G(z) = \mathcal{Z}\{G_a(s)\}$. In practice, expand $G_a(s)$ in partial fractions and use the transform table term by term.

Example. $g_a(t) = e^{-at}$, so $G_a(s) = \dfrac{1}{s + a}$, $g(k) = e^{-akT}$ and $G(z) = \dfrac{z}{z - e^{-aT}}$.

Sampling the impulse response gives the impulse train $g^*(t) = \sum g(k)\delta(t - kT)$, whose Laplace transform is $G^*(s) = \sum g(k)e^{-skT}$. With $z = e^{sT}$ this is exactly $G(z)$. In frequency terms,

$$G(e^{j\Omega}) = \frac{1}{T}\sum_{k=-\infty}^{\infty} G_a\left(j\frac{\Omega}{T} - j\frac{2\pi k}{T}\right)$$

The continuous frequency response is replicated every $2\pi/T$ and scaled by $1/T$. If $G_a(j\omega)$ is not negligible above $\omega_m = \pi/T$, the copies overlap and alias. Hence:

  • the left half of the s-plane maps inside the unit circle, and the imaginary axis in the primary strip maps onto the unit circle, so stable stays stable;
  • impulse invariance is unsuitable when $|G_a(j\omega)|$ does not approach zero as $\omega \to \infty$ (high-pass filters, lead compensators, any $G_a(s)$ with as many zeros as poles).

Because of the $1/T$ scaling, the DC gain of $\mathcal{Z}\{G_a(s)\}$ is about $1/T$ times the continuous DC gain. When impulse invariance is used to design a filter, the result is usually multiplied by $T$: $G(z) = T\,\mathcal{Z}\{G_a(s)\}$.

Step invariance: the zero-order-hold equivalent

Now match the step responses. A unit step $m(t)$ has $\mathcal{L}\{m\} = 1/s$, so the analog output is $y(t) = \mathcal{L}^{-1}\{G_a(s)/s\}$, and its samples have z-transform

$$Y(z) = \mathcal{Z}\left\{\mathcal{L}^{-1}\left[\frac{G_a(s)}{s}\right]_{t=kT}\right\} \qquad (1)$$

The discrete system driven by a sampled step gives $Y(z) = G(z)\dfrac{z}{z - 1}$ (2). Equating (1) and (2):

$$G(z) = (1 - z^{-1})\,\mathcal{Z}\left\{\frac{G_a(s)}{s}\right\}$$

This is exactly $G_{ZAS}(z)$ from Lesson 2. To see why, write the hold as $(1 - e^{-sT})/s$. With $g_1(t) = \mathcal{L}^{-1}\{G_a(s)/s\}$ and $G_1(z) = \mathcal{Z}\{g_1(kT)\}$, the delayed term gives $\mathcal{Z}\{G_a(s)e^{-sT}/s\} = z^{-1}G_1(z)$ by the shift property, so $\mathcal{Z}\{G_a(s)(1 - e^{-sT})/s\} = (1 - z^{-1})G_1(z)$.

Finite-difference methods

Replace each derivative by a difference between consecutive samples. Use the first-order equation

$$\frac{dy}{dt} + ay(t) = r(t), \qquad G_a(s) = \frac{1}{s + a}$$

Backward difference

$\dfrac{dy}{dt} \approx \dfrac{y(kT) - y((k-1)T)}{T}$. Substituting:

$$\frac{y(kT) - y((k-1)T)}{T} + ay(kT) = r(kT) \quad\Longrightarrow\quad y(kT) = \frac{1}{1 + aT}\left[y((k-1)T) + Tr(kT)\right]$$

Z-transforming, $(1 - z^{-1})Y(z) + aTY(z) = TR(z)$, so

$$G(z) = \frac{Y(z)}{R(z)} = \frac{T}{1 - z^{-1} + aT}, \qquad s = \frac{1 - z^{-1}}{T}, \qquad z = \frac{1}{1 - sT}$$

The slide writes $G(z) = 1/(1 - z^{-1} + aT)$. The line before it has $TR(z)$ on the right, so the numerator is $T$. Without it the DC gain would be $1/(aT)$ instead of $1/a$.

Stability. Put $s = j\omega$ into $z = 1/(1 - sT)$: $z - \tfrac{1}{2} = \tfrac{1}{2}\,\dfrac{1 + j\omega T}{1 - j\omega T}$, whose magnitude is always $\tfrac12$. So the imaginary axis maps onto the circle centred at $(0.5, 0)$ with radius 0.5, and the left half-plane maps inside it: writing $z = a + jb$, $(a - 0.5)^2 + b^2 < 0.25$. A stable $G_a(s)$ always gives a stable $G(z)$, but the small circle covers only part of the unit disc, so lightly damped poles become more damped than they should be.

The slide reaches this circle via "Re$(z - 1) < 0$", which is not the right step (that would be the half-plane Re $z < 1$). The condition is Re$\left((1 - z^{-1})/T\right) < 0$, which gives the circle shown.

Warping. A point on the unit circle, $z = e^{j\omega T}$, maps back to $s = (1 - e^{-j\omega T})/T$, which is not on the imaginary axis. For small $\omega T$, $e^{-j\omega T} \approx 1 - j\omega T$ and $s \approx j\omega$, so the distortion is negligible only when sampling is fast.

Forward difference

$\dfrac{dy}{dt} \approx \dfrac{y((k+1)T) - y(kT)}{T}$ gives

$$y((k+1)T) = y(kT) + T\left[-ay(kT) + r(kT)\right], \qquad G(z) = \frac{T}{z - 1 + aT} = \frac{Tz^{-1}}{1 - (1 - aT)z^{-1}}$$

$$s = \frac{z - 1}{T}, \qquad z = 1 + sT$$

The slide writes $G(z) = 1/(1 - z^{-1} - aT)$. Z-transforming the difference equation gives $zY = Y - aTY + TR$, so $G(z) = T/(z - 1 + aT)$.

The forward map sends the left half-plane to Re $z < 1$, which reaches far outside the unit circle. A stable $G_a(s)$ can become unstable: here the pole $z = 1 - aT$ leaves the unit circle when $aT > 2$.

The bilinear (Tustin) transformation

A one-to-one map from the whole s-plane to the z-plane that avoids these problems is

$$s = \frac{2}{T}\,\frac{z - 1}{z + 1}, \qquad z = \frac{1 + sT/2}{1 - sT/2}$$

  • The entire $j\omega$ axis maps onto the unit circle.
  • The left half-plane maps inside the unit circle; the right half-plane maps outside.
  • Stable analog systems always give stable discrete systems, with no aliasing.

Where it comes from. An integrator $1/s$ accumulates area. The trapezoidal rule approximates the area over one step by

$$\int_{(k-1)T}^{kT} y(t)\,dt \approx T\,\frac{y(k) + y(k - 1)}{2}$$

so the running integral $x(k) = x(k-1) + \tfrac{T}{2}\left[y(k) + y(k-1)\right]$ has transfer function $\dfrac{T}{2}\dfrac{z + 1}{z - 1}$. Replacing every $1/s$ by this is the same as substituting $s = \dfrac{2}{T}\dfrac{z - 1}{z + 1}$.

The slide writes the integral from $kT$ to $(k+1)T$ but averages $y(k)$ and $y(k-1)$. The limits that go with those two samples are $(k-1)T$ to $kT$.

Frequency warping. Because the whole infinite $j\omega$ axis is squeezed onto one turn of the unit circle, frequencies are compressed: a continuous frequency $\omega_a$ appears at the discrete frequency $\omega$ with $\omega_a = \dfrac{2}{T}\tan\dfrac{\omega T}{2}$. At low frequencies $\omega \approx \omega_a$. If one frequency (a notch or a crossover) must be exact, pre-warp it: design the analog filter for $\omega_a$ computed from this formula, then apply Tustin.

Exercises

  1. Compute the inverse z-transforms of $F_1(z) = \dfrac{10z}{(z - 1)(z - 0.5)}$ and $F_2(z) = \dfrac{2z^3 + z}{(z - 2)^2(z - 1)}$.
    Show solution
    $\dfrac{F_1(z)}{z} = \dfrac{20}{z - 1} - \dfrac{20}{z - 0.5}$, so $f_1(k) = 20\left(1 - 0.5^k\right)$: $\{0, 10, 15, 17.5, \dots\}$.
    $\dfrac{F_2(z)}{z} = \dfrac{2z^2 + 1}{(z - 2)^2(z - 1)} = \dfrac{3}{z - 1} - \dfrac{1}{z - 2} + \dfrac{9}{(z - 2)^2}$. Using $\mathcal{Z}\{k a^{k-1}\} = z/(z - a)^2$, $f_2(k) = 3 - 2^k + 9k\,2^{k-1}$: $\{2, 10, 35, \dots\}$, which matches long division.
  2. Find the transfer functions of (a) $y(k) + 0.5y(k-1) = 2x(k)$ (b) $y(k) + 2y(k-1) - y(k-2) = 2x(k) - x(k-1) + 2x(k-2)$ (c) $y(kT) + 3y(kT - T) + 4y(kT - 2T) + 5y(kT - 3T) = r(kT) - 3r(kT - T) + 2r(kT - 2T)$.
    Show solution
    Each delay becomes a factor $z^{-1}$.
    (a) $\dfrac{2}{1 + 0.5z^{-1}} = \dfrac{2z}{z + 0.5}$
    (b) $\dfrac{2 - z^{-1} + 2z^{-2}}{1 + 2z^{-1} - z^{-2}} = \dfrac{2z^2 - z + 2}{z^2 + 2z - 1}$
    (c) $\dfrac{1 - 3z^{-1} + 2z^{-2}}{1 + 3z^{-1} + 4z^{-2} + 5z^{-3}} = \dfrac{z(z^2 - 3z + 2)}{z^3 + 3z^2 + 4z + 5}$
  3. Write the difference equations for $G(z) = \dfrac{z^4 + 3z^3 + 2z^2 + z + 1}{z^4 + 4z^3 + 5z^2 + 3z + 2}$ and $H(z) = \dfrac{z}{z^2 - 1.7z + 0.72}$.
    Show solution
    Divide top and bottom by the highest power of $z$ to get powers of $z^{-1}$, then read off the delays.
    $G$: $y(k) + 4y(k-1) + 5y(k-2) + 3y(k-3) + 2y(k-4) = x(k) + 3x(k-1) + 2x(k-2) + x(k-3) + x(k-4)$.
    $H = \dfrac{z^{-1}}{1 - 1.7z^{-1} + 0.72z^{-2}}$: $y(k) = 1.7y(k-1) - 0.72y(k-2) + x(k-1)$. The poles are 0.8 and 0.9, so it is stable.
  4. In Example 1 take $T = 0.5$ s. Find the largest $K$ for a stable loop and the closed-loop pole when $K = 1$.
    Show solution
    $e^{-0.5} = 0.6065$. The pole is $z = 0.6065 - 0.3935K$, which reaches $-1$ when $K = 1.6065/0.3935 = 4.08$. So the loop is stable for $0 < K < 4.08$. With $K = 1$ the pole is at $z = 0.213$.
  5. Discretize the PI controller $C(s) = 2 + \dfrac{4}{s}$ with $T = 0.1$ s using the Tustin method, and write the control law as a difference equation.
    Show solution
    Replace $1/s$ by $\dfrac{T}{2}\dfrac{z + 1}{z - 1} = 0.05\dfrac{z + 1}{z - 1}$: $C(z) = 2 + 0.2\dfrac{z + 1}{z - 1} = \dfrac{2.2z - 1.8}{z - 1}$. So $u(k) = u(k-1) + 2.2e(k) - 1.8e(k-1)$.
  6. Why is impulse invariance a poor choice for the lead compensator $C(s) = \dfrac{s + 1}{s + 10}$?
    Show solution
    $|C(j\omega)| \to 1$ as $\omega \to \infty$: the compensator is not band limited, so the replicated spectra overlap and alias badly. Its impulse response also contains an impulse ($C(s) = 1 - 9/(s + 10)$), which sampling cannot represent. Use Tustin (or a pole-zero matching method) for compensators.
