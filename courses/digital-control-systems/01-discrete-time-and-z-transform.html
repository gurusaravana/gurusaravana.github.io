Notes

A digital controller is a computer program. It reads the plant output only at sampling instants $t = kT$, computes a new control value from a stored rule, and holds that value until the next instant. This lesson builds the mathematics for signals that exist only at those instants: difference equations, the z-transform, and the link $z = e^{sT}$ between the s-plane and the z-plane.

Why digital control?

Digital control offers clear advantages over analog control, which explains its popularity:

  • Accuracy. Digital signals are represented by numbers, so they do not drift or pick up noise the way analog voltages do.
  • Implementation errors are negligible. A coefficient stored in memory stays exactly what you wrote; resistor and capacitor values drift with age and temperature.
  • Flexibility. Changing the controller means changing the program, not replacing hardware.
  • Speed. Modern processors compute control laws very quickly, which allows fast sampling and sophisticated algorithms.
  • Cost. One inexpensive microcontroller can replace a board of analog parts, and can run several loops at once.

Structure of a digital control system

The comparison and the control law now run inside the computer. Two converters connect it to the analog world:

  • the analog-to-digital converter (ADC) samples the sensor signal every $T$ seconds and turns it into a number $y(k)$;
  • the digital-to-analog converter (DAC) turns the computed number $u(k)$ back into a voltage and holds it until the next update.

The loop is therefore a sampled-data system: part discrete (inside the computer), part continuous (the actuator and the process).

Two examples

Closed-loop drug delivery. A blood sensor measures the concentration of a drug or nutrient. The computer compares it with the prescribed level and sets the speed of a drug pump. Insulin delivery and anaesthesia control work this way.

Aircraft turbojet engine. The pilot's command goes to a computer that drives the engine through a DAC. Engine sensors (speeds, temperatures, pressures) and aircraft sensors (speed, altitude) both return through ADCs, so one computer closes two loops.

Difference equations

A differential equation relates the change in a variable to an infinitesimal change in another variable (usually time). A difference equation relates the change to a finite change: the independent variable takes only discrete values $k = 0, 1, 2, \dots$. The general linear time-invariant difference equation of order $n$ is

$$y(k+n) + a_{n-1}y(k+n-1) + \dots + a_1y(k+1) + a_0y(k) = b_nu(k+n) + b_{n-1}u(k+n-1) + \dots + b_0u(k)$$

with constant coefficients $a_i$, $b_i$. The input $u(k)$ is the forcing function. We describe a difference equation with four labels:

PropertyTest
OrderThe difference between the highest and lowest time arguments of $y$.
LinearEvery term contains $y$ or $u$ only to the first power, with no products such as $y(k)y(k+1)$ or $y(k)u(k)$.
Time invariantAll coefficients are constants (no coefficient depends on $k$).
HomogeneousThere is no forcing term ($u(k) = 0$).

Example 1. Classify each equation.

  1. $y(k+2) + 0.8y(k+1) + 0.07y(k) = u(k)$: second order, linear, time invariant (constant coefficients), nonhomogeneous (a forcing function appears). It is an LTI equation.
  2. $y(k+4) + \sin(0.4k)\,y(k+1) + 0.3y(k) = 0$: fourth order, linear (each term has $y$ to the first power), time varying (the coefficient $\sin(0.4k)$ changes with $k$), homogeneous.
  3. $y(k+1) = -0.1y^2(k)$: first order, nonlinear (the square), time invariant, homogeneous.

A coefficient that depends on $k$ does not make an equation nonlinear. Linearity is about how $y$ and $u$ appear; time variation is about the coefficients.

The z-transform

Difference equations can be solved step by step or with classical methods, but the z-transform is far more convenient for LTI equations. It turns difference equations into algebraic equations and convolution into multiplication, just as the Laplace transform does for continuous systems. For a causal sequence $\{u_0, u_1, u_2, \dots\}$,

$$U(z) = u_0 + u_1z^{-1} + u_2z^{-2} + \dots + u_kz^{-k} + \dots = \sum_{k=0}^{\infty} u_kz^{-k}$$

Each power $z^{-k}$ marks a position in time, so $z^{-1}$ can be read as a one-step time delay operator.

Example 2. The z-transform of $\{u_k\} = \{1, 1, 3, 2, 0, 4, 0, 0, \dots\}$ is read straight off the definition:

$$U(z) = 1 + z^{-1} + 3z^{-2} + 2z^{-3} + 4z^{-5}$$

From the Laplace transform to the z-transform

Represent the sampled signal as a train of impulses whose strengths are the samples:

$$u^*(t) = u_0\delta(t) + u_1\delta(t - T) + u_2\delta(t - 2T) + \dots = \sum_{k=0}^{\infty} u_k\,\delta(t - kT)$$

Its Laplace transform is $U^*(s) = \sum u_k e^{-ksT}$. Comparing this with $U(z) = \sum u_k z^{-k}$ shows that the two are the same once we set

$$z = e^{sT}$$

With $s = \sigma + j\omega$ this gives $z = e^{\sigma T}e^{j\omega T}$, so in polar form

$$|z| = e^{\sigma T}, \qquad \angle z = \omega T$$

The real part of $s$ sets the distance from the origin; the imaginary part sets the angle.

Mapping the s-plane onto the z-plane

  • Case 1, real poles $s = \sigma$. $\angle z = 0$ and $|z| = e^{\sigma T}$, so the image is on the positive real axis. $s = 0$ goes to $z = 1$; $s = -a$ goes to $z = e^{-aT}$, between 0 and 1; $s \to -\infty$ goes to $z = 0$.
  • Case 2, imaginary poles $s = \pm j\omega$. $|z| = 1$ and $\angle z = \pm\omega T$: the image is on the unit circle. As $\omega$ rises from 0 to $\pi/T$ the point travels from $z = 1$ to $z = -1$; $s = \pm j\pi/T$ both land on $z = -1$.
  • Case 3, complex poles $s = \sigma \pm j\omega$. $|z| = e^{\sigma T}$ and $\angle z = \pm\omega T$. Poles in the left half-plane ($\sigma < 0$) land inside the unit circle, in a complex-conjugate pair.

Because the angle $\omega T$ repeats every $2\pi$, the points $s$ and $s + j2\pi/T$ map to the same $z$. The band between $\pm j\pi/T$ is the primary strip; every band above and below it is an alias strip whose contents are overlaid on the same z-plane. To avoid aliasing there must be nothing in the alias strips: no signal with angular frequency above $\omega = \pi/T$, or cyclic frequency above $f = 1/(2T)$. Put another way, the sampling frequency must be at least twice the highest frequency present (the Nyquist rate). Lesson 2 returns to this as the sampling theorem.

Stability carries over directly: the left half of the s-plane becomes the inside of the unit circle. A discrete-time system is stable when all its poles satisfy $|z| < 1$.

A second-order pole pair $s = -\zeta\omega_n \pm j\omega_n\sqrt{1 - \zeta^2}$ maps to $|z| = e^{-\zeta\omega_nT}$, $\angle z = \pm\omega_nT\sqrt{1 - \zeta^2}$. Holding $\zeta$ fixed and raising $\omega_n$ traces a logarithmic spiral from $z = 1$ toward the origin; holding $\omega_nT$ fixed and raising $\zeta$ traces a curve from the unit circle to the real axis. Designers draw this grid on the z-plane in the same way they use $\zeta$ lines in the s-plane (the pink curve is $\zeta = 0.7$).

  • Positive real pole inside the circle: smooth exponential decay, faster the nearer it is to the origin.
  • Negative real pole: the response alternates in sign every sample. It has no continuous-time counterpart.
  • Complex poles inside the circle: a decaying oscillation; the angle sets the number of samples per cycle.
  • Poles on the circle: sustained output (marginal stability). Poles outside: growing output (unstable).

Example 3. With $T = 1$ s, map each s-plane pole and describe the step response.

z-transforms of standard sequences

Two sums are used again and again:

$$\sum_{k=0}^{n} a^k = \frac{1 - a^{n+1}}{1 - a}\ (a \ne 1), \qquad \sum_{k=0}^{\infty} a^k = \frac{1}{1 - a}\ (|a| < 1)$$

Sequence $f(k)$, $k \ge 0$$F(z)$Converges for
Unit impulse $\delta(k)$ (1 at $k = 0$, else 0)$1$all $z$
Sampled step $1(k)$$\dfrac{1}{1 - z^{-1}} = \dfrac{z}{z - 1}$$|z| > 1$
Sampled ramp $k$$\dfrac{z}{(z - 1)^2}$$|z| > 1$
Exponential $a^k$$\dfrac{1}{1 - az^{-1}} = \dfrac{z}{z - a}$$|z| > |a|$
$e^{-akT}$ (sampled exponential)$\dfrac{z}{z - e^{-aT}}$$|z| > e^{-aT}$

For the step, $U(z) = \sum_{k=0}^{\infty} z^{-k}$ is a geometric series with ratio $z^{-1}$, which converges to $1/(1 - z^{-1})$ when $|z^{-1}| < 1$. The exponential is the same series with ratio $az^{-1}$.

The original slides call $a^k$ a "sampled parabolic signal", write its sum as $(az)^{-k}$, and give the region of convergence as $|z| < 1$. The sequence $a^k$ is an exponential, the ratio of the series is $az^{-1}$, and the series converges for $|z| > |a|$ (for the step, $|z| > 1$).

Properties of the z-transform

PropertyStatement
Linearity$\mathcal{Z}\{\alpha f_1(k) + \beta f_2(k)\} = \alpha F_1(z) + \beta F_2(z)$
Time delay$\mathcal{Z}\{f(k - n)\} = z^{-n}F(z)$ (for a causal $f$)
Time advance$\mathcal{Z}\{f(k + n)\} = z^nF(z) - z^nf(0) - z^{n-1}f(1) - \dots - zf(n-1)$
Multiplication by an exponential$\mathcal{Z}\{a^{-k}f(k)\} = F(az)$

The time-advance property is how initial conditions enter: they appear as extra terms, just as $sF(s) - f(0)$ does for the Laplace transform of a derivative.

Worked examples

  1. $f(k) = 2\cdot1(k) + 4\delta(k)$. By linearity, $F(z) = 2\dfrac{z}{z - 1} + 4 = \dfrac{6z - 4}{z - 1}$.
  2. $f(k) = 4$ for $k \ge 2$, 0 otherwise. This is a step of height 4 delayed by two samples, $4\cdot1(k-2)$. By the delay property, $F(z) = 4z^{-2}\dfrac{z}{z - 1} = \dfrac{4}{z(z - 1)}$.
  3. $f(k) = \{4, 8, 16, 32, \dots\}$. This is $f(k) = 2^{k+2} = g(k + 2)$ with $g(k) = 2^k$, $G(z) = z/(z - 2)$. By the advance property, $F(z) = z^2G(z) - z^2g(0) - zg(1) = \dfrac{z^3}{z - 2} - z^2 - 2z = \dfrac{4z}{z - 2}$. (Check: $4\cdot 2^k$ has transform $4z/(z-2)$.)
  4. $f(k) = e^{-akT}$. Write it as $(e^{aT})^{-k}\cdot1(k)$ and apply the exponential property with $a \to e^{aT}$: $F(z) = \dfrac{e^{aT}z}{e^{aT}z - 1} = \dfrac{z}{z - e^{-aT}}$.

The slide lists the sequence in example 3 as $\{4, 8, 16, 24, \dots\}$. Since $f(k) = 2^{k+2}$, the fourth term is $2^5 = 32$, not 24.

The inverse z-transform

Two methods are used in practice:

  1. Long division. Divide the numerator by the denominator, both written in powers of $z^{-1}$, to get as many terms of the series as you need. The coefficients are the samples. It is simple but gives no closed form.
  2. Partial fractions. Almost the same as for Laplace transforms. Because most entries in the table have a $z$ in the numerator, expand $F(z)/z$, not $F(z)$, then multiply back by $z$.

Example 4 (long division). Invert $F(z) = \dfrac{z + 1}{z^2 + 0.2z + 0.1}$. Dividing,

$$F(z) = 0 + z^{-1} + 0.8z^{-2} - 0.26z^{-3} - 0.028z^{-4} + \dots$$

so $f(k) = \{0, 1, 0.8, -0.26, -0.028, \dots\}$. Each new coefficient follows from the recursion $f(k) = -0.2f(k-1) - 0.1f(k-2)$ once the numerator terms are used up.

Example 5 (partial fractions). Invert $F(z) = \dfrac{z + 1}{z^2 + 0.3z + 0.02}$. The denominator factors as $(z + 0.1)(z + 0.2)$, so

$$\frac{F(z)}{z} = \frac{z + 1}{z(z + 0.1)(z + 0.2)} = \frac{A}{z} + \frac{B}{z + 0.1} + \frac{C}{z + 0.2}$$

$$A = \left.\frac{z + 1}{(z + 0.1)(z + 0.2)}\right|_{z=0} = 50, \quad B = \left.\frac{z + 1}{z(z + 0.2)}\right|_{z=-0.1} = -90, \quad C = \left.\frac{z + 1}{z(z + 0.1)}\right|_{z=-0.2} = 40$$

$$F(z) = 50 - \frac{90z}{z + 0.1} + \frac{40z}{z + 0.2} \quad\Longrightarrow\quad f(k) = 50\delta(k) - 90(-0.1)^k + 40(-0.2)^k$$

Check: $f(0) = 50 - 90 + 40 = 0$, $f(1) = 9 - 8 = 1$, $f(2) = -0.9 + 1.6 = 0.7$, which matches long division of $F(z)$.

Exercises

  1. For each equation, give the order and test it for linearity, time invariance and homogeneity. (a) $y(k+2) = y(k+1)y(k) + u(k)$ (b) $y(k+3) + 2y(k) = 0$ (c) $y(k+4) + y(k-1) = u(k)$ (d) $y(k+5) = y(k+4) + u(k+1) - u(k)$ (e) $y(k+2) = y(k)u(k)$
    Show solution
    (a) Second order; nonlinear (product $y(k+1)y(k)$); time invariant; nonhomogeneous.
    (b) Third order; linear; time invariant; homogeneous.
    (c) Fifth order (the arguments of $y$ run from $k-1$ to $k+4$); linear; time invariant; nonhomogeneous.
    (d) First order (only $y(k+5)$ and $y(k+4)$ appear); linear; time invariant; nonhomogeneous.
    (e) Second order; nonlinear, because the output multiplies the input; time invariant. There is no stand-alone forcing term, but the input still drives the equation through the product.
  2. Find the z-transforms of (a) $\{0, 1, 2, 4, 0, 0, \dots\}$ (b) $\{0, 0, 0, 1, 1, 1, 0, 0, \dots\}$ (c) $\{0, 2^{-0.5}, 1, 2^{-0.5}, 0, 0, \dots\}$.
    Show solution
    (a) $z^{-1} + 2z^{-2} + 4z^{-3} = \dfrac{z^2 + 2z + 4}{z^3}$
    (b) $z^{-3} + z^{-4} + z^{-5} = \dfrac{z^2 + z + 1}{z^5}$
    (c) $0.7071z^{-1} + z^{-2} + 0.7071z^{-3}$ (these are samples of a half sine wave).
  3. Find the inverse z-transforms of (a) $1 + 3z^{-1} + 4z^{-2}$ (b) $5z^{-1} + 4z^{-5}$ (c) $\dfrac{z}{z^2 + 0.3z + 0.02}$ (d) $\dfrac{z - 0.1}{z^2 + 0.04z + 0.25}$ (e) $\dfrac{z}{(z + 0.1)(z + 0.2)(z + 0.3)}$
    Show solution
    (a) $f(k) = \{1, 3, 4, 0, 0, \dots\}$.
    (b) $f(1) = 5$, $f(5) = 4$, all other samples zero.
    (c) $\dfrac{F(z)}{z} = \dfrac{1}{(z + 0.1)(z + 0.2)} = \dfrac{10}{z + 0.1} - \dfrac{10}{z + 0.2}$, so $f(k) = 10\left[(-0.1)^k - (-0.2)^k\right]$: $\{0, 1, -0.3, 0.07, \dots\}$.
    (d) The poles are $-0.02 \pm j0.4996 = 0.5\angle\pm92.3°$ ($\theta = 1.611$ rad). Long division gives $\{0, 1, -0.14, -0.2444, 0.0448, 0.0593, \dots\}$. In closed form, $f(0) = 0$ and $f(k) = 0.5^{k-1}\left[\cos((k-1)\theta) - 0.2402\sin((k-1)\theta)\right]$ for $k \ge 1$, a decaying oscillation.
    (e) $\dfrac{F(z)}{z} = \dfrac{50}{z + 0.1} - \dfrac{100}{z + 0.2} + \dfrac{50}{z + 0.3}$, so $f(k) = 50(-0.1)^k - 100(-0.2)^k + 50(-0.3)^k$: $\{0, 0, 1, -0.6, 0.25, \dots\}$.
  4. With $T = 0.1$ s, where in the z-plane do the poles $s = -2 \pm j5$ land? Is the discrete system stable, and roughly how many samples does one oscillation take?
    Show solution
    $|z| = e^{-0.2} = 0.819$ and $\angle z = \pm 0.5$ rad $= \pm 28.6°$. The poles are inside the unit circle, so the system is stable. One full turn is $2\pi$ rad, so one oscillation takes about $2\pi/0.5 \approx 12.6$ samples.
  5. A signal contains a 30 Hz component and is sampled at 40 Hz. At what frequency does that component appear in the samples?
    Show solution
    The Nyquist frequency is 20 Hz, so 30 Hz lies in an alias strip. It folds to $|30 - 40| = 10$ Hz: the samples are identical to those of a 10 Hz signal.
  6. Use the time-advance property to solve $y(k+1) - 0.5y(k) = 0$ with $y(0) = 2$.
    Show solution
    $zY(z) - zy(0) - 0.5Y(z) = 0$, so $Y(z) = \dfrac{2z}{z - 0.5}$ and $y(k) = 2(0.5)^k$.
