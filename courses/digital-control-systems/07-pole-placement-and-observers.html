Notes

This lesson turns the state model into a design tool. It starts with the questions a designer must ask first (is the system stable, can the input move every state, can the output reveal every state), then places the closed-loop poles with state feedback, builds observers for states that cannot be measured, and adds integral action and deadbeat response. The worked examples come from the Chapter 5 tutorial sheet, mostly the satellite attitude problem.

Stability from the state model

For $x(k+1) = Fx(k) + gu(k)$, $y(k) = cx(k)$, the transfer function is

$$G(z) = c(zI - F)^{-1}g = c\,\frac{\operatorname{adj}(zI - F)}{\det(zI - F)}\,g$$

so the poles of $G(z)$ are roots of $\det(zI - F) = 0$, the eigenvalues of $F$. The system is asymptotically stable when every eigenvalue of $F$ lies inside the unit circle (Lesson 4).

Controllability

A system is completely state controllable if some input sequence moves it from any initial state to any desired state in a finite number of samples. If a state is unaffected by the input, no control signal can steer it.

With the input held constant over each sampling period (ZOH), the solution from Lesson 5 is

$$x(n) = F^nx(0) + F^{n-1}gu(0) + F^{n-2}gu(1) + \dots + gu(n-1)$$

$$x(n) - F^nx(0) = \begin{bmatrix} g & Fg & \cdots & F^{n-1}g \end{bmatrix}\begin{bmatrix} u(n-1) \\ u(n-2) \\ \vdots \\ u(0) \end{bmatrix}$$

For a single input each column $F^ig$ is $n \times 1$, so the bracketed matrix is $n \times n$. If it is invertible, the input sequence that reaches any target $x(n)$ in $n$ steps is found by inverting it. Hence

$$W_C = \begin{bmatrix} g & Fg & F^2g & \cdots & F^{n-1}g \end{bmatrix}, \qquad \text{controllable} \iff \operatorname{rank}W_C = n \iff \det W_C \ne 0$$

The slides say $[g\ \ Fg\ \cdots\ F^{k-1}g]$ is "$k \times k$" and needs "rank $k$". Its size is fixed by the order of the system: it is $n \times n$ and needs rank $n$. The number of steps $k$ can be larger, but $n$ steps are always enough.

Example 1. $G(z) = \dfrac{z + 2}{z^2 + z + 0.16}$. In the first companion form $F = \begin{bmatrix} 0 & 1 \\ -0.16 & -1 \end{bmatrix}$, $g = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$, $c = [2\ \ 1]$. Then $Fg = \begin{bmatrix} 1 \\ -1 \end{bmatrix}$ and

$$W_C = \begin{bmatrix} 0 & 1 \\ 1 & -1 \end{bmatrix}, \qquad \det W_C = -1 \ne 0$$

so the system is controllable (as every first companion realization is).

Observability

A system is completely observable if the initial state $x(0)$ can be found from the input and output over a finite number of samples. State feedback needs every state, but sensors are often missing or too expensive, so unmeasured states must be estimated. That is only possible if the system is observable.

Write $y(k) = cx(k)$ for $k = 0, 1, \dots, n-1$:

$$\begin{bmatrix} y(0) \\ y(1) \\ \vdots \\ y(n-1) \end{bmatrix} = \begin{bmatrix} c \\ cF \\ \vdots \\ cF^{n-1} \end{bmatrix}x(0) + \begin{bmatrix} 0 & 0 & \cdots & 0 \\ 0 & 0 & \cdots & cg \\ \vdots & & & \vdots \\ 0 & cg & \cdots & cF^{n-2}g \end{bmatrix}\begin{bmatrix} u(n-1) \\ \vdots \\ u(0) \end{bmatrix}$$

The input terms are known, so $x(0)$ can be solved for if the first matrix is invertible:

$$W_O = \begin{bmatrix} c \\ cF \\ \vdots \\ cF^{n-1} \end{bmatrix}, \qquad \text{observable} \iff \operatorname{rank}W_O = n \iff \det W_O \ne 0$$

Example 2. $F = \begin{bmatrix} 1.1 & -0.3 \\ 1 & 0 \end{bmatrix}$, $g = \begin{bmatrix} 1 \\ -0.5 \end{bmatrix}$, $c = [1\ \ -0.5]$. $cF = [1.1 - 0.5\ \ \ -0.3] = [0.6\ \ -0.3]$, so

$$W_O = \begin{bmatrix} 1 & -0.5 \\ 0.6 & -0.3 \end{bmatrix}, \qquad \det W_O = -0.3 + 0.3 = 0$$

The system is not observable: the second row is $0.6$ times the first, so the output never separates the two states. (The eigenvalues of $F$ are $0.5$ and $0.6$, and $c$ is a left eigenvector for $0.6$, so the mode $0.5^k$ is invisible.)

Sampling can destroy controllability and observability

A continuous plant that is controllable and observable can lose both properties when it is sampled. For an undamped oscillator $\ddot y + \omega^2y = u$, the ZOH model has $F = \begin{bmatrix} \cos\omega T & \sin(\omega T)/\omega \\ -\omega\sin\omega T & \cos\omega T \end{bmatrix}$. If $\omega T = \pi$ (two samples per period), $F = -I$, so $Fg = -g$ and $W_C$ has rank 1. A pole-zero cancellation appears in the pulse transfer function. Choose $T$ so that $\omega T$ is not a multiple of $\pi$ for any lightly damped mode.

Pole placement by state feedback

Root locus lets the designer move the two dominant closed-loop poles. Pole placement sets all $n$ closed-loop poles, at the cost of feeding back every state. When a state cannot be measured, an observer supplies an estimate (the second half of this lesson). The design is done in two phases: assume all states are available and design the control law, then design the observer and use the estimates in its place.

With the control law

$$u(k) = -kx(k) = -\begin{bmatrix} k_1 & k_2 & \cdots & k_n \end{bmatrix}x(k)$$

the closed loop is $x(k+1) = (F - gk)x(k)$ with characteristic equation $|zI - (F - gk)| = 0$. Choose the desired poles $\lambda_1, \dots, \lambda_n$ inside the unit circle, form

$$\alpha_c(z) = (z - \lambda_1)(z - \lambda_2)\cdots(z - \lambda_n) = z^n + a_1z^{n-1} + \dots + a_n$$

and match coefficients: $|zI - F + gk| = \alpha_c(z)$. The poles can be placed anywhere if and only if $(F, g)$ is controllable.

One slide writes the matching condition as $\det(sI - (F - gk)) = \prod(s - \lambda_i)$. For the discrete model the variable is $z$, and the $\lambda_i$ are $z$-plane poles: inside the unit circle, found from $s$-plane specifications with $z = e^{sT}$.

Ackermann's formula

For a controllable single-input system, the gain can be written in one line:

$$k = \begin{bmatrix} 0 & 0 & \cdots & 1 \end{bmatrix}W_C^{-1}\,\alpha_c(F), \qquad \alpha_c(F) = F^n + a_1F^{n-1} + \dots + a_{n-1}F + a_nI$$

Example 3: satellite attitude control

A satellite's antennas must point at the Earth and its solar panels at the Sun. Taking one axis at a time, reaction jets apply a torque $T_c = Fd$ (force times distance from the mass centre) and $J\ddot\theta = T_c$. With $u = T_c/J$ the plant is a double integrator, $\theta(s)/U(s) = 1/s^2$:

$$\dot x = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}x + \begin{bmatrix} 0 \\ 1 \end{bmatrix}u, \qquad x_1 = \theta, \quad x_2 = \dot\theta = \omega$$

With a ZOH, $F = e^{AT} = \begin{bmatrix} 1 & T \\ 0 & 1 \end{bmatrix}$ and $g = \displaystyle\int_0^T e^{A\tau}b\,d\tau = \begin{bmatrix} T^2/2 \\ T \end{bmatrix}$. For $T = 0.1$ s, $F = \begin{bmatrix} 1 & 0.1 \\ 0 & 1 \end{bmatrix}$, $g = \begin{bmatrix} 0.005 \\ 0.1 \end{bmatrix}$. The open loop has a double pole at $z = 1$: it is not stable.

The closed-loop characteristic equation is

$$|zI - (F - gk)| = z^2 + \left(Tk_2 + \frac{T^2}{2}k_1 - 2\right)z + \left(\frac{T^2}{2}k_1 - Tk_2 + 1\right) = 0$$

The specification $\zeta = 0.5$, $\omega_n = 3.6$ rad/s gives $s = -1.8 \pm j3.12$, and $z = e^{sT} = e^{-0.18}e^{\pm j0.312} = 0.795 \pm j0.256$, so $\alpha_c(z) = z^2 - 1.6z + 0.70$. Matching coefficients with $T = 0.1$:

$$0.005k_1 + 0.1k_2 = 0.4, \qquad 0.005k_1 - 0.1k_2 = -0.3 \quad\Rightarrow\quad k_1 = 10, \quad k_2 = 3.5$$

The tutorial sheet gives the desired poles as $0.875 \pm j0.273$. Those do not produce $z^2 - 1.6z + 0.70$ (their product is $0.84$). The specification $\zeta = 0.5$, $\omega_n = 3.6$ gives $0.795 \pm j0.256$, which does. The gains $k = [10\ \ 3.5]$ are right.

State observers

An open-loop estimator runs a copy of the model, $\hat x(k+1) = F\hat x(k) + gu(k)$, beside the plant. Its error $\tilde x = x - \hat x$ obeys $\tilde x(k+1) = F\tilde x(k)$: it never corrects a wrong initial guess faster than the plant itself, and if $F$ is unstable it diverges. The fix is to feed back the difference between the measured and predicted outputs.

The prediction observer is

$$\hat x(k+1) = F\hat x(k) + gu(k) + m\left[y(k) - c\hat x(k)\right]$$

It is called a prediction observer because $\hat x(k+1)$ is computed from measurements up to $y(k)$, one step ahead. Subtracting it from the plant equation gives the error dynamics

$$\tilde x(k+1) = (F - mc)\,\tilde x(k)$$

Choose the observer poles, form $\alpha_e(z)$, and pick $m$ so that $|zI - F + mc| = \alpha_e(z)$. This is possible for any $\alpha_e$ if and only if $(F, c)$ is observable. By duality with Ackermann's formula,

$$m = \alpha_e(F)\,W_O^{-1}\begin{bmatrix} 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix}$$

A common rule is to make the observer poles two to six times faster than the controller poles, so the estimate settles before it matters to the loop, but not so fast that sensor noise is amplified.

Example 4. A full-order observer for the satellite with $c = [1\ \ 0]$ (angle measured) and both observer poles at $z = 0.5$: $\alpha_e(F) = F^2 - F + 0.25I = \begin{bmatrix} 0.25 & 0.1 \\ 0 & 0.25 \end{bmatrix}$, $W_O = \begin{bmatrix} 1 & 0 \\ 1 & 0.1 \end{bmatrix}$, $W_O^{-1}\begin{bmatrix} 0 \\ 1 \end{bmatrix} = \begin{bmatrix} 0 \\ 10 \end{bmatrix}$, so $m = \begin{bmatrix} 1 \\ 2.5 \end{bmatrix}$. Check: $F - mc = \begin{bmatrix} 0 & 0.1 \\ -2.5 & 1 \end{bmatrix}$ has trace 1 and determinant 0.25, so $|zI - F + mc| = z^2 - z + 0.25 = (z - 0.5)^2$.

Combining the observer with the control law

Use the estimate in the control law, $u(k) = -k\hat x(k)$. The compensator is

$$\hat x(k+1) = (F - gk - mc)\,\hat x(k) + m\,y(k), \qquad u(k) = -k\,\hat x(k)$$

Separation principle. In the coordinates $(x, \tilde x)$ the closed loop is block triangular, so its characteristic polynomial is $\alpha_c(z)\,\alpha_e(z)$. The control law and the observer can be designed separately: the controller poles stay where they were placed, and the observer adds its own poles.

Reduced-order observer

If some states are measured directly, there is no need to estimate them. Partition the state into the measured part $x_1$ ($y = x_1$) and the part to estimate $x_e$:

$$\begin{bmatrix} x_1(k+1) \\ x_e(k+1) \end{bmatrix} = \begin{bmatrix} f_{11} & f_{1e} \\ f_{e1} & F_{ee} \end{bmatrix}\begin{bmatrix} x_1(k) \\ x_e(k) \end{bmatrix} + \begin{bmatrix} g_1 \\ g_e \end{bmatrix}u(k), \qquad y(k) = \begin{bmatrix} 1 & 0 \end{bmatrix}x(k)$$

The unmeasured states obey $x_e(k+1) = F_{ee}x_e(k) + f_{e1}x_1(k) + g_eu(k)$, where the last two terms are known. The first row gives a "measurement" of $x_e$:

$$y(k+1) - f_{11}y(k) - g_1u(k) = f_{1e}x_e(k)$$

The reduced-order observer runs the $x_e$ model and corrects it with this measurement:

$$\hat x_e(k+1) = F_{ee}\hat x_e(k) + f_{e1}y(k) + g_eu(k) + m\left[y(k+1) - f_{11}y(k) - g_1u(k) - f_{1e}\hat x_e(k)\right]$$

$$\tilde x_e(k+1) = (F_{ee} - mf_{1e})\,\tilde x_e(k)$$

Choose $m$ to place the eigenvalues of $F_{ee} - mf_{1e}$. The observer has order $n - 1$ for one measured state, and it uses the current measurement $y(k+1)$.

Example 5. Satellite with the angle measured and the velocity estimated, $T = 0.1$ s. The partitions are $f_{11} = 1$, $f_{1e} = T$, $f_{e1} = 0$, $F_{ee} = 1$, $g_1 = T^2/2$, $g_e = T$:

$$\hat x_2(k+1) = \hat x_2(k) + Tu(k) + m\left[y(k+1) - y(k) - \frac{T^2}{2}u(k) - T\hat x_2(k)\right]$$

The error pole is $z = 1 - mT$. The controller poles have radius $0.835$; four times faster means radius $0.835^4 \approx 0.49$, so put the observer pole at $z = 0.5$: $1 - 0.1m = 0.5$, $m = 5$. Then

$$\hat x_2(k+1) = 0.5\hat x_2(k) + 5\left[y(k+1) - y(k)\right] + 0.075u(k)$$

With the control law from Example 3, $u(k) = -10y(k) - 3.5\hat x_2(k)$, the observer becomes

$$\hat x_2(k+1) = 0.2375\hat x_2(k) + 5y(k+1) - 5.75y(k)$$

Z-transforming both equations, $\hat X_2(z) = \dfrac{5z - 5.75}{z - 0.2375}Y(z)$ and

$$\frac{U(z)}{Y(z)} = -10 - 3.5\,\frac{5z - 5.75}{z - 0.2375} = -\frac{27.5z - 22.5}{z - 0.2375} = -27.5\,\frac{z - 0.818}{z - 0.2375}$$

A zero at $0.818$ and a pole at $0.2375$: a discrete lead compensator, the classical answer for a $1/s^2$ plant.

The tutorial sheet gives this compensator as $\dfrac{U(z)}{Y(z)} = \dfrac{27.5z}{z - 0.2375}$, which drops the $-10y(k)$ term (the zero at $0.818$) and the minus sign of negative feedback. In its Ex-3 version, the last line also swaps $\hat x_2$ and $y$ ("$0.2375y(k) + \dots - 5.75\hat x_2(k)$"); the correct form is the one above.

State feedback with integral control

State feedback alone gives a steady-state error to a constant reference when the plant has no integrator, or when there is a constant disturbance. Add an integral state that sums the error:

$$v(k) = v(k-1) + y(k) - r \quad\Rightarrow\quad v(k+1) = v(k) + c\left[Fx(k) + gu(k)\right] - r$$

The augmented system is

$$\begin{bmatrix} x(k+1) \\ v(k+1) \end{bmatrix} = \begin{bmatrix} F & 0 \\ cF & 1 \end{bmatrix}\begin{bmatrix} x(k) \\ v(k) \end{bmatrix} + \begin{bmatrix} g \\ cg \end{bmatrix}u(k) + \begin{bmatrix} 0 \\ -1 \end{bmatrix}r$$

If the loop is stable and $r$ is constant, the states settle to constants $x_s$, $v_s$, $u_s$, and then $v(k+1) = v(k)$ forces $y = r$: zero steady-state error. Subtracting the steady-state equations gives a standard regulator in the deviations $\tilde x = [x - x_s;\ v - v_s]$, $\tilde u = u - u_s$:

$$\tilde x(k+1) = \tilde F\tilde x(k) + \tilde g\tilde u(k), \qquad \tilde F = \begin{bmatrix} F & 0 \\ cF & 1 \end{bmatrix}, \quad \tilde g = \begin{bmatrix} g \\ cg \end{bmatrix}$$

Place the poles of $\tilde F - \tilde g\tilde k$ as before and split $\tilde k = [k_p\ \ k_i]$.

Example 6. $G(s) = \dfrac{1}{s + 3}$, $T = 0.1$ s. With a ZOH, $G(z) = \dfrac{(1 - e^{-0.3})/3}{z - e^{-0.3}} = \dfrac{0.0864}{z - 0.741}$, so $y(k+1) = 0.741y(k) + 0.0864u(k)$ (here the state is $y$ itself). The specification $\zeta = 0.5$, $\omega_n = 5$ rad/s gives

$$z = e^{-\zeta\omega_nT}e^{\pm j\omega_nT\sqrt{1 - \zeta^2}} = e^{-0.25}e^{\pm j0.433} = 0.7788\angle \pm 24.8^\circ = 0.707 \pm j0.327, \qquad \alpha_c(z) = z^2 - 1.4136z + 0.6065$$

$$\tilde F = \begin{bmatrix} 0.741 & 0 \\ 0.741 & 1 \end{bmatrix}, \quad \tilde g = \begin{bmatrix} 0.0864 \\ 0.0864 \end{bmatrix}, \quad W_C = \begin{bmatrix} 0.0864 & 0.0640 \\ 0.0864 & 0.1504 \end{bmatrix}, \quad \alpha_c(\tilde F) = \begin{bmatrix} 0.108 & 0 \\ 0.2425 & 0.1929 \end{bmatrix}$$

Ackermann's formula gives $\tilde k = [0\ \ 1]W_C^{-1}\alpha_c(\tilde F) = [1.55\ \ 2.23]$, so

$$u(k) = -1.55\,y(k) - 2.23\,v(k)$$

Check: $\tilde F - \tilde g\tilde k$ has eigenvalues $0.707 \pm j0.327$.

Three small slips on the tutorial sheet: the integral state is written $v(k+1) = v(k) + y(k) - r$, but the augmented matrices it then uses belong to $v(k+1) = v(k) + y(k+1) - r$ (the chapter's definition); the radius is written $e^{-0.5}$ where $e^{-0.25} = 0.7788$ is meant, and the angle uses $0.75$ in place of $\sqrt{0.75}$ (the numbers that follow are right); and the gains $[1.564\ \ 2.243]$ should be about $[1.55\ \ 2.23]$, which places the poles exactly.

Deadbeat control

A discrete system can do something no continuous one can: reach the target exactly in a finite number of steps. Put all $n$ closed-loop poles at the origin,

$$\alpha_c(z) = z^n \quad (a_1 = a_2 = \dots = a_n = 0)$$

By the Cayley-Hamilton theorem $(F - gk)^n = 0$, so $x(n) = (F - gk)^nx(0) = 0$: any initial state is driven to the origin in at most $n$ samples. Ackermann's formula becomes $k = [0\ \cdots\ 0\ \ 1]\,W_C^{-1}F^n$. A deadbeat observer likewise puts all eigenvalues of $F - mc$ at $z = 0$, so the estimation error vanishes in $n$ steps.

Example 7. Deadbeat control of the satellite to a step command $\theta_r$. The target state is $x_s = [\theta_r\ \ 0]^T$, and because the plant integrates, the steady input is $u_s = 0$. With the shifted state $\tilde x_1 = x_1 - \theta_r$, $\tilde x_2 = x_2$ the model is unchanged, $\tilde x(k+1) = F\tilde x(k) + gu(k)$. Then

$$F^2 = \begin{bmatrix} 1 & 2T \\ 0 & 1 \end{bmatrix}, \quad W_C = \begin{bmatrix} T^2/2 & 3T^2/2 \\ T & T \end{bmatrix}, \quad \det W_C = -T^3, \quad W_C^{-1} = \frac{1}{T^3}\begin{bmatrix} -T & 3T^2/2 \\ T & -T^2/2 \end{bmatrix}$$

$$k = \begin{bmatrix} 0 & 1 \end{bmatrix}W_C^{-1}F^2 = \begin{bmatrix} \dfrac{1}{T^2} & \dfrac{3}{2T} \end{bmatrix} = \begin{bmatrix} 100 & 15 \end{bmatrix} \text{ for } T = 0.1 \text{ s}$$

$$u(k) = -100\left(x_1(k) - \theta_r\right) - 15x_2(k)$$

The figure above shows the angle reaching $\theta_r$ exactly at the second sample and staying there.

The tutorial sheet writes $Fg = [3T^2/2\ \ \ T + T^2]^T$ and carries $T + T^2$ into $W_C$ and its determinant. With $F = \begin{bmatrix} 1 & T \\ 0 & 1 \end{bmatrix}$ the second entry is just $T$, so $\det W_C = -T^3$. The final gain $k = [100\ \ 15]$ printed on the sheet is right.

Deadbeat control is the fastest possible response, but it is aggressive: the gains grow as $1/T^2$, so a short sampling period demands large inputs that may saturate the actuator, and the response between samples can overshoot. In practice the sampling period is chosen with the actuator limits in mind.

Exercises

  1. For $F = \begin{bmatrix} 1 & 1 \\ -0.25 & 0 \end{bmatrix}$, $g = \begin{bmatrix} 1 \\ -0.5 \end{bmatrix}$, $c = [1\ \ 1]$, test controllability and observability.
    Show solution
    $Fg = \begin{bmatrix} 0.5 \\ -0.25 \end{bmatrix}$, $W_C = \begin{bmatrix} 1 & 0.5 \\ -0.5 & -0.25 \end{bmatrix}$, $\det W_C = -0.25 + 0.25 = 0$: not controllable ($g$ is an eigenvector of $F$ for the double eigenvalue $0.5$).
    $cF = [0.75\ \ 1]$, $W_O = \begin{bmatrix} 1 & 1 \\ 0.75 & 1 \end{bmatrix}$, $\det W_O = 0.25 \ne 0$: observable.
  2. (Drone attitude.) For the double integrator with $T = 0.1$ s, $F = \begin{bmatrix} 1 & 0.1 \\ 0 & 1 \end{bmatrix}$, $g = \begin{bmatrix} 0.005 \\ 0.1 \end{bmatrix}$, find $k$ that places the closed-loop poles at $z = 0.85 \pm j0.15$.
    Show solution
    $\alpha_c(z) = z^2 - 1.7z + 0.745$. Matching with the characteristic equation of Example 3: $0.005k_1 + 0.1k_2 = 0.3$ and $0.005k_1 - 0.1k_2 = -0.255$. Adding, $0.01k_1 = 0.045$, so $k_1 = 4.5$ and $k_2 = 2.775$.
    Note: these poles have radius $0.863$, so $\zeta\omega_n = -\ln(0.863)/0.1 \approx 1.47$ s⁻¹ and the settling time is about $4/1.47 \approx 2.7$ s, not the 0.5 s quoted in the tutorial's problem statement.
  3. (Robot arm, deadbeat.) With $T = 0.05$ s, $F = \begin{bmatrix} 1 & 0.05 \\ 0 & 1 \end{bmatrix}$, $g = \begin{bmatrix} 0.00125 \\ 0.05 \end{bmatrix}$, check controllability and find the deadbeat gain.
    Show solution
    $\det W_C = -T^3 = -1.25\times10^{-4} \ne 0$, so the system is controllable. From Example 7, $k = [1/T^2\ \ \ 3/(2T)] = [400\ \ 30]$. The arm reaches the commanded position in two samples (0.1 s), but the gain is four times larger than at $T = 0.1$ s, so check the actuator limits.
  4. (UAV velocity.) For the double integrator with $y = x_1$ and sampling period $T$, design a reduced-order observer for $x_2$ with its pole at $z = 0.6$.
    Show solution
    As in Example 5 the error pole is $1 - mT$, so $m = 0.4/T$ ($m = 4$ for $T = 0.1$ s). The observer is $\hat x_2(k+1) = \hat x_2(k) + Tu(k) + m\left[y(k+1) - y(k) - \tfrac{T^2}{2}u(k) - T\hat x_2(k)\right]$; for $T = 0.1$: $\hat x_2(k+1) = 0.6\hat x_2(k) + 4[y(k+1) - y(k)] + 0.08u(k)$.
  5. (Greenhouse temperature.) $G(s) = \dfrac{1}{s + 2}$, $T = 0.1$ s. Discretize with a ZOH, augment with an integral state, and place the poles at $z = 0.7 \pm j0.2$.
    Show solution
    $G(z) = \dfrac{(1 - e^{-0.2})/2}{z - e^{-0.2}} = \dfrac{0.0906}{z - 0.8187}$. (The tutorial sheet prints $0.095$ for the numerator.) $\tilde F = \begin{bmatrix} 0.8187 & 0 \\ 0.8187 & 1 \end{bmatrix}$, $\tilde g = \begin{bmatrix} 0.0906 \\ 0.0906 \end{bmatrix}$, $\alpha_c(z) = z^2 - 1.4z + 0.53$. Ackermann's formula gives $\tilde k \approx [3.19\ \ 1.43]$, so $u(k) = -3.19y(k) - 1.43v(k)$. (With the sheet's $0.095$ the gains would be $[3.04\ \ 1.37]$.)
  6. Example 4's observer (poles at 0.5, 0.5) is used with Example 3's control law. What are the poles of the complete closed loop?
    Show solution
    By the separation principle they are the controller poles and the observer poles together: $0.795 \pm j0.256$ and $0.5$ (twice). The characteristic polynomial is $(z^2 - 1.6z + 0.70)(z - 0.5)^2$.
  7. Why does the satellite need the shifted state $\tilde x_1 = x_1 - \theta_r$ to follow a step, while Example 6 needs an integral state?
    Show solution
    The satellite is a double integrator: a constant angle needs zero input, so $u_s = 0$ and feeding back the error $x_1 - \theta_r$ is enough. The plant $1/(s + 3)$ has no integrator: holding $y = r$ needs a non-zero $u_s$, and any error in the model or a constant disturbance would leave an offset. The integral state supplies $u_s$ automatically and removes the offset.
