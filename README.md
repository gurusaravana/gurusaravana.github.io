# gurusaravana.github.io

Personal academic website of Dr. Saravanakumar Gurusamy, live at https://gurusaravana.github.io

## How to update the website

Everything on the website is in one file: `index.html`.

1. Open `index.html` on GitHub and click the pencil icon ("Edit this file").
2. Find the text you want to change (for example a course name or a new paper) and edit it.
3. Click **Commit changes**. The website updates automatically within about two minutes.

To add a publication, copy one of the existing `<li class="pub" ...> ... </li>` blocks under the right year and change the title, authors and journal.

Images live in `assets/img/`. To change the profile photo, upload a new picture there named `gskPro1.jpg`.

The previous version of the site (al-folio theme) is kept in the repository history.
